[현재 상태 — 재조사 금지]

- 사람 외부 판정자는 없다. 판정자는 맥락 없는 서브에이전트(AI)뿐이며 **사람 검증이 아니다**.
- 문턱 A(확대 없음, 구역 크롭) AI 파일럿 2회: alpha 0.666→0.680, 판단불가 12.5→15%, 정의 모호 지적 미해결(가장자리 경계가 3명 모두 재제기). 통과 선언 없음.
- 탐색 160곳(문턱 A, AI): 칸별 합의 결함 TN 0/33, FP 4/33, FN 6/31, TP 13/28(0%/12%/19%/46%), 가중 9.6%(6.4~13.1), 보조 alpha 0.561, 판단불가·합의불가 21.9%. 해석(추정): 사람 target 양성의 절반 이상이 A 기준으로 정상이고 확대해야 보이는 자국으로 보임.
- 산출물: `artifacts/independent-judgment-20261112/`(Git 제외: sample.json, crops, pilot*_responses, main_responses, *_results.json, rater_instructions_v2.txt), 스크립트 `tools/diagnostics/independent-judgment-20261112/`.
- **사용자 결정 대기(너는 결정하지 않는다)**: ① 문턱을 확대 기준(B, 고정 2배)으로 바꿔 target과 맞춘다 ② 문턱 A 유지 + target 양성을 A 기준으로 재정의한다. 이 결정과 AUC 게이트 처리는 사용자만 한다.
