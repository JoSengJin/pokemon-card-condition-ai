# 후면 표면 새 독립 보류(보류2) 계획 (2026-11-03, 라벨 입력 전 고정)

- 배경: D2에서 후보 B가 D1 표면 칸에서 미충족(격차 0.140, §80). D1 표면 칸은 후보 B에 소비됐다. 사용자가 표면 다시 라벨링을 지시(2026-11-03).
- 자료: 후면 101장(ap~aw, C5 후보 F 평가에 쓰인 사진이며 표면 후보 B의 학습·평가·임계에는 쓰이지 않음). 새 사진 수집 없음(외부 호출 0).
- 라벨: 새 규약(확대 기준, 안쪽 인쇄면의 긁힘·눌림·구김·얼룩·인쇄 외 자국만 결함; 엣지·모서리 마모·화이트닝 제외) 9칸, 카드 상자 사람 확인, 모델 예측·미리 채움 없음.
- 사용: 새 표면 후보를 다른 자료(개발 + 소비된 보류)로 동결한 뒤 이 보류에서만 한 번 평가한다. 후보와 기준 수치는 결과 전에 확정한다. 이 계획은 후보·기준을 정하지 않는다.
- 위험: 101장 중 결함 사진이 약 20장 안팎이라 기준(결함 사진 ≥20)에 간당간당하다. 모자라면 미충족이 아니라 "분모 부족"으로 기록하고 추가 수집은 별도 승인.
