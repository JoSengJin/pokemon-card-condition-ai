## 1. 목적과 배경

- 읽기 전용 점검(사후): 크롭 크기(짧은 변 중앙값 309~312px)와 묶음·언어·촬영 제한 구성은 화면 간 비슷하고, 화면마다 사진 64개가 서로 다르다. 화면 1과 2~5 양쪽에 판정 가능한 모서리가 있는 정상 카드 33장 중 28장이 화면 1에서 결함 비율이 높고 0장이 낮다. 화면 1 안의 네 구간은 10/11·8/9·10/11·8/10으로 고르게 높다. 원인은 미확인이다.
- 목표: 흔들림의 크기와 그것이 회차를 따르는지 구역을 따르는지 안다. 확장 146장과 v2를 정하기 위한 근거다.
- 목표가 아님: 1단계 답 교체, 봉인 라벨 정정, 올바른 정답 확정, 사람 판정의 좋고 나쁨 평가, 모델 성능.
- 실패로 보는 것: 새 답으로 1단계 결과를 덮어쓰기, 결과를 본 뒤 규칙 변경, 엄격한 쪽이나 느슨한 쪽을 정답으로 고르기.

## 3. 표본 (점수·답을 보지 않고 고름)
- 화면 1: 64구역 전부(정상 50·눈가림 결함 10·기준점 4).
- 화면 2~5: 같은 구성 64구역. 정상 50 = 화면별 12·12·13·13(화면 2·3·4·5 순), 눈가림 결함 10과 기준점 4는 화면 2~5 전체에서. 번호순 정렬 뒤 `random.Random(20261125)`로 섞어 앞에서부터. 응답 파일은 읽지 않는다.
- 화면 1은 결과가 극단이라 고른 화면이므로, 새 회차에서 가운데로 움직이는 것이 일부는 우연일 수 있다(평균으로의 회귀). 화면 2~5 묶음을 함께 봐서 구분하며, 화면 1만의 움직임을 원인의 증거로 쓰지 않는다.
- 배치: 새 화면 2개(각 64구역). 각 화면에 원래 화면 1 구역 32, 나머지 32를 층 구성이 같게(정상 25·눈가림 결함 5·기준점 2씩) 나눠 넣고 섞는다. 같은 카드의 구역은 10칸 이상 떨어뜨린다. 원래 화면이 새 화면의 순서·피로와 섞이지 않게 하려는 것이다.
- 번호는 새로 매긴다(z2001~z2128). 이전 번호·답·층·원래 화면은 숨긴다.

## 4. 화면·판정 절차
- 1단계와 같은 화면 코드(고정 SHA), 같은 안내문, 같은 크롭, 같은 입력. 바뀌는 것은 화면 이름(A2·B2)과 구역 순서뿐이다.
- 마지막 1단계 판정(2026-11-24 07:35 도착)에서 **24시간 이상 뒤**, 두 화면을 이어서 판정한다. 기억을 줄이려는 것이며 완전히 없애지는 못한다.
- 결과는 `# 화면=`·`# 제출시각=` 줄까지 붙여넣는다. 두 줄이 없으면 분석은 종료 코드 2로 멈추고, 1단계의 예외를 자동으로 이어 쓰지 않는다. "사람이 직접 판정함" 문장도 화면마다 확인한다.

## 5. 지표와 판정 규칙 (결과 전에 고정, 승인 뒤 변경 금지)
- 이진 값: 미세·뚜렷 = 결함, 정상 = 정상. 불가·미판정은 해당 계산에서 빼고 건수와 이동(판정 가능↔불가)을 따로 보고한다. 1단계 값은 분석 입력 `input-1~5.txt`를 쓴다(z1·z2는 첫 답).
- 주 1: 새 회차 정상 층 구역의 결함 비율, 원래 화면 1 대 화면 2~5(각 k/n, Wilson95, 양측 Fisher 정확 p).
- 주 2: 정상 층에서 두 회차 모두 판정 가능한 구역의 변경, 묶음별(결함→정상, 정상→결함, 양측 McNemar 정확 p).
- 미측정: 주 1에서 어느 묶음이든 판정 가능 구역 30 미만, 또는 주 2에서 어느 묶음이든 두 회차 공통 판정 구역 25 미만.
- 판정(위에서부터 첫 번째 해당):
  1. **구역을 따라 남음**: 주 1의 p < 0.05이고 화면 1 묶음이 20%p 이상 높다. (자료의 차이일 수도, 이전 답의 기억일 수도 있다. 둘을 가르지 못한다.)
  2. **회차마다 엄격도가 달라짐**: 주 2에서 어느 한 묶음이든 p < 0.025(두 묶음이라 0.05를 나눔).
  3. **불확정**: 그 외.
- 판정 1이어도 주 2의 결과를 함께 적는다. 같은 카드의 구역은 독립이 아니므로 p와 구간은 방향 표지다.
- 이전 대화에서 말한 "안정" 결과는 따로 두지 않는다. 첫 회차 차이가 커서, 답이 안정적이면 판정 1이 된다.
- 보조(장수 위주, 판정에 쓰지 않음): 전체·묶음별 이진 일치율(Wilson95)과 카파, 눈가림 결함 20구역의 정상 판정 수, 기준점 8구역의 정상 판정 수, 미세/뚜렷 이동, 새 화면 A2·B2 차이, z1·z2의 세 번 답. 분모 15 미만은 장수만.
