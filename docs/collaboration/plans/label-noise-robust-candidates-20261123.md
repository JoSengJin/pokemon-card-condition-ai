# 라벨 잡음(정상 라벨에 결함 혼입)에 강건한 학습 후보 조사 (2026-11-23, Claude R2) — 조사 문서, 실행 승인 아님

**결론: 후보 3개로 압축, 추천 순서 ① 라벨 v2 교체 학습의 선행 재판정(사람 작업) → ② 의심 정상 구역 학습 제외(스코어 기반) → ③ PU식 비음수 위험 손실.** 학습·추론·소스 수정·라벨 변경·외부 모델 호출은 0이다. 이 문서는 승인이 아니며, 실험은 새 가설 ID·사전 기준·사용자 승인 뒤에만 `./experiment --plan`으로 한다. 독립 350장·새 코호트 468장은 쓰지 않는다. 모델 오답을 이유로 사람 라벨을 바꾸지 않는다.

## 1. 우리 기록의 근거와 한계

- 블라인드 재판정(`docs/collaboration/reports/w1-blind-rejudge-result-20261123.md`): 이진 45구역 일치 36/45, kappa 0.609. 이전 결함→이번 결함 18/19, 이전 정상→이번 정상 18/26. 불일치 사후 확인(사용자 진술, 비블라인드)에서 이전 정상 중 ≥6구역이 결함. 6/26 = 23.1%(Wilson95 약 11~42%, 제가 계산, 하한이라 표본 선정 방식이 대표적인지는 **가정**). 결함 라벨 쪽 잡음은 작아 보임(1/19)이나 n이 작아 **비대칭 확정 아님**(보고서가 구간 겹침으로 확정 불가라 명시).
- 정상 표본 30구역 중 모델 점수 ≥0.60 4구역은 모두 재확인 결함(4/4, Wilson95 하한 약 0.51, 제가 계산), 일치 정상 18구역은 0/18. 즉 "높은 OOF 점수의 이전 정상"이 잡음 의심 신호로 쓸 만하다는 **n=4의 개발 근거**다. 이 30구역이 모델 점수와 어떤 관계로 뽑혔는지(선정 규칙)는 이 문서에서 미확인.
- 구조: 고정 DINOv2 ViT-S/14 패치 토큰 + 선형 토큰 head, 묶음 손실 `detail_bag_loss` mean_odds, 후보 E는 같은 사진 쌍 순위 항 포함. 모서리 후보 E 개발 OOF(946구역·257그룹): 풀링 AUC 0.8565, 같은 사진 AUC 0.796(`docs/superpowers/specs/2026-11-21-accuracy-ceiling-head-input-quality-design.md`).
- 용량·자료 증가의 효과 없음: 백본·차원·L2·해상도·층·미세조정·자료 추가가 AUC 0.85를 못 넘었고 §37·§39에서는 오히려 낮췄다(같은 설계 문서 인용). MLP head는 수렴 실패로 중단(효과 미확인). 따라서 **용량을 늘리는 방법은 제외**하고, 선형 head·고정 특징을 유지하는 방법만 본다.
- 재판정 규모의 한계: 이전 정상 26구역뿐이며 확신도는 대부분 미입력(확신도별 분석 미측정). 라벨 기준 초안(`corner-label-standard-draft-20261123.md`)은 사용자 확정 전이고 "경계" 범주·미세 백화 문턱이 미확인이라, 잡음이 "진짜 오류"인지 "기준 차이"인지 분리되지 않았다. **이 구분 없이 잡음률을 확정하지 않는다.**

## 3. 후보 (3개)

### 후보 ① 라벨 v2 교체 학습 — 선행 재판정 필요
- 원리: 의심 이전 정상 구역을 사용자가 블라인드 재판정해 별도 v2 파일(원본 보존)에서 확정 결함·정상으로 학습한다. 잡음을 추정하지 않고 제거한다.
- 변경 변수: 학습 라벨 집합 1개(코드·손실·특징 불변). **단, 평가 라벨도 v1이냐 v2냐를 사전 고정해야** 해서 평가 분모가 바뀌면 이전 수치와 비교 금지(AGENTS.md 성능 보고 규칙).
- 선행 조건: (a) 사용자가 라벨 기준(미세 백화 문턱, 경계 범주)을 확정(초안 §4 질문 1~5), (b) v2 파일 별도 생성 승인, (c) 재판정 대상 규모. 후보 집합 크기는 **미확인**(이전 정상 946구역 중 의심 목록은 아직 없음). 한 번에 전부 못 하므로 의심 높은 순 상위 N(예: 30~60)부터가 현실적이나 N은 **가정**이며 사용자 노동량 결정 사항. 완료 라벨 재요청 금지 규칙의 예외이므로 사용자 결정이 필요하다.
- 사전 기준 초안(기존 W2 계약 인용): 개발 OOF 풀링 AUC 대조 대비 ≥ +0.02이고 사진 그룹 부트스트랩 2000회 하한 >0, 같은 사진 AUC가 대조보다 낮지 않음, 오탐을 맞춘 카드 단위 누락이 대조보다 많지 않음, 새 FN 없음(`no_new_errors`). 평가 라벨은 v1(대조와 같은 분모)을 주 평가로 두고 v2 부분집합은 보조로만 보고.
- 실패 판정 문장(초안): 위 중 하나라도 미충족이면 "라벨 v2 교체 학습은 개발 OOF에서 개선을 보이지 않음"으로 기록하며, 라벨 잡음이 원인이 아니라고 단정하지 않는다(재판정 규모 부족, v1 평가 잡음이 가려질 수 있음).
- 과적합·용량 위험: 용량 불변이라 낮음. 단, 라벨이 학습에만 바뀌고 평가는 v1이면 평가 잡음이 개선을 가린다(방향이 불리한 쪽). 사람 재판정 결과가 사용자 판정이므로 모델 오답을 이유로 정답을 바꾸는 것이 아니다(재판정 구역 선정에 모델 점수를 쓰면 그 선정 규칙과 의도를 기록해야 함).
- 비용: 학습 5 fold(특징 캐시 재사용 가정), 주된 비용은 사람 재판정 시간. 외부 호출 0.

### 후보 ② 의심 정상 구역 학습 제외(스코어 기반 작은 손실/신뢰 학습의 최소형)
- 원리: 교차검증 표본외(out-of-fold) 점수가 높은 이전 정상 구역을 학습에서만 제외(또는 1회 정제)한다. 라벨은 바꾸지 않고, 평가는 전체 v1 라벨로 한다. Confident Learning·작은 손실 선택의 가장 단순한 형태.
- 변경 변수: 학습 행 집합 1개(제외 규칙 하나). 임계는 결과 보기 전에 고정(예: 정상 라벨 중 OOF 점수 상위 q%, q는 승인 시 확정). 기록상 근거는 "≥0.60 정상 4/4가 재확인 결함"(n=4)뿐이다.
- 선행 조건: 저장된 후보 E OOF 점수 재사용 가능 여부(미확인: 경로 `artifacts/experiments/20261102T140143-82781117`는 설계 문서 인용). 순환 위험: 같은 OOF 점수로 선별하므로 선별된 구역은 모델이 이미 정답이라 믿는 쪽의 편향을 강화할 수 있다. 이를 줄이려 **선별은 fold 안에서 해당 fold 학습 구역만으로 산출**해야 하며, 평가 fold의 점수·라벨은 선별에 쓰지 않는다(구현 계약, 승인 시 명시). 잡음률 추정을 위한 별도 재판정은 필수가 아니나, 제외 대상의 정밀도(진짜 결함 비율)를 알려면 최소 30구역 안팎의 블라인드 재판정 추가를 권한다(정밀도 추정용, 분모 30은 W1 관문 규칙을 따른 **가정**).
- 사전 기준 초안: 후보 ①과 동일(풀링 AUC +0.02 & 하한 >0, 같은 사진 AUC 비하락, 오탐 맞춘 누락 비악화, 새 FN 없음). 추가: 제외 구역 수·비율과 제외된 구역의 사람 재확인 결함 비율(있는 범위)을 함께 기록.
- 실패 판정 문장(초안): 기준 미충족이면 "스코어 기반 제외는 개발 OOF에서 개선을 보이지 않음". 풀링 AUC만 오르고 같은 사진 AUC나 누락이 나빠지면 실패로 처리한다(쉬운 쪽으로 편향된 개선 방지).
- 과적합·용량 위험: 용량 불변. 그러나 어려운 진짜 정상(예: 반사·홀더)을 같이 제외해 모델이 쉬운 구역에만 맞춰질 위험이 있고, 모델 점수로 학습 행을 고르므로 "모델 오답을 이유로 정답을 바꾼다"는 오해를 피하려면 라벨 파일은 불변이고 제외는 학습 행 선택일 뿐임을 기록에 명시한다. 이 해석이 규칙에 어긋나는지는 사용자 확인 필요(미확인).
- 비용: 학습 5 fold + 1단계 선별 학습, 외부 호출 0. 구현 변경은 행 선택 한 곳이어도 `./develop` 안에서만 한다.

### 후보 ③ PU식 비음수 위험 손실(결함=양성, 정상=비라벨)
- 원리: 정상 라벨을 "비라벨(결함이 섞일 수 있음)"로 보고, 양성(결함) 손실과 비라벨 손실에서 양성이 섞인 몫을 빼되 음수로 내려가지 않게 하는 추정기(nnPU).
- 변경 변수: 손실 함수 1개(특징·head·fold 불변). 그러나 우리 손실이 구역이 아닌 **묶음 손실(detail_bag_loss mean_odds, 카드·사진 단위)** 이라 PU 항을 구역 단위로 두는지 묶음 단위로 두는지 설계가 필요하고, 같은 사진 쌍 순위 항과의 상호작용도 **미확인**. 즉 "변수 하나"가 구현상 가장 흐리다.
- 선행 조건: 정상 라벨 안의 실제 결함 비율(클래스 사전확률) 추정. 재판정 기준 6/26≈23%(구간 약 11~42%)로 폭이 너무 넓어, nnPU가 사전확률에 민감한지(본문 미확인)를 확인하기 전에는 위험. 재판정 규모를 키워 구간을 좁히거나(예: 정상 라벨 무작위 표본 60구역 이상, 가정) 라벨 기준을 확정해 사전확률을 안정시켜야 한다. 평가 분모가 같은 v1이면 비교 가능.
- 사전 기준 초안: 후보 ①과 동일. 사전확률 값은 결과 보기 전에 고정(예: 재판정 점추정 23%와 하·상한 민감도 3점, 단 가설 하나로 묶기 위해 주 실험은 점추정 1개만).
- 실패 판정 문장(초안): 기준 미충족이면 "PU식 손실은 개발 OOF에서 개선을 보이지 않음". 손실 항이 음수로 갈 때 보정이 작동했는지 로그에 기록.
- 과적합·용량 위험: 선형 head라 용량 위험은 낮으나, nnPU는 유연한 모델의 과적합을 막는 용도로 제안된 것이라(요약) 선형 head에서 이득이 작을 수 있다(가정). 사전확률 오추정 시 정상 쪽 신호를 과도하게 깎을 위험.
- 비용: 구현 복잡도 최고(묶음 손실 개조), 학습 5 fold.

## 4. 추천 순서와 기각 이유

추천 순서
1. **후보 ①의 선행(재판정 확대 + 라벨 기준 확정)부터.** 이유: 잡음이 진짜 오류인지 기준 차이(미세 백화 문턱)인지가 지금 분리되지 않았고, 후보 ②·③의 정밀도·사전확률 추정이 모두 이 재판정 규모에 의존한다. 사람 작업이지만 모델 용량·구조 시도가 모두 천장에 막힌 기록과 맞는 유일한 직접 방법이다.
2. **후보 ② 의심 정상 구역 학습 제외.** 코드 변경이 가장 작고(행 선택 한 곳) 기존 OOF 근거(4/4)와 맞으며 용량 불변.
3. **후보 ③ PU식 손실.** 사전확률 구간이 넓고 묶음 손실과의 결합 설계가 불명확해 마지막.

기각 이유
- forward/backward 손실 보정: 이진 한쪽 방향 잡음이면 전이행렬이 모수 하나(정상 라벨이 결함일 확률 ρ)지만, ρ 추정 구간이 약 11~42%로 넓고, 민감하다는 요약이 있다. 점수 순위는 단조 변환이라 AUC에 미치는 효과가 제한적일 것이라는 **추정(미검증)**. 후보 ③과 사실상 같은 문제(사전확률)를 공유해 별도 후보로 두지 않는다.
- Co-teaching(두 네트워크 상호 선택): 네트워크 2개·학습 일정 필요, 선형 head는 암기 용량이 작아 작은 손실 이점이 제한적일 것이라는 **가정**. 후보 ②가 같은 원리를 더 작게 구현.
- 소프트 라벨·확신도 가중: 확신도가 대부분 미입력이라 가중치 근거 자료가 없다(보고서: 확신도별 분석 미측정). 새 입력을 요청해야 하므로 보류.
- 경계 구역 학습 제외: 경계 범주가 규약에 없고 사례는 z38 한 건뿐. 라벨 기준 확정 뒤 후보 ①의 일부로 재검토.
- MLP head·용량 증가·자료 추가·미세조정: 기존 기록상 천장을 넘지 못했고 일부는 성능을 낮췄다(위 인용). 잡음 때문일 수 있다는 가설과 겹치나, 용량 증가는 잡음 암기 위험을 키우므로 제외.
