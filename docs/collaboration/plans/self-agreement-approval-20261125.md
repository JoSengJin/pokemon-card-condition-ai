# 자기 일치도 측정 전체 승인 기록 (2026-11-25)

이 문서는 사용자의 채팅 승인을 기록한다. 승인의 증명이 아니라 `plan.json`의 `approval_ref`가 가리키는 기록이다. 새 규칙을 만들지 않으며 기존 규칙이 우선한다. 정확도 변화 없음.

## 사용자 문장 (채팅 원문, 2026-11-25)
- "남은일 모두 승인" — 직전에 제시한 남은 일 목록(입력 파일 3개 담당 지정과 봉인·독립·cohort2 자료의 ID 목록 읽기 허용, 오탐 9카드 전체 ID 확보, `plan.json` 작성·커밋, 전체 승인(완료 라벨 재요청))에 대한 답이다.
- "권고. 진행" — 이전 재판정 카드 제외 범위를 "11-21만 제외하지 않고 W1·11-24·v2는 제외"(남는 카드 107장)로 하는 권고안에 대한 답이다.

## 승인 범위(위 문장이 가리키는 것만)
- 대상: 후면 모서리 칸, 제안서 `docs/collaboration/plans/label-self-agreement-prereg-20261125.md`(개정본 커밋 048905b).
- 구역: 무작위 80구역(카드당 1) + 오탐 9카드×네 모서리 36구역 = 116구역. 사람 판정은 두 회차 × 116 = 232회.
- 간격: 1차 마지막 제출 뒤 7일 이상, 1차 첫 제출부터 14일 이내(중심 10일). 각 회차는 한 번에 끝낸다.
- 화면: `highres` 크롭, 쪽당 30구역(4쪽), 회차마다 확인 문장 "내가 직접 판정했다."를 직접 입력.
- 입력 파일: 모집단·제외 목록·오탐 층 3개를 이 세션이 만들고 ID 목록(group 문자열)만 읽는다. 라벨·점수는 입력 파일에 넣지 않는다.

## 승인하지 않는 것
학습·추론·실험, 정답표·라벨 수정, 구역 추가, 결과를 본 뒤 규칙·값 변경, 오탐 층 결과로 모델 개선을 주장하는 일, 결과가 "미측정"일 때의 추가 수집(새 승인), main 통합·push(별도 승인).

## 이 승인을 실행하면서 확인된 편차(사용자에게 보고함)
- 이전 재판정 카드를 모두 제외하면 모집단이 14장이라 선정 불가였다. 사용자가 "11-21 재판정 카드는 제외하지 않음"으로 정했다.
- 오탐 9카드 중 2장(`b11aa0`, `c3d834`)은 개발 자료에 확정 구역이 2·3개뿐이어서, 나머지 3구역은 같은 사진의 3×3 격자 규칙으로 상자를 도출해 추가했다(재구성 검증: 완전한 카드 218장 중 216장이 오차 0.00005 이내).
