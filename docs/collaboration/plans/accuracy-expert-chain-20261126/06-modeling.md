# 06. 컴퓨터 비전 모델링 — 현재 구조, 시도 이력, 모델 쪽 몫, 잡음·판단 불가 설계 (2026-11-26, Claude)

범위: 읽기 전용 조사, 저장된 점수·라벨의 python 집계, 이 문서 작성만 했다. 학습·새 추론·모델 비교 실행·라벨 수정·사진 열람·외부 AI 호출·`./develop`·`./experiment`·`./review`·commit은 하지 않았다. 다른 파일은 고치지 않았다. 자기 일치도 새 1차 답(`artifacts/self-agreement-split-20261126/out1/`)과 독립 350·봉인 468의 원 라벨 파일은 열지 않았다.

**결론 3줄**
1. **현재 모델이 새 엄격 기준에서 많이 놓치는 이유는 순위 능력 부족보다 점수 눈금 차이다.** 무작위 재판정 119구역(카드당 1구역, 점수를 보지 않고 추출)에서 같은 점수의 AUC는 옛 라벨 0.873, 새 기준 라벨 0.891이다(차이 95% −0.066~+0.099). 그런데 0.5에서 새 기준 누락은 33/60(55%)이다. 결함을 가르는 순서는 유지되고 점수 전체가 옛 느슨한 기준에 맞춰 낮게 놓여 있다. 학습 손실(정상 구역의 최고 패치를 강하게 누르는 항)이 옛 정상 라벨의 숨은 결함을 억누르는 구조와 맞는 방향이다(코드 근거, 인과 미확정).
2. **개발 자료(942구역)에서 모델 변경으로 줄일 수 있다고 근거가 있는 오류는 6/178(3.4%)뿐이다.** 문턱 근처까지 더한 상한도 누락 26·오탐 29구역이다. 같은 칸의 라벨 흔들림 폭(05 관문 ③: 결함 33·정상 44구역)보다 작다. 같은 개발 자료의 모서리 모델 비교 12회 중 2회만 통과했고, 마지막 3회는 연속 미달이다. **지금 개발 자료로 낼 모델 가설은 없다.**
3. **"판단 불가 출력"은 새 head 없이 이미 있는 두 문턱(0.20/0.60) 사이 구간으로 낼 수 있다.** 새 기준 표본에서 낮음 구간의 결함은 6/49(12%), 높음 구간의 정상은 2/25(8%)이고 가운데 보류가 45/119(38%)다. 사람 `판단 불가` 라벨이 0건(02)이라 판단 불가를 학습하는 head는 지금 만들 수 없다. 모델 쪽 개선 목표는 "같은 위험에서 보류 구간을 좁히는 것"으로 바꿔 재야 한다.

구조에서 정확도에 직접 걸리는 세 지점:
- **최대값 집계.** 구역 점수는 약 730개 유효 패치의 최대값이다. 둥근 끝은 약 2%뿐이다(03 2-4). 정상 구역에서 테두리·배경 경계 패치 하나만 높아도 오탐이 된다. 결함 구역에서는 끝 패치 하나가 문턱을 넘어야 한다.
- **정상 묶음 손실의 방향.** 정상 라벨 구역에서는 모든 패치의 최고점을 내리는 쪽으로 학습한다. 옛 정상 라벨 구역의 37%(35/94)가 새 기준에서 결함이다(02 2-5, 04 2-2). 그 구역의 미세 흰 흔적 패치는 학습에서 "낮춰야 할 패치"가 된다. 이것이 2-3절의 눈금 차이와 맞는 작동 경로다(가정: 패치 단위 기울기를 재지 않았다).
- **고정 백본·선형 head.** 백본 미세조정은 한 번도 하지 않았다. head 용량을 키운 MLP는 같은 사진 AUC가 내려가 "용량은 병목이 아니라는 신호"로 기록됐다(`corner-mlp-head-w3-20261121.md:13`). 백본을 ViT-B로 바꾸거나 더한 시도도 기준 미달이었다(2-2절).

모서리에서 **한 번도 시도하지 않은 것**: 백본 미세조정(LoRA 포함), 라벨 잡음 보정 손실(전이 행렬·PU 방식·부드러운 정답), 보정(온도·Platt·등위), 판단 불가 출력 학습, 끝점 기준 집계 범위.

**같은 개발 자료 재시도 금지 목록** (946·942·338구역 개발 CV에서):
1. 입력 축소(224), 60%×60% 확대 크롭, 유효 패치 덮임 조건, 방향 통일, 두 배치 학습
2. head 용량 증가(MLP tanh·ReLU 모두. ReLU는 실행 실패라 성능 미측정이지만, tanh 결과가 "용량 병목 아님"이라 같은 자료 재실행 근거가 없다)
3. 두 번째 패치 집계, 단일 배치 점수의 억제
4. ViT-B/14 추가·교체
5. 애매 구역 학습 제외(재판정 주체가 AI·미확인이라 다시 해도 사람 근거가 되지 않는다)
6. 인쇄면 정상 손실 추가
7. 학습 자료 크기만 늘린 같은 레시피(170→338)
8. 같은 자료에서 문턱·작동점 이동을 개선으로 보고

연속 미달 상태: 942구역에서 마지막 세 모델 비교(coverage, orientation, phase-train)가 연속 미달이다. `stop-repeated-misses` 상한 3은 아직 발효 전이고 과거 미달은 세지 않는다(`COMMON_EXPERIMENT_RECORDS.md:152-153`). 형식상 차단은 아니지만 내용상 같은 상황이다. 개발 자료의 모서리 모델 비교 12회 중 통과 2회(E, 네 배치 평균)다.

### 2-3. 새 기준에서 모델 순위는 유지되고 눈금만 어긋난다 (K2)

같은 119구역(무작위, 카드당 1구역, `select.py` 시드 추출), 같은 네 배치 평균 점수:

| 정답 | 결함 / 정상 | AUC (구역 복원추출 95%) | 0.5에서 누락 | 0.5에서 오탐 |
|---|---|---|---|---|
| v1 옛 라벨(주체 미확인) | 25 / 94 | 0.873 (0.79~0.945) | 8/25 | 12/94 |
| v2 새 기준(사람 기록, 11-27 재대조 예정) | 60 / 59 | 0.891 (0.83~0.944) | 33/60 = 55% (42.5~66.9) | 2/59 = 3.4% (0.9~11.5) |

- AUC 차이 v2−v1은 +0.018(95% −0.066~+0.099)이다. 순위 능력이 새 기준에서 나빠졌다는 근거가 없다.
- 문턱별 v2 오류: 0.5 → 누락 33·오탐 2, 0.4 → 22·5, 0.3 → 11·11, 0.2 → 6·16. 새 기준 정상 59구역 중 57구역이 0.43 미만이다.
- **해석:** 새 기준에서 누락이 큰 것은 대부분 "어디에 선을 긋는가"(기준 쪽)이고, 순위로 남는 오류는 0.3 근처에서 약 22/119구역이다. 이 문턱 값들은 결과를 본 뒤의 곡선 읽기다. 개선 주장에 쓰지 않는다(`OBSERVATION_CONSENSUS_20261011.md:25`, `QUALITY_RULES.md:77`).
- 한계: 119구역은 개발 자료의 부분집합이라 독립 시험이 아니다. 결함 25구역은 눈가림으로 섞은 표본이라 결함 비율 50%는 실제 비율이 아니다. v2 판정 주체가 11-27 재대조에서 AI 동일로 나오면 이 절 전체가 무효다(05 4-3 분기 B).

## 4. 설계 (상위 3개)

### 설계 M1: 새 기준 작동점 사전 고정 (변경 변수: 작동점 하나. 모델·head·라벨 불변)

- 성격: `error-cause-triage`의 "기준 쪽" 진단이다. 정확도 향상이라고 부르지 않는다. 목적은 400장 측정이 옛 기준 눈금으로 새 기준 라벨을 재는 일을 막는 것이다.
- 입력: 네 배치 평균 개발 OOF 점수(`8588eeb0/observations.json`), `overlay-100.json` 119구역(v2). 오류 구역에서 골라 넣은 8구역(`overlay.json`)은 섞지 않는다.
- 규칙 후보(사용자가 하나를 고른다, 추천 A):
  - (A) **누락 상한 규칙**: v2 결함 60구역 누락이 Wilson 95% 상한 ≤ 30%가 되는 가장 높은 0.01 단위 문턱. 정확도 우선(누락 우선) 결정과 맞다.
  - (B) 같은 오류 규칙: v2 누락 수 = 오탐 수가 되는 가장 높은 문턱.
- **선행 노출 공개**: 이 문서를 쓰며 곡선(0.5/0.4/0.3/0.2)을 이미 봤다. (B)는 0.30(11/11)이 되고, (A)도 0.30이다(11/60의 Wilson 상한 29.9%, 0.31이면 12/60). 규칙을 먼저 고르고 값을 기계적으로 계산해 기록하되, 이 노출을 계획에 적는다.
- 카드 작동점 0.20/0.60은 바꾸지 않는다. 새 기준 표본에서도 0.20 아래 결함 6/49, 0.60 이상 정상 2/25로 양 끝이 작동한다(2-4절). 바꿀 근거가 없다.
- 판정(사전 고정): 400장 측정에서 구역 누락·오탐을 05 4-2절 DEFF 보정 Wilson으로 보고한다. 0.5와 M1 문턱 두 값을 같은 표에 기술용으로 둔다. 비교 판정은 하지 않는다(측정 1회).
- 분기: 11-27 v2 재대조가 B(AI 동일)·C(미결)면 M1을 하지 않는다. 그 경우 400장 측정은 0.5와 0.20/0.60만 쓴다.
- 필요 자료: 05 4-4절 독립 400장(새 기준 V, 판정 주체 관문 02 L1 통과).

### 설계 M2: 판단 보류 출력과 위험-보류 보고 (변경 변수: 평가 보고 형식 하나. 모델 불변)

- 출력 정의(사전 고정):
  - 구역 점수 < 0.20 → "정상 쪽", ≥ 0.60 → "결함 쪽", 그 사이 → "판단 보류(점수)".
  - 입력 지표 `corner_cut`·`no_blue_border`·px/mm < 10 → "판단 보류(입력)". 점수와 무관하게 먼저 적용한다.
  - 이미 있는 `held` 상태와 우선순위 구간(`back_zone_triage.py:35-45`, `back_edge_triage.py:17-18`)을 그대로 쓴다. 새 head·새 손실은 없다. 운영 코드 변경은 이번 범위가 아니다(사용자 결정).
- 보고 칸(사전 고정): ① 보류 비율(점수·입력 각각) ② "정상 쪽" 안의 사람 결함 수와 비율(= 확신 누락) ③ "결함 쪽" 안의 사람 정상 수와 비율(= 확신 오탐) ④ 0.5 단일 문턱의 누락·오탐(기존 칸). 사진 묶음 DEFF 보정 Wilson(05 4-2).
- 판정 규칙(사전 고정):
  1. ②·③은 보류 비율 ①과 반드시 함께 쓴다. ①이 다른 두 모델의 ②·③을 비교하지 않는다.
  2. 두 모델 비교는 **같은 확신 누락 상한(예: ② ≤ 10%)에서 보류 비율이 줄었는가**로 한다. 짝지은 검정은 05 4-2절 사진 단위 부호 뒤집기 순열 검정(보류 여부의 엇갈림). 이것이 모델 쪽 개선의 정의다.
  3. 입력 보류 구역의 오류율이 남은 구역보다 높지 않으면(사진 부트스트랩 차이 구간이 0 포함) 입력 보류 규칙을 "정보 없음"으로 적고 쓰지 않는다.
- 현재 기술값(개발 942, v1, 탐색): 보류 36%, 확신 누락 5.7%, 확신 오탐 16.0%(2-4절). v2 119: 보류 38%, 12%, 8%.
- 필요 자료: 400장 측정에 같이 넣는다(추가 장수 없음). 판단 불가 사람 상태(01 G1)가 들어오면 "사람 판단 불가 구역의 보류 비율"을 칸으로 더한다.

### 설계 M3: 단방향 라벨 잡음 보정 손실 (변경 변수: 정상 묶음 손실의 전이율 ρ 하나, 0 → 0.372)

- 가설(사전 고정): 옛 정상 라벨은 새 기준 결함을 37%(35/94, Wilson 28.1~47.3%) 품고, 옛 결함 라벨은 거의 뒤집히지 않는다(0/25, 상한 13.3%)(02 2-5, 04 2-2). 정상 묶음 손실이 이 숨은 결함의 패치를 누르기 때문에 새 기준 누락이 생긴다. 이 잡음은 "결함은 깨끗하고 정상이 섞인" 형태라, 정상 라벨을 확률 ρ로 결함일 수 있는 것으로 다루면(양성-미표시 학습과 같은 구조) 새 기준 누락이 준다.
- 변경(최소): `detail_bag_loss`의 정상 분기만 바꾼다(`confounder_head.py:18-20`). 정상 라벨 구역의 손실 = (1 − ρ) × 기존 정상 손실(`max_bound`) + ρ × 기존 결함 손실(`softplus(−max)`). ρ = 35/94 = 0.372, 결과 전에 고정, 다른 값 탐색 없음. 결함 라벨 구역, 같은 사진·카드 순위 항, 가중, L2, LBFGS, fold, 네 배치 평균 채점은 그대로다. 순위 항은 옛 라벨 그대로 쓴다(두 변수를 바꾸지 않기 위해).
- 위험·한계:
  - ρ는 구역 평균이다. 실제로는 모델이 표시한 구역 83%, 표시 안 한 구역 30.5%로 다르다(04 2-2). 균일 ρ는 근사다.
  - 양성-미표시 위험식은 유연한 모델에서 음수로 갈 수 있다(가정: 일반 지식, 원문 이번에 확인 안 함). 선형 head + L2 1.0이라 위험이 작지만, 학습 목적이 음수가 되면 실행 실패로 기록하고 재시도하지 않는다.
  - 사람 정상 라벨을 바꾸지 않는다. 저장 라벨·평가 라벨은 그대로이고 학습 손실의 가중만 바뀐다. 그래도 "사람 정상을 37% 결함으로 다룬다"는 해석이 생기므로 **사용자 결정**으로 둔다.
- 개발 단계(가능성 확인만, 채택 근거 아님): 같은 5겹 OOF로 v2 무작위 119구역에서 M1 문턱의 v2 누락이 대조보다 N_noise(05 4-3, m = 두 팔이 갈린 v2 구역 수) 넘게 줄고, v2 오탐이 2/59에서 N_noise 넘게 늘지 않을 때만 다음으로 간다. v1 942 대비 오탐은 늘 것으로 예상하므로 판정에 쓰지 않고 기술용으로만 적는다(04 E1 규칙 1의 반대 방향임을 계획에 밝힌다). 이 단계도 같은 개발 자료의 13번째 비교라 "우연 가능"으로 적는다.
- 채택 판단(사전 고정): 05 4-3 블록 그대로. 주 지표 = 새 기준 V의 구역 누락(M1 작동점), 반대 지표 = 구역 오탐 비열등 Δ(사용자), N_noise = 2 × ⌈f_hi × m⌉, 사진 단위 순열 검정.
- 필요 자료: 독립 사람 자료. 두 안 중 사용자 결정.
  - (가) 400장을 측정 전용으로 쓰고, A/B는 별도 자료(장수는 개발 단계의 b·c로 `size.py`를 돌려 정한다. 지금은 b·c가 없어 계산하지 않았다. 지어내지 않음).
  - (나) M3 후보와 현재 모델을 **400장 점수 공개 전에 둘 다 동결**하고 한 번에 잰다. D3 첫 시험이 이 방식이었다(`corner-rank-independent-v1`, E와 평균을 둘 다 동결). 자료를 아끼지만, 개발 단계 결과로 후보를 동결한 뒤여야 한다.
- 반증 조건: 새 기준 누락이 N_noise 안이면 "단방향 잡음 가설 지지 안 함"으로 적고, 다른 ρ로 재시도하지 않는다.
- 분기: v2 재대조 B·C면 ρ의 근거가 사라지므로 M3를 하지 않는다.

## 5. 앞 담당 의견에 대한 반박/보완

- **04 결론 1 보완(오탐 대부분 라벨 기준).** 같은 무작위 표본에서 AUC를 재면 v1 0.873, v2 0.891이다. 기준 변화가 오탐을 부풀렸을 뿐 아니라, 새 기준에서 누락이 55%가 되는 이유도 순위가 아니라 눈금이다(2-3절). 그래서 "기준을 바꾸면 오탐은 줄지만 누락은 늘어난다"(04 2-2)는 맞지만, 그 누락의 대부분은 모델 교체가 아니라 작동점(M1)과 학습 정답의 기준 일치(M3·M4)로 다뤄야 한다.
- **04 2-5 "5번째 변형을 정당화할 오류 묶음이 없다" 동의, 횟수 정정.** 개발 자료의 모서리 모델 비교는 12회이고(통과 2), 마지막 3회가 연속 미달이다(2-2절). "4회 미채택"은 E 이후 네 배치 평균 이후만 센 값으로 보인다(`corner-error4-cause-20261125.md:50`, 이번에 그 줄의 정의는 재확인하지 않음).
- **04 질문 답(문턱 근처 26구역 패치 열람).** 열람하지 않았다. 문턱 근처 누락은 2-3절처럼 새 기준에서 작동점 문제와 겹친다. 패치를 봐도 개발 자료에서는 모델 가설로 이어질 수 없으므로(관문 ① < ③) 우선순위를 낮게 둔다.
- **03 질문 답(끝점 기준 집계를 head 쪽에서).** head 쪽 "최대값을 끝점 주변 패치로 제한"(M5)과 03 I4(끝점 중심 입력 창)는 같은 변수(점수가 보는 영역)를 바꾼다. 둘 중 하나만 해야 한다. 두 번째 패치·덮임 조건 미채택과는 다르다(그 둘은 영역이 아니라 집계 값·유효 조건을 바꿨다). 입력 창(I4)은 재추출이 필요하고, head 쪽 제한은 저장 특징으로 할 수 있어 비용이 낮다. 다만 01 G3 위치 정본이 정해지기 전에는 끝점 주변의 범위를 정할 근거가 없다.
- **03 I3(배경 표준화) 보완.** 04가 오탐 쪽 근거를 약화했다. 모델 쪽에서 보면 배경 픽셀은 최대값 집계의 후보 패치를 늘린다. I3를 한다면 M2의 입력 보류 규칙과 겹치는 구역(끝 잘림·테두리 없음)을 빼고 비교해야 효과가 섞이지 않는다.
- **05 4-4 "400장은 측정 전용, A/B와 분리" 보완.** 후보를 점수 공개 전에 동결하면 한 번의 사용으로 측정과 A/B를 같이 할 수 있다. D3 첫 시험이 그렇게 했다. 다만 05의 지적대로 감지력(`size.py`)이 0.80 미만이면 A/B는 하지 않는다. (가)/(나)는 사용자 결정으로 남긴다(M3).
- **05 S5(구역 단위 주 지표) 동의, 보완.** 보류 출력(M2)을 쓰면 "같은 확신 누락에서 보류 비율"이 문턱 이동과 섞이지 않는 모델 비교 지표가 된다. 단일 문턱 누락·오탐만 쓰면 보정·문턱 변경이 개선처럼 보인다.
- **02 L1(판정 주체 관문) 동의.** M1·M3는 v2 표본에 기대므로 11-27 재대조 결과가 B·C면 둘 다 멈춘다(4절 분기).
- **01 G1(판단 불가 상태) 보완.** 판단 불가를 학습하는 모델(M6)은 G1 화면으로 쌓인 사람 상태 없이는 만들 수 없다. 합의 실험의 "애매" 193구역은 주체가 AI·미확인이라 대신 쓸 수 없다(`corner-consensus-experiment-20261121.md:3`).

## 6. 다음 담당에게 넘기는 질문·미확인 사항

- 사용자 결정 필요: M1 규칙(A 누락 상한 / B 같은 오류), M3에서 ρ로 사람 정상 라벨을 확률적으로 다루는 것, M3 자료 방식(가)/(나), M2 보류 출력의 운영 문구 반영 여부.
- 미확인: v2 판정 주체(11-27 재대조), 정상 묶음 손실이 숨은 미세 결함 패치를 실제로 누르는지(패치 단위 기울기 미측정), 백본 미세조정의 효과(시도 기록 없음), MLP ReLU 실행 실패의 원인(`error_kind: child_exit`만 확인).
- 미확인: 운영 릴리스(후보 E)와 개발 기준(네 배치 평균)의 새 기준 v2 AUC 차이. 이번에는 네 배치 평균만 쟀다.
- 미확인: 엣지·표면 head는 같은 손실 계열(`max_bound`)인데, 같은 단방향 기준 변화가 있는지 측정이 없다(엣지 구역 재판정 0건, 02 2-5).
- 다음 담당에게: M1·M2·M3의 사전 기록을 결과 전에 커밋할 방법(이 체인은 commit 금지라 첫 저장뿐이다).
