## 08의 핵심 결론 5줄

1. 지금 개발 자료(942구역)로 낼 모델 가설은 없다. 모델 쪽 근거 오류는 6/178구역으로, 라벨 흔들림 폭보다 작다.
2. 첫 병목은 정답이다. 사람 정답이 증명된 모서리 시험 자료가 없다(A2·B2는 AI 최종 파일과 64/64 동일, 재대조함). 옛 정상의 37%는 현행 기준에서 결함이다.
3. 지금 바로 할 일은 기록 도구 5개다(판정 주체 관문·제외 건수·층×점수 구간 표·사진 묶음 통계·연속 미달 계수). 병렬로 구현할 수 있다. 정확도가 바뀌지는 않는다.
4. 막힘은 11-27 v2 판정 주체 재대조, 흰 흔적 기준 결정, 새 화면 변경 승인, 독립 사람 자료 400장 승인이다(160장은 부족, 재계산으로 확인).
5. 모델 개선 후보(단방향 잡음 보정 M3, 배경 표준화 I3는 누락 기준만)는 400장으로 현재 모델을 1회 측정한 뒤에만 시험한다.
