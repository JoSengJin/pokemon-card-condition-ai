# 04. ML 오류 분석 — 누락·오탐 행 단위 원인 분류 (2026-11-26, Claude)

범위: 저장된 점수·라벨·측정 기록을 읽고 python으로 세는 일, 이 문서 작성만 했다. 학습·새 추론·모델 비교 실행·라벨 수정·사진 열람·외부 AI 호출·`./develop`·`./experiment`·`./review`·commit은 하지 않았다. 다른 파일도 고치지 않았다. 자기 일치도 새 1차 답(`artifacts/self-agreement-split-20261126/out1/`)은 눈가림을 지키려고 열지 않았다. 독립 350장·봉인 468장 원자료는 승인 범위 밖이라 열지 않았다.

**결론 3줄**
1. **오탐 89구역 중 모델 쪽 근거는 1구역뿐이다. 무작위 표본에서는 모델이 표시한 옛 정상 구역의 10/12(83%)가 새 기준 사람 기록 재판정에서 결함이었다.** 모델이 표시하지 않은 옛 정상 구역은 25/82(30.5%)였다. 새 기준(v2)으로 보면 같은 표본의 오탐은 2/59(3.4%)다. 지금 오탐의 상당 부분은 라벨 기준(느슨→엄격) 쪽일 가능성이 크다. 다만 표본은 12구역이다(Wilson 95% 55~95%).
2. **누락은 라벨 쪽 근거가 0구역이다.** 눈가림으로 섞은 옛 결함 25구역은 새 기준에서도 25/25가 결함이었고, 그중 모델이 놓친 8구역은 모두 사람 기록으로 결함이 확인됐다(뚜렷 5). 누락에서는 입력·촬영 쪽 의심(18)과 작동점 근처(21)가 근거 있는 묶음이다. 나머지 40구역은 판단 불가다.
3. **03의 배경 층 수치는 정확히 재현된다. 그러나 03의 라벨 쪽 해석("밝은 배경 정상 라벨에 놓친 결함")은 이 자료에서 지지되지 않는다.** 무작위 재판정에서 새 기준 결함 비율은 밝은 배경 20/59(33.9%), 어두운 배경 15/30(50.0%)로 방향이 반대다. 어두운 배경 오탐 중 재판정된 6구역은 6/6이 새 기준 결함이었다. 어두운 배경 오탐이 많은 이유 중 일부는 테두리·배경 경계선이 아니라 진짜 흔적일 수 있다(탐색).

### 2-4. 사람 판정 원문과 AI 산출 동일 여부 (02 발견의 행 단위 적용)

### 2-5. 정확도를 막는 원인 요약

1. **정답 기준의 한 방향 변화가 오탐을 부풀린다**(근거: 2-2절 무작위 표본). 모델 가설로 줄일 대상이 아니다.

## 4. 설계 (상위 3개)

### 설계 E1: 이중 기준 오탐 보고 (변경 변수: 보고 형식 하나. 모델·라벨·문턱 불변)
- 입력: 평가 점수, v1 target, `overlay-v2.json` 중 `select.py`로 뽑힌 무작위 119구역(정상 94 판정 가능 + 눈가림 결함 25). 오류에서 골라 넣은 8구역(`overlay.json`)은 섞지 않는다.
- 출력 칸(사전 고정): ① v1 전체 누락·오탐(분모 401/541), ② 무작위 표본의 v1 대비 오탐(12/94), ③ 같은 표본의 v2 대비 오탐(2/59)과 v2 대비 누락(25/35 + 8/25), ④ 각 Wilson 95% 구간.
- 판정 규칙(사전 고정):
  1. 두 모델의 오탐 차이를 개선으로 쓰려면 ①과 ③이 같은 방향이어야 한다. ①만 줄고 ③이 그대로거나 늘면 "옛 기준 맞춤, 개선 아님"이다.
  2. ③ 분모(59)에서 2구역 이하 차이는 짝지은 정확 검정으로 구분할 수 없다고 적는다(`accuracy-evidence-methods-20261125.md:25`).
  3. 11-27 재대조에서 v2가 AI 동일이면 ②·③ 칸을 지우고 "정식 값 없음"이라고 적는다.
- 검증: 현재 기준 모델로 ② 12/94, ③ 2/59, v2 결함 표시 10/35가 재현돼야 한다(T3 값).

### 설계 E2: 새 독립 사람 시험 자료의 사전 층 (변경 변수: 평가 기록 형식 하나)
- 층(사전 고정): 배경 = `measure.py` 상태(상수 변경 금지, SHA `e49d2c2f…`와 대조), 원본 px/mm = <10 / 10~15.3 / ≥15.3, 끝 잘림 여부, 흰 크기 = 0 / 0~0.26 / 0.26~0.5 / ≥0.5mm(측정 가능 구역만), 사람 상태 = 정상·결함·판단 불가·미확인(01 G1), 판정 주체(02 L1).
- 장수 기준(계산): 비율 약 0.3을 ±0.08(95%)로 재려면 층당 결함·정상 각 약 126구역이 필요하다(n = 1.96² × 0.3 × 0.7 / 0.08²). 배경 두 층이면 결함 약 252·정상 약 252구역이다. 모서리 4구역/장, 결함 비율 약 0.4를 가정하면 약 160장이다(가정: 개발 자료의 구역 비율을 옮김). 모델 A/B 판정 장수는 `size.py`로 따로 계산한다(PB·PC 근거가 생긴 뒤).
- 분류: 이 문서의 1~6 규칙을 그대로 쓰고, 결과를 보기 전에 커밋한다.
- 금지: 모델 점수로 사진을 고르지 않는다(무작위 또는 수집 순).

### 설계 E3: 작동점 대역 분리 (변경 변수: 보고 칸 하나)
- 칸: 점수 <0.4 / 0.4~0.5 / 0.5~0.6 / ≥0.6별 누락·오탐 수. 현재 값은 누락 63/26/0/0, 오탐 0/0/35/54다.
- 규칙: 문턱만 바꾼 비교는 "기준 진단"으로 적고 누락·오탐을 함께 보고한다. 같은 모델의 문턱 이동을 다른 모델의 개선과 비교하지 않는다. 카드 단위 고정 작동점(0.6/0.2, worker `fixed_low`)과 구역 0.5를 같은 표에 섞지 않는다.
