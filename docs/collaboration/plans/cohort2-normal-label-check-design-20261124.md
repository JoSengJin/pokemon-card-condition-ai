### ④ D3 주 라벨 버전과 분모가 바뀔 때의 비교 규칙
| 선택지 | 내용 |
|---|---|
| **v1 주, v2 병행 (추천)** | D3 통과 판정과 진척 점수는 봉인 때 고정한 v1(262/206)로만. v2는 사전 지정 병행 지표로 각자 분모와 함께 보고 |

| 둘 다 통과해야 통과 | 가장 보수적 |

추천 이유: v1 통과선은 봉인 때 고정됐고, v2는 한 명이 목적을 알고 만든 층이며 정상 분모가 작아지면 통과 한도가 급히 줄어든다(정상 100장이면 오탐 13장까지, 60장이면 6장까지, 40장이면 3장까지). v2 주를 기각하는 이유: 진단 결과를 보고 주 정답을 바꾸는 모양이 되고(점수 전이라도), 배점 조건 변경은 별도 명시 승인 사항이다. v2가 통과하고 v1이 미통과면 그대로 "v1 미통과, v2 병행 통과"로 쓰고 진척은 올리지 않는다.

비교 규칙(선택과 무관하게 고정 제안):
- v1과 v2 수치는 분모·정답이 달라 %p 차이나 "개선·감소"로 쓰지 않는다. 각자 `k/n`과 Wilson 구간을 나란히 적는다.
- 허용하는 연결은 같은 206장의 교차표뿐이다: v1 오탐 카드 k장 중 v2에서 결함 카드로 바뀐 장수(재분류 장수로 표기).
- 후보 간 비교(E·현 평균·개선 후보)는 같은 라벨 버전 안에서만 한다.
- v2에서 결함 카드가 된 이전 정상 카드는 v2 결함 분모에 더한다(놓침 판정은 새로 찾은 결함 모서리 기준). 기존 결함 262장의 정상 모서리는 다시 보지 않으므로 v2 놓침은 그 카드들에서 v1 모서리 기준이고, 결함 모서리가 늘면 놓침은 줄기만 하므로 보수적인 값이다.
- 판단 불가로 정상·결함을 정하지 못한 카드는 v2 분모에서 빼고 장수를 공개한다. 1차 350장·개발 자료와는 계속 비교하지 않는다.

## 3. 점수 열람 전 사전 고정 체크리스트 (단계 2에서 문서화, 판정 전 커밋)
1. 표본 규칙: 풀(정상 206, 묶음 134/72), 시드, 정렬·섞기 순서, 1단계 장수, 선정 결과를 보기 전 규칙 커밋, 선정 파일 SHA256.
2. 눈가림: 출처·개수·카드당 구역 수, 기준점 사용 여부, 주 분석과 분리 보고.
3. 화면: 입력 4종(정상/미세/뚜렷/판단 불가), 안내문 문구(개발 재판정과 같은 문구), 구역 섞기, 화면 분할 수, 숨기는 정보, 결과 끝의 화면 식별자·제출시각, 화면 파일 SHA256.
4. 주 지표: 정상 카드 중 하나라도 미세/뚜렷인 카드 비율(Wilson 95%). 카드 판정 규칙: 하나라도 미세/뚜렷이면 결함 카드, 네 모서리 모두 정상이면 정상 카드, 결함 없이 불가·미판정이 있으면 판단 불가 카드(분모 제외, 장수 공개). 제외 때문에 비율이 위로 쏠리므로 제외 카드를 전부 정상으로 본 하한값을 함께 보고.
5. 분모 하한(제안: 판정 가능 카드 30장 미만이면 미측정, 묶음별 15장 미만이면 장수만)과 해석 규칙의 수치 구간, 1단계 뒤 계속·중단 규칙.
6. 보조: 묶음별(134/72), 판정 절차 시기별(149/57, 가정 표시), 미세/뚜렷 분해, 구역 단위 비율, 화면별 차이, 눈가림 결함의 정상 판정 비율, 기준점 일치율.
7. 판정 주체 기록: "사람이 직접 판정함" 문장이 있을 때만 사람 라벨, 없으면 "사용자 붙여넣기, 사람 직접 판정 미확인"으로 기록하고 한 줄 확인 요청.
8. v2 동결: 대상 범위(정상 206만), 파일 위치(봉인 폴더 밖), 값(정상/결함, 심각도는 별도), 판단 불가 처리, SHA256 기록, 동결 뒤 수정 금지.
9. v1·v2 동시 보고 규칙(§2 ④)과 D3 주 버전, 봉인 기준 문서·T5 문서에 대한 보충 문서(원문은 고치지 않음).
10. 금지 재확인: 봉인 파일·기존 라벨 수정, 점수 생성·열람, 468장의 학습·튜닝·임계 선택 사용, 점수 뒤 기준·후보·층 변경.

## 4. 위험·한계
- 한 명의 판정, 목적을 아는 판정. 이전 화면(사진 전체)과 새 화면(확대 크롭)의 제시 방식 차이가 결과에 섞인다. 기준 변화와 이전 라벨의 느슨함을 가를 수 없다.
- 봉인 라벨의 판정 주체·절차가 파일로 확정되지 않는다(§1 (a)). 결과 해석에서 "사람 라벨의 자기 일치"로 쓰지 않는다.
- 판정자가 봉인 사진을 다시 본다. 점수는 없으므로 평가 독립성에는 영향이 없다고 보지만, 이 판정 뒤 468장을 본 기억으로 모델·임계를 고치지 않는다는 금지는 그대로다.
- 봉인 기준 문서 §1과 표준 초안 Q4는 "재라벨 없음"이다. 선택 (b)는 이를 다시 여는 것이므로 사용자의 명시 승인과 보충 문서가 필요하다.
- 개발 자료 구역 상자 8/225가 같은 식과 다르다(원인 미확인). 크롭이 개발 재판정과 완전히 같다고 주장하지 않는다.

## 5. 검증·롤백
- 실행: 봉인 SHA256 대조(일치), 출처 핀 116개 대조(불일치 0), 사진 2,203개 원본 SHA256 대조(불일치 0), `region_box` 468×4 계산(오류 0), 분포·Wilson·통과 한도 계산. 확인 스크립트는 저장소 밖 임시 폴더에서 읽기 전용으로 실행(종료 코드 0), 저장소 파일 변경은 이 문서뿐.
- 안 한 것: 사진 내용 열람, 복호 해시 재계산, 크롭 생성·렌더, 화면·스크립트 작성, 사전 등록, 사용자 판정 요청, 모델 점수 관련 작업 일체, HTML 보고(모델 평가·성과 변경 없음).
- 롤백: 이 문서 커밋 revert.
