### 제안값을 적용했다면 보인 것

- 규칙 대상 7행 중 분모·카파가 모두 측정된 행은 4행이다(40곳, 30곳, 45구역, 36구역). 이 중 경고선 아래는 1행(40곳, 구 기준), 경고~목표 사이는 1행(30곳), 목표선 이상은 2행(모서리 B 재판정, 주체 미확인·기억 효과·선택 편향 단서 있음).
- 같은 칸의 값도 기준이 바뀌면 다시 재는 대상이다(40곳 구 기준 → 30곳 새 기준은 합쳐 비교하지 않는다. `label-ceiling-20261121.md:3`).
- 주체 미확인 문제: 규칙에 "판정 주체 확인 여부를 함께 적는다"를 넣어야 위 표처럼 읽힌다. 확인 문장이 없는 값은 "미확인 주체"로 표시하고 목표·경고 판정은 참고로 둔다.
- 카파의 95% 구간이 선을 걸치면(예: 30곳 0.617 [0.328, 0.868]) 점추정으로 판정하되 구간을 함께 적는다.
- 틀릴 조건: 0.80·0.60은 일반 관례일 뿐이다. 표본이 30~45라 구간이 매우 넓어(위 표) 선 근처 값은 우연일 수 있다. 사용자가 더 엄격·느슨한 선이나 다른 최소 분모를 정하면 숫자만 바꾼다.

## 2. 연속 미달 (`stop-repeated-misses`)

제안: 3(ECC 원문 값). 대안 5, 값 없음(횟수 기록만). **같은 평가 자료(`cohort_sha256`)에서 모델 가설이 사전 기준에 연속으로 못 미친 횟수가 값에 닿으면 그 평가 자료로 새 모델 가설을 내지 않는다.**

### 센 방법

읽은 곳: `artifacts/experiments/*/{record,reference,plan,result}.json`(272개 폴더, 기록 상태 completed 222·failed 48·interrupted 2). `reference.cohort_sha256`로 묶고 `record.started_at` 순. `record.status=completed`이고 `plan.experiment_kind != "diagnostic"`인 것만 세고 통과 여부는 `result.acceptance_passed`(true 통과, false 미달)를 썼다. 실패·중단 실행과 `diagnostic` 종류는 뺐다. 세어진 실험은 181개(45개 평가 자료)이고, 그 중 계획에 `experiment_kind`가 없는 29개는 모델 실험으로 셌다(272개 전체로는 종류 없음 31개·평가 자료 48개). 아래 표의 평가 자료들에서 `acceptance_passed`가 없는 완료 실험은 0개였다.

**주의: 통과 기준은 계획마다 다르다.** 같은 평가 자료 안에서도 허용 오류(`acceptance`)가 계획마다 달라 "통과"의 뜻이 같지 않다.

"막혔을 실험"은 그 실험을 시작할 때 이미 연속 미달이 값 이상이었던 것의 수다. 값 없음이면 막힌 것이 없다. 이 열은 실제 이력에서 연속 미달이 이미 값 이상인 채 시작된 실험만 센다. 규칙을 엄격히 적용했다면 그 뒤 같은 평가 자료의 모든 실험이 막혔을 것이므로 실제 효과는 더 크다. 세어진 45개 평가 자료 중 지금 연속 미달이 3 이상인 것은 6개, 5 이상은 5개다.

### 읽는 법

- **긴 미달 뒤 통과가 있었다.** fdb90e18은 21번 연속 미달한 뒤 통과했고, 이어서 3번 연속 통과했다. 값이 3이든 5든 이 통과(21번 뒤)는 막혔을 것이다. c85a4ae4의 두 통과도 값 3·5 모두에서 막혔다. 이 통과들이 우연인지, 기준 차이인지, 실제 향상인지는 이 자료로 구분하지 못한다. 원인을 단정하지 않는다.
- **기준 차이가 섞여 있다.** fdb90e18의 통과 4개는 미달 33개와 같은 기준(`max_fp 2, max_fn 0`, 실제점 보호)이다. c85a4ae4의 통과 2개는 각각 더 느슨한 기준(`max_fn 28, max_fp 69`)과 다수 미달과 같은 기준(`max_fn 18, max_fp 59`)이고, 앞의 것은 종류가 `diagnostic_geometry_sensitivity`다. 2167feaf의 통과 3개는 `max_fn 405, max_fp 541`로 같은 평가 자료의 미달 4개(`max_fn 18, max_fp 59`)와 기준이 다르다. 그래서 "연속 미달 뒤 통과"를 값 선택의 근거로 쓰기 어렵다.
- 값을 크게 잡으면 막는 횟수가 줄고 기준이 다른 통과도 덜 막는다. 값이 작을수록 헛도는 시도를 일찍 멈추지만 우연한 통과 기회도 일찍 막는다. 이 표로 어느 값이 정확도를 높인다고 말할 수는 없다.
- 세는 방식(진단 종류 제외 범위)을 `diagnostic`만 vs `diagnostic`·감사류 모두로 바꾸면 달라지는 것은 c85a4ae4(완료 21 → 20, 막힘 15(2) → 17(1))와 fdb90e18(39 → 37), af70b99a(16 → 15) 정도다.

### 소급 여부

- **권장: 과거 미달은 세지 않고 승인 뒤 새 실험부터 0으로 시작한다.** 이미 판정한 과거 실험에 새 규칙을 씌우면 진행 중인 평가 자료가 바로 막힌다.
- 소급하면 위 표의 "지금 연속 미달"이 값에 닿아 즉시 막히는 평가 자료는 값 3에서 6개(fdb90e18 14, 2f409466 22, af70b99a 16, 0a93f917 9, f8868be1 8, 10a91d0b 3), 값 5에서 5개(10a91d0b 제외)다. 어느 평가 자료가 지금 개발에 쓰이는지는 이 조사에서 확인하지 않았다.
- 틀릴 조건: 연속 미달이 같은 원인(예: 라벨 잡음)에서 나온다면 3이든 5든 모델 가설을 멈추는 것이 맞고, 미달마다 서로 다른 변경을 시험한 것이라면 더 일찍 멈추는 것이 탐색을 막는다. 이 자료로는 원인을 구분하지 못한다.
