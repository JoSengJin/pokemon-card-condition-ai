# 후면 모서리 A/B 독립 시험 규칙 (결과를 보기 전 고정, 2026-11-24)

이 문서는 규칙이며 시험·실험·자료 사용을 승인하지 않는다. 어떤 카드 묶음을 쓸지와 아래 `<사람>` 값은 사용자가 정한다.
용어: A=기존 모델, B=후보. 놓침=결함 카드의 결함 구역 점수가 전부 낮은 임계값(0.20) 미만. 잘못 표시=정상 카드의 어느 구역이든 높은 임계값(0.60) 이상. 중간=카드 점수(결함 카드는 결함 구역 최고점, 정상 카드는 전 구역 최고점)가 0.20 이상 0.60 미만. b=A는 아닌데 B만 해당(나빠짐), c=A만 해당(좋아짐). 카드 규칙은 `tools/experiments/corner-mlp-head-20261121/worker.py`의 `card_miss`와 같다.

1. 독립 자료. 시험 카드는 카드(group) 단위로 A·B의 학습, 조기 종료, 임계값·모델 선택, 과거 어떤 비교에도 쓰이지 않았어야 한다. 같은 카드의 다른 사진이 개발 자료에 있으면 뺀다. 정답은 모델 출력을 보지 않은 사람이 추론 전에 확정한 것만 쓴다.
2. 정답 미확인. 모든 구역의 정답이 확정된 카드만 목록에 넣는다. 미확인 구역을 정상·결함으로 채우지 않는다. 뺀 장수를 사전 기록에 적는다. 결론은 "정답을 확정할 수 있었던 카드"에만 해당한다. 채점 뒤에는 정답을 고치지 않는다.
3. 사전 기록(채점 전에 커밋). 카드 목록과 정답 파일의 SHA256, 정상·결함 카드 실제 장수, A·B 가중치와 추론 코드의 SHA256, 임계값(기본 A·B 모두 0.20/0.60), 주 지표, Δ=`<사람>`, Δm=`<사람>`, 가정한 A 오류율과 (pb, pc)(pc는 A 오류율을 넘을 수 없다), 실제 장수로 `size.py`가 낸 감지력·통과 확률·`false_pass.max`, 두 문 통과 확률의 곱, 비열등 임계값(규칙 4), 이 문서의 SHA256.
4. 문 세 개. 셋 다 통과해야 "개선 확인" 문장을 쓴다.
   4-1 주 지표(하나): 정상 카드의 잘못 표시. 양측 정확 McNemar p<0.05 이면서 c>b.
   4-2 놓침 비열등: 결함 카드에서 귀무가설 pb−pc ≥ Δ. Tango 점수 통계량 z ≤ −임계값이면 통과.
   4-3 중간 띠 보호: 전체 카드에서 "중간"에 대해 귀무가설 pb−pc ≥ Δm. 같은 검정.
   임계값: `size.py noninferior <실제 장수> <한도> <한도> 0 --crit <값>`의 `false_pass.max`가 0.05 이하가 되는 첫 값. 1.6448536269514722에서 시작해 1.65, 1.66, …으로 0.01씩 올린다. 4-2와 4-3 각각 정한다.
5. 시험 1회. 한 번의 시험은 사전 기록 하나, 후보 하나, 채점(점수를 정답과 맞추는 일) 한 번이다. 추론은 채점 전에 끝낸다. 추론 재실행은 종료 코드가 0이 아니거나 점수가 빠진 카드가 있을 때만, 동결값 그대로, 채점 전에만 한다. 모든 실행의 시각·명령·종료 코드를 남기고 지우지 않는다. 채점 뒤에는 Δ·임계값·카드 목록·검정·주 지표를 바꾸지 않는다. 부분집합 재분석과 부가 수치는 기술용이며 결론을 바꾸지 않는다.
6. 미측정(수치를 성능으로 말하지 않는다). 사전 기록 없음, SHA 불일치, 독립 조건 위반 카드 포함, 실제 장수가 기록과 다름, 재실행 뒤에도 점수가 빠진 카드 존재(카드를 빼고 계산하지 않는다), 채점 전 정답과 출력을 함께 봄, 두 번째 채점.
7. 봉인 보호. 채점한 카드는 "사용됨"으로 기록한다. 이후 학습·임계값·모델 선택에 넣지 않으며, 같은 카드로 다른 후보를 다시 비교하면 독립 시험이 아니라 개발용 비교로만 적는다.
8. 결론 문장(아래 밖의 문장은 쓰지 않는다). 모든 경우에 문마다 b, c, 장수, p 또는 z, 두 모델의 비율을 함께 적는다.

| 4-1 주 지표 | 4-2 놓침 | 4-3 중간 띠 | 문장 |
|---|---|---|---|
| 감지 | 통과 | 통과 | 개선 확인: B는 잘못 표시를 줄였고, 놓침은 Δ, 중간 띠는 Δm 이상 나빠지지 않았다. 채택 여부는 사람이 정한다 |
| 감지 | 하나라도 미통과 | | 잘못 표시는 줄었으나 미통과 항목의 악화를 배제하지 못했다(나빠졌다는 뜻이 아니다). 채택 근거 없음 |

| p<0.05 이면서 b>c | 무관 | 무관 | B가 잘못 표시를 늘렸다 |

한계: 장수는 가정한 pb·pc가 맞을 때만 유효하다(개발 자료 9/81·5/175는 독립 값이 아니다). 카드끼리 독립이라고 가정했다(같은 묶음·촬영 조건이 함께 틀리면 감지력은 더 낮다). 사람 정답의 오류는 반영하지 않았다. 중간 띠 문은 다른 두 문과 같은 카드를 쓰므로 세 문 동시 통과 확률은 두 문의 곱보다 작고 계산하지 않았다. 정상 구역과 결함 구역이 섞인 카드는 결함 카드로만 센다.
