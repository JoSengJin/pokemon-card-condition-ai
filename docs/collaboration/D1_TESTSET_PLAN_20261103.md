# D1 독립 시험셋 구성안 (2026-11-03, 사용자 승인: 지원 범위만 D1에 포함)

## 해석(사용자 승인 2026-11-03 "권장 1번")
D1의 "각질문/앞뒤별"은 현재 지원 범위(verified·재정의된 칸)만 뜻한다. 미지원 칸(앞면 엣지·모서리·표면·관찰제한)은 D1 분모에 넣지 않고 "미지원"으로 공개한다. 이 해석은 기준 본문을 바꾸지 않으며 D1 증거 문구에 해석을 명시한다. 기준 문서(v1.10) 수치·배점은 불변.

## 칸(셀)과 요건
각 칸에서 양성·정상 각 ≥30 **실물**(카드). 실물은 앞뒤 한 쌍, 같은 카드의 사진은 한 그룹.
| 칸 | 면 | 양성 정의(실물 단위) | 라벨 도구 |
|---|---|---|---|
| 엣지 | 뒷면 | 엣지 구역 하나 이상 결함 | `tools/ebay_back_edge_review_pages.py`·기존 엣지 라벨 흐름 |
| 모서리 | 뒷면 | 모서리 네 곳 중 하나 이상 결함 | `tools/mobile_corner_label_pages.py` |
| 표면 | 뒷면 | 표면 구역 하나 이상 결함(정의: 긁힘·뜯김·접힘·눌림·얼룩; 화이트닝·엣지·모서리 마모 제외) | `tools/mobile_surface_label_pages.py` |
| 관찰 제한 | 뒷면 | 사람 라벨 '제한' | `tools/mobile_visibility_label_pages.py` |
| 센터링 | 앞면 | 사람 센터링 결함 라벨 | (라벨 페이지 신규 필요; 이진 정상/결함/미확인) |
센터링 칸은 v1.9 C4가 미충족(pending)이라 D2 통과 대상이 아니다. D1에는 포함하되 C4가 풀리지 않으면 이 칸은 "시험셋 보유, 후보 없음"으로 보고한다.

## 규모(추정, 실제 비율은 라벨 후 확인)
뒷면 구역 결함 비율이 낮은 표면(카드 단위 약 20~30%)이 병목이라 약 130 실물(쌍)이 필요하다. 관찰제한은 약 26%(§79), 모서리는 약 55%(§72)로 이미 충분. 쌍 확정률 약 60~80%이므로 후보 약 180건 수집. 이미 수집되어 미사용인 ax(30건)를 포함한다.

## 단계(사람 입력 위치)
1. 수집(코드, eBay 수집 전용): ax + 새 intake. 기존 모든 intake·학습 자료는 `--reference-learn`으로 제외. `HOLDOUT.md`에 D1 전용 선언.
2. **사람**: 앞뒤 짝 확인 페이지.
3. 코드: 인벤토리·자동 상자 제안(`autobox.py`, 사람 확인 전 상자). **사람**: 카드 영역 확인(필요 시), 칸별 라벨 페이지(엣지·모서리·표면·관찰제한·센터링).
4. 코드: 칸별 양성/정상 실물 수 집계. 부족한 칸은 추가 수집.
5. 봉인: 사진/정답/그룹 SHA, 사용 이력, 세부유형·촬영조건 표를 담은 manifest를 만들고 커밋(`artifacts/d1-testset-*/SEALED.json` + 사본). 봉인 이후 개발·모델 선택·임계 설정·원인 분석에 쓰지 않는다. 한 번 보면 이후 후보에는 재사용하지 않는다(D2 규칙).

## 위험·한계
- 라벨은 한 사람, 같은 eBay 계열 → 일반화 한계. 앞면(미지원 칸)은 D1 분모 밖.
- 봉인 manifest는 코드로 변조를 막지 못하고 SHA·커밋으로 감지한다.
- 이 단계는 점수를 바꾸지 않는다(D1 pending 유지). 점수 +5는 봉인 manifest가 D1 완료 조건(칸별 ≥30/30·SHA·이력·표)을 모두 만족할 때 반영한다.
