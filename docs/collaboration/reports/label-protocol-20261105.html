# 카드 상태 라벨 규약 — 2026-11-05 정리

대상: 앞으로 생성하는 사람 라벨 안내. 기존 답·라벨·실험·평가 결과를 새 정의로 다시 해석하지 않는다. 현재 모델은 후면 점검/재촬영 우선순위 도구이며 앞면·센터링은 미지원이다. 라벨의 결함 표시와 모델의 우선순위 높음은 서로 다른 정보다.

## 위치로 먼저 구분하기

| 살펴볼 곳 | 결함으로 표시할 것 | 그 항목에서 제외할 것 |
|---|---|---|
| 표면: 카드 인쇄면 안쪽 | 긁힘·뜯김·눌림·구김·접힘·얼룩·인쇄 외 자국, 면 위의 흰 마모 자국(화이트닝) | 옆면 테두리의 백화만 있는 경우, 둥근 귀퉁이 끝의 마모만 있는 경우, 카드 밖 배경·홀로 반사·인쇄 무늬 |
| 엣지: 카드의 바깥 테두리선/옆면 띠 | 해당 위치의 마모·백화·찍힘·들뜸 | 둥근 귀퉁이 끝만의 손상, 면 안쪽 기스·오염 |
| 모서리: 네 귀퉁이의 둥근 끝 | 해당 위치의 뭉개짐·찍힘·백화·접힘 | 근처 직선 테두리만의 마모·백화, 면 안쪽 기스·오염 |

**‘화이트닝’이라는 단어만으로 정상/결함을 결정하지 않는다. 위치와 실제 보이는 자국을 함께 본다.** 면 안쪽 흰 마모 자국은 표면, 옆면 테두리 백화는 엣지, 둥근 끝 백화는 모서리다. 반사인지 실제 마모인지 구분되지 않으면 판단 불가/미확인이다. 모델 점수나 흰색 픽셀만으로 손상을 추정하지 않는다.

예시: 한 칸에 옆면 백화만 있고 인쇄면은 충분히 확인해 깨끗하다면 그 칸의 ‘표면’은 정상이다. 이는 카드 전체/엣지가 정상이라는 뜻이 아니다. 칸이 모서리까지 걸쳐 있다는 이유만으로 표면 결함을 누르지 않는다.

## 정상·결함·불확실을 구분하기

- 결함: 이 항목이 대상으로 삼는 위치에서 손상/자국을 확인했다.
- 정상: 충분히 확인한 해당 위치에 이 항목의 결함이 없다. 전체 카드 정상이나 공식 등급을 뜻하지 않는다.
- 판단 불가: 확대해도 반사/손상 구분이 안 되거나 가림/흐림 등으로 판단할 수 없다. 전용 선택지가 없는 기존 화면에서는 미확인으로 남긴다.
- 미확인: 아직 보지 않았거나 판정하지 않았다. 정상으로 자동 해석하지 않는다. 화면별 저장 문자열은 기존 형식을 유지한다(예: ‘불가’/‘판단 불가’).
- 전체 정상 버튼은 해당 구역을 전부 실제로 확인한 뒤에만 누른다. 상자 확인은 구역 상태 확인과 별개다.
- 평소 확대 기준으로 관찰하되 사진에 없는 사실을 추정하지 않는다. 확대가 새 원본 세부정보를 만들어 주는 것은 아니다.
