## 1. 판정 질문과 위치 규칙
결함 있음 / 결함 없음 / 판단 불가. 위치 정의는 `LABELING_PROTOCOL.md` 표면 행 그대로(엣지 백화·모서리 마모·카드 밖·홀로 반사·인쇄 무늬 제외). 심각도는 묻지 않는다. 항목마다 "판단 불가 사유" 선택(반사/카드 밖/보이지 않음/기타, 분석용 기록).
- **카드 밖(`card_off`)**: `rows2.json`에서 `bad` 또는 `center_out`인 구역. 별도 표시하고 표본에 포함(칸 층화는 유지). 판정 화면에서는 보통 구역과 똑같이 보이며 "판정할 인쇄면이 없으면 판단 불가"로 처리. 합의 후 `card_off` 판단불가는 별도 개수로 보고하고 분모에서 뺀다. **정상/결함으로 추정해 채우지 않는다.**
- **판단 불가 처리**: 판정자 개인의 판단 불가는 alpha의 제3범주로 그대로 센다. 합의에서는 §6.

- **갤러리 구역의 사진 그룹 전체를 평가 모집단에서 먼저 제외**한다(추출 이전).

## 3. 표본 (seed 고정 20261112)
- 모집단: 기준 직접 알파0 `20261108T215307-941b3aaa/observations.json` 1776곳 − 갤러리 사진 그룹. 칸 = target × (점수≥0.5): TN 1239 / FP 167 / FN 57 / TP 313.
- 칸 층화 무작위 추출, **단계(파일럿·본)별 사진 그룹당 최대 1구역**. 파일럿과 본 판정은 **구역이 겹치지 않는다**(사진 그룹은 단계 사이에 겹칠 수 있음. 그룹이 204개뿐이라 파일럿 40 + 본 160을 그룹 비중복으로 만들 수 없음).
- 사실 확인(읽기 전용, 2026-11-12): 칸별 구역/그룹 수 = TN 1239/193, FP 167/92, FN 57/44, TP 313/108. FN 칸은 그룹이 44개라, 갤러리 제외 후 본 40이 안 채워지면 같은 단계 내 `group_repeat` 구역을 쓰고 표시한다(그룹 단위 부트스트랩으로 반영).
- 칸 크기 가중 추정: 구역 가중치 = 칸 크기 / 칸 표본 수. 사전 지정 주 alpha는 **가중하지 않은 표본 alpha**(도구의 판정 재현성), 칸 가중 alpha는 보조(오류 칸 과대표집 효과 확인용).
- 기존 재판정·구역 평가·심각도·후보 판정에 쓴 구역은 **제외하지 않고** `prior_used`(사용 출처 목록)로 표시. 외부 판정과 비교할 때만 사용.
- `card_off` 표시, 칸 라벨은 분석 파일에만 있고 판정 화면에는 없다.

## 4. 2단계 진행
**(a) 파일럿**: 외부 판정자 ≥2명 + 원 판정자(세 번째 평가자) × 40구역(칸당 10). 진행 여부를 거르는 용도, **0.667 판정에 쓰지 않는다**(합성 반폭 ±0.14~0.16). 통과 조건(모두 충족): 외부 간 alpha ≥ 0.5, 판단 불가 ≤ 20%, 판정자가 제기한 정의 모호 지적을 모두 해결(해결 = 안내문 예시/표현 수정 기록; **문턱 문장은 바꾸지 않음**). 안내문 표현을 고치면 수정 내용과 시각을 기록하고 파일럿 구역은 본 판정에 쓰지 않는다.
**(b) 본 판정**: 외부 판정자 3명 × 약 160구역(칸당 약 40). 규모 근거는 아래 합성 시뮬레이션(**합성**).

## 6. 지표와 합의
- **주 지표**: 외부 판정자끼리 Krippendorff alpha(3범주, 명목). 보조: 이진 alpha(결함 vs 그 외), 원 판정자 포함 alpha, 원 판정자 vs 외부 합의 일치율, 갤러리 열람별 alpha. 사진 그룹 단위 부트스트랩 95% 구간.
- **alpha ≥ 0.667이면 합의 정답 사용 가능, 미만이면 사용 불가.** 구간 하한이 아니라 점추정 기준(사전 지정). 구간은 함께 보고.
- 합의: 외부 3명 다수결. 1:1:1이거나 판단 불가 2명 이상이면 판단 불가로 분모에서 빼고 개수 보고(`card_off` 별도). 원 판정자는 합의에 넣지 않는다.
- **합의 정답이 생긴 뒤(실행은 승인 후)**: 저장 점수만으로(새 추론 없음) 직접 알파0의 FN/FP·가중 AUC를 칸 가중으로 재평가. 같은 합의로 "합의 정답을 완벽히 맞히는 모델을 원 라벨(target)로 채점할 때의 FN/FP 하한"과 95% 구간(그룹 부트스트랩, 칸 가중)을 계산. 가중 분모: FN/370, FP/1406.

## 7. 합성 시뮬레이션 (합성, 실데이터·실판정 미사용)
`tools/diagnostics/independent-judgment-20261112/sim_alpha.py`, seed 20261112, 반복 150, 부트스트랩 200, 결과 `artifacts/independent-judgment-20261112/sim_result.json`(Git 제외). 잠재 점수 모델에 판정자 잡음 SD s를 바꿔 가짜 3명 판정을 만들고 그룹=항목 부트스트랩 95% 구간 반폭을 잰다. 칸 평균(−0.6/0.2/0.4/1.3)과 판단불가 띠는 **임의 가정**이다.

| 0.5 | 0.540 | 18% | ±0.159 | ±0.110 | ±0.090 | ±0.078 | ±0.070 | ±0.064 |

- 해석(합성): 반폭 ±0.1 목표는 n≈100~120에서 도달, **160이면 ±0.07~0.08로 여유**. 파일럿 40은 ±0.14~0.16이라 0.667 판정에 못 쓴다는 설계와 일치. 이 가정에서는 판단불가가 파일럿 한도 20%에 근접하므로 실제 판단불가율이 높으면 파일럿에서 걸릴 수 있다.
- 한계: 판정자 간 독립 잡음 가정이라 실제 판정자 간 상관·비균질 항목(경계 구역)은 반폭을 키울 수 있다. 표본을 칸 균등 배분했으므로 모집단 alpha와 다르다.

## 8. 결정 규칙 표 (사전 고정)
alpha = 본 판정 외부 alpha(점추정). 합의 결함 비율 = 칸 가중. FP 하한/FN 하한 = §6의 완벽 모델 하한, 95% 구간 [L,U]. 게이트: FN ≤ 67/370, FP ≤ 112/1406. 위에서 아래로 처음 맞는 행을 적용한다.

| # | 조건 | 다음 모델 작업 (하나) | AUC +0.03 게이트 처리 |
|---|---|---|---|
| 1 | alpha < 0.667 | 이진 게이트 대신 점검 우선순위(순위) 출력으로 제품 재정의를 사용자에게 제안. 합의 정답 사용 불가 | **사용자 결정**: 순위 출력으로 바꿀 때 AUC 게이트를 유지·교체할지 |
| 2 | alpha ≥ 0.667, 합의 결함 비율 ≥ 85% | 이 문턱은 재현되지만 게이트와 맞지 않음. 문턱 정의 재설정을 사용자에게 요청 | **사용자 결정**: 재설정된 문턱에서 AUC 게이트 재기준 필요 여부 |
| 3 | alpha ≥ 0.667, FP 하한 L > 112 | 평가 정답을 합의 정답으로 교체할지 사용자 결정 요청. **그 전까지 표현 가설 재개 금지** | **사용자 결정**: 합의 정답 기준으로 AUC +0.03 게이트 재산정 |
| 4 | alpha ≥ 0.667, FP 구간 [L,U]가 112 포함 | 판단 불가. 본 판정 확대 여부를 사용자가 결정 | **사용자 결정**: 확대 판정 전까지 게이트 유지(변경 없음) |
| 5 | alpha ≥ 0.667, FP U < 112 | 현 라벨 문턱으로 게이트 달성이 원리상 가능. 표현 가설 재개 후보 제시(실행은 승인 후) | **사용자 결정**: 후보 가설의 AUC 목표를 기존 +0.03로 둘지(변경 없음이 기본값) |

**FN도 같은 방식**으로 기준 67에 적용한다(FN 하한 L>67 → 3행과 동일 처리, 구간이 67 포함 → 4행, U<67 → 5행). FP와 FN이 서로 다른 행이면 더 보수적인 행(번호가 작은 쪽)을 따르고 두 값을 모두 보고한다. FN 칸은 n=57이라 구간이 넓을 수 있으며, 구간이 0을 포함하는 퇴화 구간은 그대로 보고한다.
