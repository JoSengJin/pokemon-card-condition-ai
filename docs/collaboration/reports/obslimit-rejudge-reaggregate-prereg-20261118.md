# 재판정 반영 재집계 — 사전 고정 (결과 계산 전, 2026-11-18)

읽기 전용 재집계다. 학습·추론·사진 열람·기존 라벨 수정을 하지 않는다. 점수는 기존 OOF를 그대로 쓴다. 새 모델 성능이나 일반화 개선을 주장하지 않으며 진척 점수에 반영하지 않는다.

## 입력
- 점수·행: `artifacts/experiments/20261102T225059-98b83ef4/observations.json`(obslimit-pooled-source-20261103, 267면 OOF).
- 라벨 버전 A(기존): observations의 target. 버전 B(재판정 반영): 버전 A에서 `artifacts/obslimit-reasons-20261118/rejudge-answers-1.txt`가 `정상`인 12행만 target 1→0. `제한` 4행과 그 외 행은 그대로. 확신도는 기본값(애매)이라 쓰지 않는다.
- 버전 C(민감도): 재판정 `정상` 12행을 제거.

## 계산 (이 정의만)
1. 버전 A·B·C 각각 전체 AUC(순위 쌍, 동점 0.5), 행 수·양성 수. 같은 점수의 재집계다.
2. 같은 각 버전의 자료원별(eBay 120 / 개발 147) AUC. 재판정은 eBay 행에만 있으므로 개발 AUC는 세 버전에서 같아야 한다.
3. 사진 그룹 부트스트랩 2000회, 시드 20261118, 95% 백분위 구간. 쌍 부트스트랩으로 B−A, C−A 차이의 구간.
4. 임계 0.5에서 버전별 eBay 양성 재현율(점수≥0.5 양성/양성)과 정상 오탐률(점수≥0.5 음성/음성), 분모 명시.
5. 재판정 대상 16행 점수 분포: `정상` 12행 중 점수≥0.5 수, `제한` 4행 중 점수≥0.5 수.

## 해석 규칙 (고정, 결과로 바꾸지 않음)
- 이 재집계는 통과/미통과 판정이 아니다. v1.8·v1.10 기준(AUC ≥0.75, 하한 ≥0.60)과 증거 지위는 바꾸지 않는다.
- B와 C의 eBay AUC가 A와 구간이 크게 겹치면 "재판정이 평가를 바꿨다는 증거 없음"으로 쓴다. 차이 구간이 0을 포함하지 않을 때만 "이 라벨 변경에 민감함"으로 쓴다.
- 편향 명시: 재판정은 `not_limited`로 사람이 표시한 양성 16행에만 이뤄졌고 음성·나머지 양성은 다시 보지 않았다. 선택이 비대칭이라 B·C는 정정된 정답이 아니라 민감도 분석이다.
