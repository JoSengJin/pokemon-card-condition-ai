## 승인이 필요한 진척 기준 변경안 (아직 적용하지 않음)
현재 C1(엣지)은 "앞/뒤 각각 FN ≤5%·FP ≤10%, 실제점 누락 ≤5% 등"이다. 이 재정의에서는 C1의 판정 목표를 그대로 둘 수 없다. 제안:
1. C1의 범위를 "엣지 판정"에서 "엣지 점검 우선순위 제안(후면)"으로 바꾸고, 판정 FN/FP 수치 조건 대신 다음을 쓴다: 독립 보류 사진 그룹 ≥ 40·결함 사진 ≥ 20에서 (a) 높음 구간 결함 비율 − 낮음 구간 결함 비율 ≥ 0.40, (b) 사진 내 1위 구역 적중률이 무작위 기대보다 ≥ 0.20 높음, (c) 양쪽 결과의 95% 부트스트랩 하한이 각 기준 이상.
2. 앞면 엣지·모서리·표면·센터링·관찰 제한(C2~C5)은 변경하지 않는다(미충족 유지).
3. 점수 배점(7점)과 다른 항목 배점은 바꾸지 않는다.
- 수치 (a)(b)는 이번 개발 평가에서 본 값(구간 격차 0.61~0.68, 적중률 격차 0.32~0.36)보다 낮게 잡아 독립 시험에서 여유를 두었다. 결과를 본 뒤 정한 값이므로 이 기준의 최초 평가는 새 독립 보류 자료로만 한다.
- 범위·배점·수치 조건 변경이라 사용자의 명시적 승인 전에는 `PROGRESS_CRITERIA.md`·`development-progress.json`을 수정하지 않는다. 승인하면 history에 점수·ID·근거를 기록한다.
