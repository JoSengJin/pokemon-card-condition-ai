## 3. 점수를 보기 전에 고정할 독립 코호트와 시험

### 모집과 제외

1. 표본은 실물 카드 ID 하나다. 새로 모집한 실물에서 개발·학습·후보 선택·과거 평가 전체의 그룹/원천/매물·수집 ID 및 앞뒤 raw SHA와 EXIF RGB decoded SHA를 조회한다. D1/D2는 금지 목록의 식별자와 해시로만 사용한다. 스캔/압축/크롭/같은 카드 재매물은 바이트 해시를 피할 수 있어 정면 판본·카드번호·판매자/소유 출처와 이미지 유사도 후보를 함께 사람이 대조한다. 동일 판본을 동일 실물로 단정하지 않는다. 중복 의심을 해소할 수 없으면 시험에서 제외하고 사유를 남긴다.
2. 모집 시작 전에 대상 유통/촬영 프레임과 사람 모집·라벨 순서를 기록한다. 동일 실물의 재촬영은 동일 ID로 묶고, 시각 순서로 처음 적격 판정을 받은 원본 사진 하나를 대표로 고정한다. 앞면이나 재촬영은 식별·사람 정답 확인에 활용할 수 있으며 추론 입력을 추가하지 않는다. 한 매물에서 여러 실물임이 확인되지 않으면 한 그룹으로 처리한다. 초과 카드가 있으면 적격으로 판정한 순서와 ID 사전순을 적용해 결함·정상별 첫 목표 수만 넣는다. 점수를 가린 상태에서 진짜 둥근 끝의 결함·정상·판단 불가, 정답 근거 구역·점(가능할 때), 상자와 제외 사유를 확정한다. 불일치는 원본 재검토 후 두 번째 사람의 블라인드 판정으로 해결하고 해결되지 않으면 미확인이다. 판매자 문구/등급은 정답으로 쓰지 않는다.
3. 일차 평가의 두 집단은 네 모서리 모두 판정 가능해야 한다. 결함은 사람 결함 ≥1곳, 정상은 4곳 모두 정상. 제한이 있으나 모서리 네 곳이 전부 읽히는 카드는 포함하고 촬영 제한으로 표기한다. 네 모서리 중 하나라도 미확인, 후면/카드 경계 미확인, 앞면·비정품·복제 등 비지원은 사유와 장수를 보존하되 양쪽 주 분모에서 제외한다. 입력 봉인 뒤 모델 오류/누락은 사후 제외 사유가 될 수 없다. 실패 수·카드를 공개하고 공식 판정은 보류한다. 불량 입력으로 인한 중단/재개는 같은 후보 SHA·같은 입력·누적 로그로만 진행한다.
4. 언어(영어/일본어/한국어/기타/미확인), 뒷면 판본(표준 국제판/일본 구판/일본 신판/특수/미확인), 촬영 제한(없음/반사/흐림/가림/잘림/저해상도/각도/그림자/기타/미확인, 복수 허용)을 봉인한다. 각각 모집·제외·미지원·결함·정상·실행 실패·FN/FP와 관찰된 짝불일치를 보고한다. 0 분모는 미판정, 제한 복수 분모는 중복 허용임을 밝힌다. 전체 결과의 적용 범위는 실제 모집 프레임 및 적격 사진이며 하위군 수치는 별도 우위 주장에 사용하지 않는다.
5. 정답·포함/제외·샘플 순서의 manifest와 두 모델 파일·코드·실행 환경을 서명 또는 SHA256으로 봉인하고, 두 후보의 결과가 다 기록되기 전에는 공개하지 않는다. 작은 모집과 대규모 모집 중 하나를 점수 공개 전에 선택한다. 중간 열람 또는 결과에 따른 모집 연장은 금지한다. 독립 결과를 보고 수정한 후보는 별도로 버전 발급하고 새 독립 자료로만 확인한다.

### D3 절대 기준과 모집 장수

### 같은 카드에서 두 오류가 감소했는지

결함·정상 집단 각각에서 양쪽 오류, E만 오류(회복 b), 후보만 오류(신규 c), 둘 다 맞음을 표시한다. 순개선 `(b−c)/n`과 오류율, 새 오류 ID·실물 수를 보고한다. 회복 우위의 단측 정확 McNemar 검정은 `m=b+c`인 짝불일치에 대해 `P[Bin(m, 0.5) ≥ b]`다. 불일치가 0이면 `p=1`. 신규 0·회복 5개부터 `p=0.03125`로 판정 가능하다. **두 집단 모두 `b>c` 및 `p≤0.05`**일 때만 함께 감소했다고 판정한다. 둘 모두 우위여야 한다는 교집합 판정의 단측 유의수준은 최대 5%다. [SAS 정확 조건부 짝검정](https://support.sas.com/documentation/cdl/en/statug/66103/HTML/default/statug_power_details55.htm)

| 개발 E 대비를 설계에 대입 | 놓침 | 잘못 표시 |
|---|---:|---:|
| 회복 / 신규 | 5 / 3 | 3 / 2 |
| 검출하려는 절대 감소 | 2/175 = 1.14%p | 1/81 = 1.23%p |
| 가정한 짝불일치 비율 q, 회복 비중 r | 8/175, 5/8 | 5/81, 3/5 |
| 조건부 검정력 90%에 처음 도달하는 짝불일치 수 | 139 | 213 |
| 150/200장에서 예상 짝불일치, 검정력 | 6.86, 7.16% | 12.35, 10.88% |
| 3,200/3,700장에서 예상 짝불일치, 검정력 | 146.29, 90.63% | 228.40, 90.78% |

검정력은 `m ~ Bin(n, q)`로 가중한, 회복 수 `Bin(m, r)`가 각 (m)의 정확 기각 경계 이상일 확률이다. 두 결과 동시 검정력은 이 가정 아래 최소 약 81.4%(합집합 경계)다. q와 r은 소수의 개발 오류에서 추정해 불확실성이 크고 독립 효과를 보장하지 않는다. 150/200장으로도 큰 우위가 관찰되면 같은 판정 규칙을 적용한다. 감소 방향이나 절대 기준 충족만 확인되면 그 범위로 보고하며 두 오류의 동시 우위는 판정 보류다.

**교체 검토 진입**은 후보의 후면 모서리 D3 절대 기준 모두 충족, 두 단측 짝검정 모두 통과, 쌍 누락 없이 유효한 시간 측정과 보류 사유 공개를 요구한다. 어느 한 조건이라도 미충족이면 교체 검토를 보류한다. 시간 허용 예산은 정해진 값이 없어 실측 평균·p95 증가를 검토 자료로 제시한다. 교체 검토는 운영 연결 승인과 별개다.

### 보조 비교와 시간 측정

- **같은 잘못 표시 예산.** 기존 코드는 `corner-card-ranking-20261121/worker.py::summarize → corner-mlp-head-20261121/worker.py::card_miss`. 정상 카드 최고점을 정렬해 내림차순 11번째 점수 + `1e−12`로 `≥` 기준을 적용했고 10장·놓침 50/48/42를 재현했다. 독립 자료의 예산은 `K = floor(10 × 정상 카드 수 / 81)` (권장 정상 200장에서는 24). 양쪽 각각 정상 카드 최대 점수 경계 전체를 탐색한다. 후보 임계는 0과 각 고유 정상 최고점의 바로 위 부동소수점 `nextafter(score,+∞)`이다. 동일 점수 카드는 함께 남기거나 함께 제외한다. 정확히 K가 양쪽에서 가능하면 K, 아니면 양쪽에서 달성 가능한 가장 큰 공통 수 ≤K를 적용하고 K를 맞추지 못한 사유를 남긴다. 각각 선택된 오탐 수가 같아지는 가장 낮은 임계에서 결함 모서리 최대가 그 임계 미만인 카드 수를 계산한다. 같은 규칙으로 실제 임계·예산·달성 장수를 공개하며 D3 및 운영 임계는 여기서 최적화하지 않는다.
- **실측 범위.** 동일 Mac/가속기(원 실험과 같은 MPS를 기본), OS와 Python·PyTorch·Torchvision·Pillow 버전·스레드 2·동시성 1·FP32·448·같은 로컬 원본을 고정한다. 양쪽 모델·백본을 미리 로드한다. 한 카드의 로컬 이미지 읽기, EXIF/RGB·크롭·리사이즈·정규화·마스크, 장치 이동·백본·head·배치 평균·4구역 점수와 카드 판정 결과 완성까지 단조 시계로 잰다. 공통 정답 join은 시간 측정 밖에서 수행한다. 모델 초기 로딩·네트워크·라벨 입력·UI는 계측 범위 밖이다. 양쪽 경로에 특징 캐시와 추론 간 재사용을 금지한다.
- **실행.** 시간 전용 개발 카드 20장(별도 SHA 고정)으로 후보당 워밍업 20회, 결과에서 제외한다. 독립 적격표에서 각 집단 25장을 `sha256('corner-latency-v1/'+group_id)` 오름차순으로 먼저 선정해 같은 카드 50장을 다섯 라운드, 후보당 250회 잰다. 라운드 0~4마다 `sha256('corner-latency-v1/'+str(round)+'/'+group_id)` 오름차순, 그 순위(0부터)+라운드가 짝수면 E 먼저, 홀수면 평균 후보 먼저 실행한다. 짝 사이 다른 요청을 실행하지 않는다. 각 호출 직전 동기화 완료 후 시작, 출력 완성 후 `torch.mps.synchronize()` 뒤 끝 시간을 읽는다. CPU면 호출 종료로 동기화된다. OS 읽기 캐시를 사용하는 warm 지연을 보고한다. 타임아웃·오류는 원래 시도 수/총 시간에 표시하며 유효 쌍이 250 미만이면 확정 시간 결론을 보류한다.
- **보고.** 양쪽 평균 ms·p95(정렬 후 `ceil(.95*n)`번째), 동일 순서·동일 카드에서 얻은 후보−E 지연 평균/차이 p95와 두 모델의 p95 차이를 각각 표시한다. 카드/요청 수, 반복·실패 수, 백본 실행 수 실측을 함께 공개한다. 모서리당 호출 1→4이므로 완전한 네 모서리 카드의 예상 호출은 4→16이다. 호출 수 변화와 밀리초 변화의 관계는 계측으로 확인한다.
