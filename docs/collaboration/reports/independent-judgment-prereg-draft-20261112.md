# 독립 판정 사전 등록 초안 (Q2, 미승인·미실행, 2026-11-12)

상태: **초안. 외부 판정자 모집·판정 실행은 사용자 승인 대상이다.** 표본 추출·갤러리·페이지 생성도 승인 후 고정한다. 학습·추론·라벨·게이트 변경 0.

질문: 개발에 참여하지 않은 판정자들이 "뒷면 표면 결함"을 재현 가능하게 판정할 수 있는가.

## 1. 판정 질문 (고정)
- "이 구역의 **인쇄면 안쪽(표면)**에 결함이 있나요?" → `결함 있음` / `결함 없음` / `판단 불가`. 심각도는 묻지 않는다.
- 정의는 `LABELING_PROTOCOL.md` 표면 행 그대로: 긁힘·뜯김·눌림·구김·접힘·얼룩·인쇄 외 자국, 면 위 흰 마모 자국은 결함. **옆면 테두리 백화(엣지)·둥근 끝 마모(모서리)·카드 밖 배경·홀로 반사·인쇄 무늬는 제외.** 반사인지 마모인지 구분되지 않거나 카드 밖이면 판단 불가.
- 안내문 정본: `card_condition/label_instructions.py`의 `SURFACE_INSTRUCTIONS`(문구 수정 없음).

## 2. 기준 고정 장치
- **예시 갤러리**: 결함 6·정상 6·경계 6 크롭. 출처는 같은 사람 반복 판정이 일치한 구역(구역평가 반복 결함 일치, 심각도 반복 0↔0 또는 2↔2 일치)과 경계 예시(반복이 뒤집힌 구역, "판단 불가 허용"이라는 이유와 함께 표시). 갤러리 구역과 **같은 사진 그룹 전체**를 평가 표본 모집단에서 먼저 제외한다.
- **크롭·배율 고정**: 크롭 = `surface-grounding-20261110/packet.json`의 구역 box(여백 0), 긴 변 900px. 확대는 자유 핀치 대신 **고정 2배 확대 버튼 1개**만 제공하고 사용 여부를 기록한다(심각도 진단에서 불일치가 "확대해야 보임" 경계에 몰렸기 때문).
- 판정 전 갤러리 확인을 필수로 하고, 갤러리 열람 완료 여부를 기록한다.

## 3. 표본 (1776곳, 직접 알파0 저장 점수 `20261108T215307-941b3aaa`)
- 칸: 원 target × (점수 ≥ 0.5) = TN 1239 / FP 167 / FN 57 / TP 313. 칸별 층화 무작위, **사진 그룹당 최대 1구역**(전 칸 공통), 고정 seed. 추정은 칸 크기 가중.
- 기존 재판정·구역평가·심각도·후보 판정에 쓴 구역은 **제외하지 않고 `prior_used` 표시**한다(원 판정자 기억 효과는 이 표시로 분리 분석). 카드 밖(마스크) 구역도 모집단에 포함하고 `card_off` 표시.
- 파일럿과 본 판정 표본은 서로 겹치지 않는다. 파일럿 결과는 본 판정 추정에 합치지 않는다.

## 4. 2단계 진행
| 단계 | 판정자 | 규모 | 통과 조건(사전 고정) |
|---|---|---|---|
| (a) 파일럿 | 외부 2명 이상 + 원 판정자(세 번째 평가자) | 40구역(칸당 10) | 외부 판정자 간 alpha ≥ 0.5 **그리고** 판단불가 ≤ 20% **그리고** 판정자 질문 중 정의 모호 지적이 해결됨. 미통과 시 본 판정 진행 안 함 |
| (b) 본 판정 | 외부 3명 + 원 판정자 | 160구역(칸당 40) | 아래 §6 |

규모 근거(`tools/diagnostics/label-noise-floor-20261112/alpha_size.py`, **합성 시뮬레이션**, 3명·결측 10%·표본 유병 0.5): alpha ≈ 0.64~0.70일 때 95% 반폭은 n=40 ±0.19, n=120 ±0.11, **n=160 ±0.09~0.10**, n=200 ±0.08~0.09. 목표 ±0.1 → 160구역. 파일럿 40구역(±0.19)은 진행 여부 선별용이라 0.667 판정에 쓰지 않는다.

## 5. 화면 (승인 후 생성)
- 예측 점수·이전 라벨·칸 미표시, 미리 채우기 없음, 구역 순서는 판정자별 무작위.
- 항목별 기록 필드(현재 응답 117파일에는 없음, 원시 기록 감사 참조): `shown_at`, `answered_at`(ISO 시각), `zoom_used`(2배 버튼 사용 여부), `changes`(선택 변경 이력: 이전값→새값·시각), `gallery_viewed`, `rater_id`(익명 코드), `device`(화면 폭만).
- 원본 사진·응답은 Git 제외 `artifacts/`에만 저장.

## 6. 판정 기준과 합의 규칙 (사전 고정)
- 지표: Krippendorff alpha(명목, 3범주; 판단불가도 범주로 포함) 주 지표, 이진(결함 vs 그 외) alpha 보조. 사진 그룹 부트스트랩 95% 구간(B=10000).
- **주 판정은 외부 판정자끼리의 alpha.** 원 판정자를 포함한 alpha와 원 판정자 vs 외부 합의 일치율은 보조로 보고한다.
- alpha 점추정 ≥ 0.667 → 합의 정답 사용 가능. < 0.667 → 사용 불가. 구간 하한이 0.667 미만이면 "기준 통과, 구간이 기준 포함"으로 함께 표시한다. 결과를 본 뒤 기준을 바꾸지 않는다.
- 합의: 외부 3명 다수결(2명 이상 같은 확정 답). 그 외(1:1:1, 판단불가 2명 이상)는 `판단 불가`로 평가 분모에서 제외하고 개수·칸별 비율을 보고. 원 판정자는 합의에 넣지 않는다.
- 합의 정답이 쓰일 때: 저장 점수(새 추론 없음)로 직접 알파0의 FP/FN·가중 AUC를 칸 가중으로 재평가하고, 같은 합의로 Q1 잡음 하한을 독립 판정 기반으로 재계산한다.

## 7. 리스크
- 외부 판정자 확보·보상·개인정보(판정자 식별 정보 비저장)는 사용자 결정.
- 판매자 사진 해상도 한계로 판단불가가 많을 수 있다(카드 밖 구역 포함).
- 원 판정자는 표본 일부를 이미 봤다(`prior_used`). 외부 판정자 alpha가 주 지표라 판정에는 영향 없음.
