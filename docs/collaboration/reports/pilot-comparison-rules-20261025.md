# 파일럿 2인 응답 대조 규칙 (2026-10-25, 실행 전 고정용 초안)

[파일럿 계획](data-acquisition-pilot-plan-20261025.md) 3절의 측정값을 계산하는 규칙이다. 결과를 보기 전에 사용자 승인으로 고정한다. 이후 분모와 분류를 바꾸지 않는다. 구현은 Codex가 기본 checkout에서 맡으며, **새 판정 로직은 만들지 않고 기존 투영을 재사용한다.**

## 1. 입력

- A(사용자)와 B(협력자)가 각자 저장한 inventory JSONL 사본 2개. 두 파일은 편집하지 않는다.
- 두 사본은 같은 원본에서 복제한다. 행 id, group, split, 사진 경로가 같아야 한다. 저장 직후 각 파일의 SHA256을 기록한다.
- 사진 원본·디코드 SHA 또는 ID/group/split이 다르면 대조를 중단하고 입력 오류로 기록한다. 다른 사진의 면 판정도 비교하지 않는다. box만 달라진 경우에 한해 아래 구역 제외 규칙을 쓴다.
- 판정 전 두 사본의 `with_suffix('.drafts.json')` 파일·심볼릭 링크가 없음을 확인한다. 새 파일럿 입력은 box 확인 외 판정값을 비워 두고, 기존 AI/사람 답·후보 점·메모를 보여 주지 않는다. 개발용 "hi 후보 미리 표시"는 금지한다. 완료된 기존 정답을 지워 재질문하지 않고 신규 실물만 대상으로 한다.

## 2. 영역(box)을 먼저 고정한다

기존 검토 UI는 사본마다 카드 영역 box를 따로 저장한다. 구역(3×3)은 box 기준으로 나뉜다. 그래서 두 사람의 box가 다르면 "같은 구역"이 서로 다른 픽셀을 가리킨다.

- **독립 판정 전에** 한 사람(제안: 사용자)이 20면의 box를 확인한다(`box_reviewed=true`). 그 상태로 A·B 사본을 만든다.
- 판정 중에 box가 바뀐 면은 구역 질문(모서리·엣지·표면) 비교에서 **제외**하고 `box_changed`로 따로 센다. 면 질문(판정 가능·센터링·관찰 제한)은 그대로 비교한다.

## 3. 단위 만들기 = 기존 `coverage_report` 투영 재사용

각 사본에 `card_condition.data_coverage.coverage_report`를 그대로 적용해 단위 목록을 얻는다. 이 함수의 판정 규칙(2026-10-25 main 기준)은 다음과 같다.

| 질문 | 단위 | 값 |
|---|---|---|
| 센터링 | 면 | `labels.centering_defect` 0/1, null이면 unknown |
| 관찰 제한 | 면 | `visibility_issues`가 비어 있지 않으면 1. 빈 목록이면서 `gradable==1`이면 0. 그 밖에는 unknown |
| 모서리·엣지·표면 | 구역 (4/8/9) | 기존 3×3 투영값 0/1. 투영이 없으면 unknown. 관찰 제한 구역은 투영에서 제외된다 |

- 단위 키: `(card_id, side, question, area)`. 사전 고정 입력과 두 사본의 `image_sha256`·`card_box`를 모두 대조한다. 사진이 다르면1절의 중단, box만 다르면2절의 구역 제외 규칙을 적용한다. 제외 구역 수와 원래 예정 분모도 보고해 작은 분모를 숨기지 않는다.
- 판정 가능(gradable)은 coverage 질문에 없다. 사본의 `side_annotations[side].labels.gradable`을 직접 읽어 따로 집계한다.
- 결함점은 위치를 비교하지 않는다. 구역별 점 개수만 기록한다(정상점·IoU 주장 없음).

## 4. 분류

| A \\ B | 0 | 1 | unknown |
|---|---|---|---|
| **0** | 일치-정상 | 불일치(B 과잉) | B 미응답 |
| **1** | 불일치(B 누락) | 일치-결함 | B 미응답 |
| **unknown** | A 미응답 | A 미응답 | 둘 다 미응답 |

- "unknown"은 판단 유보, 미클릭, 관찰 제한 투영 제외를 모두 포함한다. 원인별 개수는 사본에서 따로 센다. **어느 경우도 정상으로 바꾸지 않는다.**

## 5. 측정값과 분모 (질문×면별로 따로, 합산은 참고로만)

- 불일치율 = (B 과잉 + B 누락) / (일치-정상 + 일치-결함 + B 과잉 + B 누락)
- B 결함 불일치(누락 방향) = B 누락 / (B 누락 + 일치-결함). 분모는 A=1이면서 B가0/1로 응답한 단위다. A를 임시 비교 기준으로 삼는 작업자 간 불일치이며 실제 오류 확정이나 모델 FN이 아니다.
- B 결함 불일치(과잉 방향) = B 과잉 / (B 과잉 + 일치-정상). 최종 사용자 조정값과 A·B 원본은 별도 보존한다.
- B 미응답률 = B 미응답 / (A가 응답한 단위)
- 관찰 불가 비율(A/B 각각) = 해당 사본의 관찰제한 양성 면 / 관찰제한0/1이 알려진 면. 판정 가능(gradable) 면만으로 나누지 않는다. unknown 면/전체20면과 구역 `glare_areas`도 별도 보고한다.
- 분모가0이면 "측정 불가"로 쓴다. 0%로 쓰지 않는다. B가0/1로 응답한 A 양성 단위가10미만이면 누락 방향 항목은 측정 불가이며 성공으로 세지 않는다. 미응답률·제외량과 함께 해석한다(계획4절).
- 같은 실물의 앞·뒤와 구역은 독립 표본이 아니다. 실물 단위 결과(실물마다 불일치가 하나 이상 있는지)도 함께 보고한다.

## 6. 최종값과 시간

- 최종값은 사용자의 4단계 판정이다. A·B 원본값, 최종값, 판정 메모를 측정표 CSV에 남긴다.
- 사용자 최종 검토시간 = 4단계(불일치 + B 미응답 항목) + 5단계(감사) 시간. 2단계 A 시간과 같은 10실물 범위에서만 비교한다.
- 준비·영역 확인·기준 예제 승인/교육시간은 별도 보고하고 사용자 총투입에도 포함한다. 같은 사진의 재판정 기억 효과 때문에 운영 절감률은 미검증이다. 카드 시작/종료시간은 단위행마다 복제돼도 실물별 한번만 계산한다. 조정·감사시간은 중복 구간 없이 기록한다(CSV `audit_seconds` 포함).
- 유효 판정단위 = 최종값이 0 또는 1이고, box가 확인됐고, 권리와 중복 검사를 통과한 단위.

## 7. 하지 않는 것

- 모델 점수나 AI 후보로 불일치를 해소하지 않는다.
- 두 사람이 일치했다는 이유만으로 사용자 감사를 생략하지 않는다(무작위 감사 비율 유지).
- 결과를 본 뒤 분류나 분모를 바꾸지 않는다. 바꿔야 하면 다음 파일럿의 새 규칙 버전으로 분리한다.
