# 후면 모서리 점검 우선순위 용도 제안 (2026-11-01)

§42(개발 평가)에서 후면 모서리가 가장 유망했다: 풀링 교차검증 AUC 0.893, 높음−낮음 구간 결함 비율 격차 0.778[0.634,0.887], 1위 적중률 격차 0.344[0.056,0.549](170구역·66 사진 그룹, 결함 91·정상 79). 개발 평가이며 구간 임계(낮음 <0.41, 높음 ≥0.63)가 같은 out-of-fold 점수에서 정해져 낙관적이다. 이 제안은 진척 기준 C2(모서리)를 후면 모서리 한정으로 재정의하는 안이며, **사용자 승인 전에는 `PROGRESS_CRITERIA.md`·`development-progress.json`을 바꾸지 않는다**(규칙 4: 기준 본문 변경은 새 버전으로 분리, 승인 필요).

## 제안하는 C2 변경 (v1.2 안)
- 범위: C2를 "후면 모서리 점검 우선순위 제안"으로 한정. 앞면 모서리는 이 항목의 충족 범위가 아니다(§42에서 AUC 0.751·격차 0.296으로 미달).
- 평가 자료: 학습·튜닝에 쓰지 않은 독립 보류 사진 그룹 ≥40개·결함 사진 ≥20개. 사람이 예측 없이 4모서리를 라벨.
- 모델·임계: 풀링 학습 자료(`corner_defect` 후면 170구역)로 한 번 학습한 후보. 구간 임계 0.41/0.63은 개발 out-of-fold 점수에서 결과 전에 고정하며 독립 자료로 바꾸지 않는다.
- 충족 조건: (a) 높음−낮음 구간 결함 비율 격차 ≥0.40이고 사진 그룹 부트스트랩 95% 하한 ≥0.40, (b) 결함과 정상이 섞인 사진에서 1위 모서리가 결함인 비율이 무작위 기대보다 ≥0.20 높고 부트스트랩 95% 하한 > 0. (C1과 다른 점: 모서리는 사진당 후보가 4개뿐이라 적중률 하한 요건을 0 초과로 둔다. 개발 평가의 하한이 0.056이었기 때문이며, 결과를 본 뒤 정한 값이므로 첫 평가는 새 독립 자료로만 한다.)
- 배점 7점과 다른 항목은 불변. 이 항목이 충족되면 점수 42→49(+7, v1.2 기준).
- 금지 표현: 결함 판정, 누락 5% 이하.

## 수집 상태
- 독립 보류로 쓸 자료: 후면 엣지 첫 평가(§41)에 쓴 y·z 45 사진은 모서리 라벨을 받은 적이 없고 학습에도 쓰지 않았다. 카드 상자는 이미 사용자가 확인했으므로 모서리 4칸만 예측 없이 새로 라벨하면 모서리 평가의 독립 자료가 된다. 모서리 라벨 페이지 6장 생성(`artifacts/corner-back-holdout-20261101/corner-pages-*.html`).
