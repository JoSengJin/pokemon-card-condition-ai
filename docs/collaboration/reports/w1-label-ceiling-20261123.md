## 에튜
- 관찰 AUC 상한: 라벨이 확률 f로 뒤집히면 완벽한 모델도 AUC<1이다. 점수가 상한에 가까우면 모델 개선 여지가 없다는 신호라 W2 전 확인했다. 예: f=0.1, 양성률 0.43 → 약 0.89.
- Cohen kappa: 우연 일치를 뺀 일치도. 클래스가 치우치면 일치율이 높아도 kappa가 낮아, 분포 편향 표본엔 AC1을 병기했다.
