고친 동작

stdout/stderr 청크를 스트림별 UTF-8/줄로 복구한 뒤 비밀값을 가린다. 종료 때 남은 줄을 가리고 줄바꿈을 마무리해 마지막 JSON이 시스템 로그와 합쳐지지 않게 한다. 로그 감시는 1MB 밖 JSON도 온전한 줄로 읽고 실제 byte offset을 유지한다. 일반 텍스트의 끝 UTF-8 조각만 다음 읽기로 넘긴다.
