## 코드로 확인한 구조와 남은 가설

현재 `pair_loss[i,j]=softplus(n_j−d_i)`이고, `n_j`는 정상patch tau0.1 upperLSE, `d_i`는 결함patch max다. 산술항0.5와 LME항0.5를 더한다. LME항은 **각 결함 내 정상쌍 LME를 계산한 뒤 결함평균**이다:

```python
lme=(torch.logsumexp(pair_loss,dim=1)-math.log(pair_loss.shape[1])).mean()
```

`A=logmeanexp_j(n_j)`이면 이 LME항은 정확히 `mean_i softplus(A−d_i)`와 같다. 이는 `exp(softplus(t))=1+exp(t)`에서 나온다. 결함 gradient 크기는 `sigmoid(A−d_i)/N_defect`여서 어려운 결함을 이미 더 강조하지만 **결함당 최대1/N_defect로 포화**된다. 따라서 '결함gradient가 전부동일/없음'은 잘못된 설명이다.

순위항은 모든 logits에 같은bias를 더해도 `n_j−d_i`가 불변이어서 rank의 biasgradient가0이다. 절대0.5 경계는 기존 bagloss가 결정한다. 순위항 추가 후 최고반응과 약한결함이 서로 다른방향으로 움직인 사실은 단순threshold/bias수정만으로 해결할 근거가 아니다. threshold를 바꿔도 AUC는 바뀌지 않는다.

합성 수치로 현행 row-LME 항등식/공통bias 불변성을 float64 오차1e-14 내 확인했다(`analysis.json.formula_checks`). 실제학습gradient 분해나 새후보손실/점수평가는 하지 않았다. 혼합모델의5fold 최종gradient4.6578e-8~7.7838e-8은 수렴기준1e-5를 충분히 통과했으므로 optimizer수정은 우선하지 않는다.

## 다음 최소 수정안 — 제안만, 미구현

**하나의 변수: LME 절반의 집계 범위를 전체 결함×정상 학습쌍으로 변경.**

```python
# 현재
lme=(torch.logsumexp(pair_loss,dim=1)-math.log(pair_loss.shape[1])).mean()
# 제안
lme=torch.logsumexp(pair_loss.reshape(-1),dim=0)-math.log(pair_loss.numel())
# 그대로
loss=loss+.5*arithmetic+.5*lme
```

제안항은 `softplus(A+B)`, `B=logmeanexp_i(−d_i)`와 같다. LME절반의 결함별 gradient가 `sigmoid(A+B)*softmax_i(−d_i)`로 바뀌어 낮은 결함logit을 지수적으로 더 강조한다. 기존 정상 간 상대gradient `softmax_j(n_j)`는 그대로이고 전체압력은 달라진다. 따라서 **정상간 강조 순서를 새로 바꾸는 수정이 아니라 약한결함 보호와 정상억제의 결합압력을 바꾸는 수정**이다. 산술50%는 유지하므로 쉬운쌍도 제외하지 않는다.

선택 근거: 정상 최고반응은 이미LSE가 거의 직접 보고 있고 새누락은 대개 위치변경 없이 약해졌다. 정상온도/출력/임계값을 또 바꾸기보다 결함축집계 한 줄을 바꿔 약한결함의 상대기여를 검증하는 것이 현재 제약에서 작다. **공통오탐160의 해결을 보장하지 않으며**, 실제 학습 기여를 보지 못한 상태의 다음 반증가능한 가설이다. 단순혼합비율 재탐색은 하지 않는다.

유지 항목:

- 모든학습fold의 모든결함×정상쌍, 산술:LME=50:50, 총순위계수1. OOF오류ID별 가중/선별0.
- 정상patch tau=0.1의 비정규화LSE, 결함patch max, pair LME의 기존 암묵온도1, 기존 bagloss/mass/L2/특징/seed/초기화.

- 최종gradient≤1e-5(내부목표1e-7), fit당1,000반복/초기평가 포함1,250평가.

승인 후에만 새 격리 소스/가설계획으로 구현한다. 기존 experiment snapshot/worker는 덮어쓰지 않는다. 합성으로 전체쌍수식/gradient/동일값정규화/유한성/모든쌍 기여/기존구조·예산보호를 검증한 뒤 공통실행기로1회만 검증해야 한다. 이번에는 실행하지 않았다.
