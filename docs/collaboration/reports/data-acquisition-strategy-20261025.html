제안 제안

역할 분담: 사용자 = 기준 예제 승인, 불일치·유보 판정, 무작위 감사. 협력자 = 자기 카드 촬영과 1차 판정(AI·모델·타인 답 비노출). 자동화(기존 도구) = SHA 중복·실물 교차 거부, coverage 재계산, 검토 패킷, 응답 대조표. AI 합의를 사람 정답으로 쓰지 않는다.
다음 검증 1개 — 2인 독립 판정 파일럿 (미실행): 신규 10실물의 앞뒤 20면을 사용자와 협력자가 따로 판정한 뒤, 사용자가 불일치만 판정한다.
제안 성공 기준: 유효 실물 ≥9/10, 질문별 불일치 ≤15%, 협력자 결함 누락 ≤20%(A 결함 ≥10단위), 관찰 불가 ≤25%, 사용자 시간 비율 ≤0.5. 실패: 불일치 >30%, 누락 >40%, 관찰 불가 >50%, 시간 비율 >0.8, 유효 실물 ≤7. 모두 제안값이다.
