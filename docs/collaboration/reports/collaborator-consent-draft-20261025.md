## 카드 상태 사진 판독 연구 참여 동의서

**연구 담당:** ［이름］ · 연락처 ［ ］
**목적:** 포켓몬 카드의 모서리·엣지·표면·센터링 상태와 사진의 관찰 제한을 사람이 판정한 자료로, 사진 판독 보조 모델을 개발하고 평가한다. 공식 등급, 가격, 진위는 판정하지 않는다.

### 1. 하는 일
- ［ ］장의 카드를 촬영 지침에 따라 앞면과 뒷면으로 촬영한다.
- 연구 담당자가 제공한 화면에서 기준 예제를 판정한 뒤, 배정된 사진의 상태를 판정한다.
- 카드마다 시작과 종료 시각을 기록한다.
- 예상 소요 시간: 시험 작업으로 측정한 뒤 알린다(현재 미측정).

### 2. 사진과 판정 자료의 사용 범위 (해당 항목에 표시)
- [ ] 연구용 **평가** 자료로 사용
- [ ] 연구용 **학습** 자료로 사용
- [ ] 연구 결과 보고서에 사진 일부를 게시(얼굴·개인정보 없는 카드 사진에 한함)
- 표시하지 않은 용도로는 쓰지 않는다. 제3자에게 판매하거나 배포하지 않는다.

### 3. 권리 확인
- [ ] 촬영한 카드는 본인 소유이거나, 소유자에게서 촬영 허락을 받았다(허락한 사람: ［ ］).
- [ ] 사진은 본인이 직접 촬영했다. 판매 사이트나 SNS에서 가져온 사진이 아니다.

### 4. 기록되는 정보
- 참여자 식별 기호(실명 대신 ［예: R2］), 판정값, 판정 시각과 소요 시간, 사진 파일의 해시값
- 사진 메타데이터(EXIF)에 위치 정보가 있으면 사용 전에 제거한다.
- 판정 품질 확인을 위해 다른 판정자와의 일치율을 계산한다. 이 값은 연구 품질 관리에만 쓴다.

### 5. 판정 원칙 (요약)
- 보이지 않는 부분은 정상으로 표시하지 않는다(관찰 불가 또는 판단 유보로 둔다).
- 판정하는 동안 AI 결과나 다른 사람의 답을 보지 않는다.

### 6. 보수
- ［없음 / 금액 ］ · 지급 조건 ［ ］

### 7. 철회와 삭제
- 언제든 참여를 그만둘 수 있다. 원하면 본인의 사진과 판정 자료를 삭제한다.
- 이미 학습이나 평가에 사용한 경우, 해당 기록과 사용 이력을 함께 알려 준다. 학습된 모델 가중치에서 개별 사진의 영향을 완전히 제거하지는 못할 수 있다.
- 보관 기간: ［ ］ 이후 삭제
