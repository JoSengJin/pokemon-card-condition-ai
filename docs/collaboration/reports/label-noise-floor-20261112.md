Q1은 FP 기준(현재 결과 = **하한 > 112**). AUC +0.03 게이트는 모든 칸에서 사용자 결정 항목이다.

| Q1 \ Q2 | alpha ≥ 0.667 (합의 정답 사용 가능) | alpha < 0.667 |
|---|---|---|
| **하한 > 112 (현재)** | 합의 정답으로 직접 알파0 저장 점수 재평가(새 추론 없음) → 그 정답으로 게이트를 다시 볼지 **사용자 결정**. 표현 가설은 그 전까지 재개 금지. AUC: 합의 정답 기준 기준선 재설정 여부 사용자 결정 | 이진 게이트 대신 **점검 우선순위(순위) 출력**으로 제품 재정의를 사용자에게 제안. AUC 게이트를 순위 지표로 바꿀지 사용자 결정 |
| 구간이 112 포함 | 합의 정답으로 잡음 하한 재계산(독립 판정 기반) 후 이 표 재적용. AUC: 재계산 후 결정 | 순위 출력 재정의 제안 + 라벨 정의 재설계 필요 보고. AUC: 사용자 결정 |
