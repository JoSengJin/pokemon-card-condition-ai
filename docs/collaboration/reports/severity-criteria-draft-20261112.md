# 표면 결함 심각도 3단계 기준 (사용자 확정 2026-11-12: 단계 1 경계 = 확대해야 보임)

범위: 구역 크롭 안의 **인쇄면 안쪽(표면)**만. 기존 정의(`LABELING_PROTOCOL.md` 9·13행)를 따른다: 긁힘·뜯김·눌림·구김·접힘·얼룩·인쇄 외 자국, 면 위 흰 마모 자국은 표면 대상. 옆면 테두리 백화(엣지), 둥근 끝 마모(모서리), 카드 밖 배경, 홀로 반사, 인쇄 무늬는 표면에서 제외. 화이트닝이라는 단어만으로 판정하지 않고 위치와 실제 보이는 자국을 함께 본다.

## 단계
| 단계 | 이름 | 기준 (구역 크롭을 확대 없이 일반 화면으로 볼 때) |
|---|---|---|
| 0 | 없음 | 인쇄면 안쪽에 인쇄 외 자국이 없다. 엣지·모서리·반사·인쇄 무늬·카드 밖만 있는 경우 포함 |
| 1 | 경미 | 자국이 있는 것은 확실하나 **한눈에 구분되지 않고** 확대해야 보이거나, 아주 작고 얕다(점 하나, 가는 선 하나 수준) |
| 2 | 뚜렷 | **확대 없이 한눈에** 구분되는 자국(긁힘·뜯김·눌림·접힘·얼룩, 또는 면적 있는 면 위 흰 마모) |

- **판단 불가는 단계가 아니다.** 자국인지 반사/무늬인지 확신이 없거나, 카드 밖이라 판단할 표면이 없으면 판단 불가로 별도 기록한다(기존 경계 기준 ②③ 유지). 경미(자국은 확실, 작음)와 판단 불가(자국인지 불확실)를 섞지 않는다.
- 기존 경계 기준 ①(한눈에 보이는 긁힘·점·색 차이 = 결함)은 **단계 2**에, ④(충분히 보이는데 없음 = 정상)는 **단계 0**에 해당한다. 단계 1은 기존 기준에 없던 구간이다.
- 판정자는 단계 하나만 고른다. 한 구역에 여러 자국이 있으면 가장 높은 단계.

## 기존 target과의 연결 (미정, 측정 후 결정)
기존 target(표면 결함 중심)이 단계 몇 이상에 해당하는지는 **가정하지 않는다.** 구역 평가 100곳 등에 단계를 매긴 뒤 기존 target과의 교차표로 확인한다.

## 확정 사항
- 확정: 단계 1(경미)의 경계는 **"확대해야 보임"**이다. 크기 수치 기준은 두지 않는다. 예시(점 하나, 가는 선 하나)는 참고용이다.

## 한계
재현성(kappa)은 미측정이다. 단계가 늘어 2분류보다 일치도가 낮을 수 있어, 사용 전에 같은 구역 일부를 반복 판정해 3단계 kappa/가중 kappa를 확인해야 한다. 기준을 확정하기 전에 라벨링·학습을 시작하지 않는다.
