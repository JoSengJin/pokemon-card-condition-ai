# 다음 검증 1개: 2인 독립 판정 파일럿 계획 (2026-10-25, 미실행)

- 가설 ID(제안): `labor-split-pilot-20261025`
- 가설: 지침과 기준 예제 검사를 거친 협력자 1명이 신규 실물을 1차 판정하면, 사용자는 불일치·유보·감사만 판정하면 되므로 실물당 사용자 시간이 줄어든다. 동시에 정답 품질(사용자 독립 판정과의 일치)이 유지된다.
- 바꾸는 변수 하나: 1차 판정자(사용자 단독 → 협력자 1차 + 사용자 판정).
- 이 파일럿은 **모델 실험이 아니다.** 학습·추론·Gemini·Codex 호출이 없으므로 `./experiment` 대상도 아니다. A3·D1 충족이나 모델 성능 개선으로 보고하지 않는다.

## 1. 실행 전에 필요한 것 (사람 의존)

1. 사용자가 이 계획과 아래 제안 수치를 승인하거나 수정한다.
2. 협력자 1명을 확보하고 동의서를 받는다. 동의서에는 사용 범위·삭제 요청·보수 여부를 적는다. **지금은 확보한 사람이 없다.**
3. 지침 초안 v0.1을 승인하고, 대표 예제를 지정한다(이미 확인한 개발 사진에서 고른다).
4. 신규 10실물을 준비한다. 기존 70실물과 다르고 D1 후보로 지정하지 않은 실물이어야 한다. 사용자나 협력자가 소유한 실물이라 촬영 권리가 명확해야 한다.
5. 파일럿 실물의 용도를 판정 전에 고정한다. 제안: "val 개발 평가 후보"로 지정하고, D1에서는 영구 제외한다. 채택은 Codex가 기본 checkout에서 한다.

## 2. 절차

| 단계 | 누가 | 무엇을 | 측정 |
|---|---|---|---|
| 0 준비 | 자동화(Codex, 기본 checkout) | 사진 20장의 원본·디코드 SHA를 계산하고 기존 manifest와 교차가 없는지 확인한다. A용·B용 inventory 사본을 따로 만들고 `.drafts.json`이 없는지 확인한다. | 유효 실물 수, 제외 사유 |
| 1 기준 예제 검사 | B | 대표 예제 판정(예제 수는 승인 시 확정) | B 일치율, 소요 시간 |
| 2 독립 판정 | A(사용자)와 B 각각 | 같은 20면을 서로의 답·모델 출력 없이 판정한다. 순서는 각자 무작위로 한다. | 카드당 시간(A, B 각각), 관찰 불가 비율, 판단 유보 비율 |
| 3 대조 | 자동화 | 면·구역·질문별로 일치·불일치·한쪽 유보를 표로 만든다. 점 위치는 비교하지 않고 개수만 기록한다. | 질문별 불일치율(분모 명시) |
| 4 판정 | A | 불일치와 B의 판단 유보 항목만 다시 보고 최종값을 정한다. 원래 두 답은 보존한다. | 사용자 최종 검토시간 |
| 5 무작위 감사 | A | 일치 항목 중 무작위 20%(제안값)를 다시 본다. 단, 2단계에서 A가 이미 판정했으므로 이 감사는 "같은 사람의 재판정 일관성"만 측정한다. | 감사 변경 건수 |

**주의:** 2단계에서 사용자도 전체를 판정한다. 이것은 협력자 품질을 측정하기 위한 파일럿 전용 비용이다. 목표 운영 흐름에서는 사용자가 1단계(기준 예제)와 4·5단계만 맡는다. 그래서 절감 효과는 "4단계 시간 + 기준 예제 승인 시간"을 "2단계 A 시간"과 비교해 추정한다. 이 비교는 같은 10실물에서만 성립하는 추정이며, 일반화되지 않는다.

## 3. 측정 항목과 분모

[측정표 CSV](data-acquisition-pilot-sheet-20261025.csv)에 카드×면×질문×구역 단위로 기록한다. CSV에는 형식 예시 6행만 들어 있다. 실제 행 수는 면당 24행이다(면 질문 3개: 판정 가능·센터링·관찰 제한, 모서리 4, 엣지 8, 표면 9). 실물당 48행, 10실물이면 480행이다. 실행 시 자동화가 생성한다.

- 카드당 작업시간: A와 B 각각, 실물별 시작과 종료 시각으로 잰다. 중앙값과 범위를 보고한다.
- 질문별 불일치율 = (A와 B가 모두 정상 또는 결함으로 답했는데 값이 다른 단위) / (둘 다 정상 또는 결함으로 답한 단위). 한쪽만 유보하거나 관찰 불가로 둔 단위는 따로 센다.
- B의 결함 누락 = (A=결함, B=정상) / (A=결함). B의 과잉 결함 = (A=정상, B=결함) / (A=정상). 둘 다 분모를 함께 쓴다.
- 관찰 불가 비율 = 관찰 불가 단위 / 전체 단위(A 기준과 B 기준 따로).
- 사용자 최종 검토시간 = 4단계 시간 + 5단계 시간.
- 유효 새 실물 = 앞뒤 사진·권리 기록·중복 없음·box 확인을 모두 갖추고 판정을 완료한 실물. 유효 판정단위 = 최종값이 정상 또는 결함인 단위(질문×면 셀별).

## 4. 성공·실패 기준 (모두 **제안값**, 사전 근거 없음, 승인 시 확정하고 결과를 본 뒤에는 바꾸지 않음)

| 항목 | 성공 | 실패 |
|---|---|---|
| 유효 새 실물 | ≥ 9/10 | ≤ 7/10 |
| 질문별 불일치율(모서리·엣지·표면·센터링 각각) | 모두 ≤ 15% | 어느 하나라도 > 30% |
| B의 결함 누락(A 결함 단위 기준) | ≤ 20% 이고 A 결함 단위 ≥ 10 | > 40% |
| 관찰 불가 비율(A 기준) | ≤ 25% | > 50%(촬영 지침 실패) |
| 사용자 시간 비율 = (4+5단계) / 2단계 A 시간 | ≤ 0.5 | > 0.8 |

- 둘 사이의 결과는 "판단 보류"로 보고하고, 지침을 개정한 다음 파일럿을 제안한다. 같은 10실물을 반복하지 않는다.
- 양성 단위가 적으면(A 결함 단위 < 10) B 결함 누락 항목은 "측정 불가"로 보고한다. 성공으로 세지 않는다.

## 5. 중단 조건 (제안값)

- 사진 하나라도 권리가 불명확하거나 기존 manifest 사진과 중복이면 → 그 실물을 제외한다. 제외 후 유효 실물이 7개 미만이면 파일럿을 중단한다.
- 판정 화면에 모델 점수, AI 후보, 다른 사람의 답이 노출되면 → 해당 판정을 무효로 하고 파일럿을 중단한다.
- 처음 3실물 이후 B의 카드당 시간 중앙값이 30분을 넘거나 관찰 불가가 50%를 넘으면 → 멈추고 지침을 고친다.
- 협력자가 동의를 철회하면 → 즉시 중단하고 그 협력자의 자료를 삭제 대상으로 분리한다.
