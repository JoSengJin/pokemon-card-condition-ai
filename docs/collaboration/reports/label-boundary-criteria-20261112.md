# 후보 박스 판정 경계 기준 (사용자 확정 2026-11-12)

범위: 모델 후보 점선 박스 안의 결함 유무 판정(`visible_defect_in_model_candidate_box`). 구역·카드 전체 라벨이 아니다.

1. 긁힘·점·주변과 구분되는 색 차이가 한눈에 보이면 → **결함**
2. 흰 기운이 보이지만 확신이 없거나 점선 밖과 구분이 안 되면 → **판단불가**
3. 카드 밖이거나 판단할 표면이 없으면 → **판단불가**
4. **정상**은 "충분히 보이는데 아무것도 없다"일 때만

근거: 재판정 40곳 kappa 0.472(CI 0.234~0.688), 카드 위 27곳 0.357, 불일치 카드 위 8곳의 세 번째 판정과 메모(`label-reliability-20261111.md`). 이 기준은 사람 판단을 정리한 것이며 모델 성능·독립 검증 근거가 아니다.

적용 규칙
- 기존 라벨·`candidate-answers.json`은 바꾸지 않는다. 새 기준은 별도 평가 뷰에만 적용한다.
- 기준 2·4는 사람이 박스를 봐야 적용된다. 자동 재분류하지 않는다.
- 기준 3은 마스크(근사)로 별도 what-if만 만든다. 마스크 오류율(일치 70~80%대)을 병기한다.
- 이 기준으로 다시 판정한 결과로 재검사 일치도를 새로 측정하기 전에는 "안정화"를 주장하지 않는다.
