1516개를 미확정으로 남기는 것은 **이미 확인된 공통 기준과 개별 원답 ID/수집 배치 사이의 적용 연결 근거가 부족하다**는 뜻이다. 공통 규약 자체를 몰라서가 아니며,1516개가 규약과 다르게 라벨됐다는 뜻도 아니다. 해당 발언이 개별 구역 모두를 포괄한다고 자동 확대하거나, 반대로 원답이 무효라고 선언하지 않는다. 기준 버전 문자열이 없다는 이유만으로 재라벨을 요구하지 않는다.

우선 기존 대화의 화면 제시→답 수신→해당 배치/ID 연결을 더 확인할 수 있는지 좁혀야 한다. 확인되는 기존 답은 그대로 제외한다. 그 뒤에도 사람만 판단할 특정 적용 범위가 남을 때만 그 부분을 묻는다. 원답/재판정값을 다시 고르게 하지 않는다.

## 원답 수신 대화까지 연결한 결과 — 가장 직접적인 미확정 근거

원답 전체1791구역을6개 실제 user 응답 메시지와 연결했다.1783구역은 원답 카드 문자열 전체 일치, 나머지 ah8구역은 사용자 승인 줄 규칙 적용 전의 같은 카드 응답에서 해당8개 상태/box가 완전히 일치한다(변경된 upper_right는 현재 풀 밖). 원문 위치·직전 assistant 요청은 response-context-links.json과 ledger.human_response_link에 기록했다.

**중요: 과거 HTML32개에 잘못된 화이트닝 문구가 없다는 것과, 실제 요청 채팅에 그 문구가 없다는 것은 다르다.** ad/ae/af/ ag·ah 라벨 요청 채팅에는 “화이트닝은 정상” 또는 “화이트닝·엣지·모서리 마모는 정상”이라는 위치를 생략한 안내가 실제 있었다. 이는 원답 직전 메시지와 정확히 연결됐다. 이 배치 전체1076구역 중 이미 확인된 §97 완료123개와 판단 불가7개는 재요청 제외했고, 나머지946구역을 가장 직접적인 적용 기준 미확정 범위로 분리했다.
