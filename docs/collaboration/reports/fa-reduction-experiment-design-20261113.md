# 오경보 감소 실험 설계안 (미승인·미실행: P2 승인 전에는 아무것도 하지 않는다)
근거: `card-fa-judgment-result-20261113.md`(오경보 구역 A 결함 8%, 발견된 결함 카드 최고 구역 36%), `card-false-alarm-diag-20261113.md`(집계 변경 무효).
- **가설(단일 변수):** 학습 라벨만 사람 target → A 합의 라벨로 바꾸면(같은 특징·head·폴드·시드) 같은 결함 카드 회수에서 정상 카드 오경보가 줄어든다. 근거: 오경보 구역의 92%가 A에서 정상.
- **필요 자료(새 판정):** 현재 1776곳 중 점수 ≥0.3인 782곳(≥0.4는 609곳)을 서브에이전트 3명이 A 문턱으로 판정(배치 40 기준 약 20배치×3=60회 호출). 점수 <0.3 구역은 A 정상으로 가정하지 않고 학습에서 제외하거나 별도 표본으로 확인. 이전 판정 표본(파일럿·본 160 + 이번 62)은 학습에 쓰지 않고 검증 전용으로 남긴다.
- **분리:** 사진 그룹 단위 폴드, 검증용 A 판정은 학습에 쓰지 않은 그룹에서 사전 고정. 판정자 지시·갤러리는 amendment_3 동일.
- **사전 수치 기준(초안, 결과 전 고정):** 검증 그룹의 A 합의 정답에서 카드 단위 결함 회수가 기존 모델과 같거나 −3%p 이내이면서 정상 카드 오경보가 −10%p 이상 감소, 카드 그룹 부트스트랩 95% 구간 하한 > 0. 사람 target 기준 지표(구역 FN/FP)는 병기만 하고 악화 허용 한도를 따로 사전 고정해야 한다(미정, 승인 시 사용자 결정).
- **위험:** 판정자와 같은 AI 계열 오류가 학습에 들어가는 순환, A 결함 양성이 적어(탐색 9.6%) 학습 신호 약함, 판정 호출 비용 큼, 독립 시험이 아니라 개발 검증. 승인되어도 일반화 개선은 주장하지 못한다.
