## 3. 가설 (원인은 미확정)
- **H1 라벨 절차 차이**: 기존 별개 정상 125장은 초기 6묶음(메모 접두 ‘AI 관찰’, 사용자가 Judy 작성으로 확인) + 보완 제출로 만들어졌고 1차 이후는 확대·상자 확인 절차 화면이다. 정상 판정의 엄격도가 다를 수 있다. 사람 정답은 모델 오답을 이유로 바꾸지 않고 재요청도 하지 않는다.
- **H2 분포 이동**: 기존 별개 영어 표준(구판 세트·반사·작은 카드)에서 개발 자료에 없던 정상 외관이 많다.
- **H3 개발 자료 구성**: 결함처럼 보이는 정상 테두리(경계 사례)가 학습에 부족하다. 이미 `corner-grid-average-independent-20261121.md` §4가 `corner-matched-hard-example-composition-v1`로 지정했다.
- **H4 정의 차이**: 개발 정상 카드는 일부 구역만 확인됐고 독립 정상 카드는 네 모서리 전부 확인이라 카드 단위 오탐 기회가 더 많다. 개발 12% 대 독립 36.5%는 같은 정의의 비교가 아니다.

## 4. 제약
- 이 350장은 결과를 본 뒤 설계에 쓰이므로 **소진된 독립 시험**이다. 학습·튜닝·임계 선택에 쓰지 않는다. 개선 후보는 개발 자료로만 만들고 **새 독립 코호트**에서 한 번 평가한다.
- v1.14 작동점(결함 구역 <0.20 놓침, 정상 구역 ≥0.60 오탐)은 사용자 승인 없이 바꾸지 않는다. 지금 결과를 본 뒤 바꾸면 안 된다.
- 소진되지 않은 후보: 선정에서 빠진 정상 134·결함 7(`cohort-seal.json`의 `not_selected_spare`). 새 코호트가 결함 150장이면 약 143장 더 필요하며 이번 수율(결함 약 16%/매물, 적격 후)로 약 900매물 수집이 든다(추정).
