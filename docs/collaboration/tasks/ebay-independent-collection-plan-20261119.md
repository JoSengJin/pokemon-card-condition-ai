# 새 eBay 독립 평가 수집 계획 (계획 승인 2026-11-19)

**승인 기록:** 사용자가 "계획 승인, 라벨러는 내가 지정할게"(2026-11-19)라고 답했다. 아래 제안 고정값이 확정됐다. 수집 기간·API 사용(1단계), 라벨러 ID는 `nada`(개발자와 다른 사람, 사용자 확인), 별도 macOS 계정은 아직 `null`이며 실행 승인은 아니다. 수집은 이 값들이 채워지고 사용자가 시작을 승인한 뒤에만 한다.

이 문서는 계획이다. 수집·API 호출·라벨·학습은 실행 승인 전까지 하지 않는다. 숫자는 사용자가 승인했다. 결과를 본 뒤에는 바꾸지 않는다.

## 목적
소비된 기존 자료와 겹치지 않는 새 후면 사진에서, 동결된 관찰 제한 후보를 한 번 평가한다(D2/D3 증거). 후보가 아직 동결되지 않았으므로 이 계획은 **사진 수집·봉인 → 후보 동결 → 라벨 공개 순서**를 고정한다.

## 근거 수치 (계산 완료, `z=1.6448536269514722` 단측 95% Wilson 상한)
D3 기준(누락 사건률 상한 ≤10%, 오탐 ≤20%)을 만족하는 최소 표본:

| 사건 수 k | 양성(제한) 최소 n (≤10%) | 정상 최소 n (≤20%) |
|---|---|---|
| 0 | 25 | 11 |
| 1 | 42 | 20 |
| 2 | 58 | 28 |
| 3 | 72 | 35 |

참고: 기존 120행 보류에서 제한 비율은 39/120(32.5%), 이전 재판정 진단의 누락은 23/55(42%)였다. 이 모델이 D3를 통과한다는 뜻이 아니다. D3은 현재 모델로 미충족이며 표본을 늘려도 비율이 같으면 통과하지 않는다.

## 실행 순서 (각 단계 별도 승인)
1. 수집 승인: 기간·API 사용 여부 확정(`null` 채우기).
2. 수집·자동 선별(후면만 골라 중복 제외) → 사진 해시 봉인. 정답 라벨 자동 생성 없음.
3. 후보 동결(모델·임계값·전처리 SHA 기록).
4. 라벨러가 별도 계정에서 판정, 개발자는 집계만 수신.
5. 동결 후보 1회 평가, 분모와 구간 보고.

## 사용자만 할 수 있는 것
수집 승인과 기간, 라벨러 지정, 별도 macOS 계정 권한, 라벨 판정.

## 이 문서가 하지 않는 것
수집·호출·학습 실행, 기준 변경, 점수 변경. 진척 78/100 불변.
