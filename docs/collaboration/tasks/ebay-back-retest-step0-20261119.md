# 후면 라벨 재현성 선행 단계 (nada 독립 재판정 40장)

사용자 승인(2026-11-19): 판정자 `nada` 가능, 선행 단계부터 진행. 모델 추론·학습·Gemini 호출·새 수집 없음. 자료는 개발 참고용이며 C5·D3·독립성 증거가 아니다.

## 설계 (nada 응답을 받기 전 잠금)
- 모집단: 사용 가능 첫 라벨 221건(정상 160·제한 61, `answers-all.json`). 첫 판정자 = 라벨을 붙여넣은 사용자. nada는 사용자와 다른 사람(사용자 확인)이며 첫 라벨을 본 적이 없어야 한다.
- 표본: 시드 20261120, 정상 20·제한 20을 계층 추출, 표시 순서는 시드 20261121로 섞음. 총 40장, 10장씩 4쪽. 같은 화면 형식·같은 선택지(제한/정상/자격아님/모름), 출처·AI 결과·첫 라벨은 화면에 없음.
- 점수: 양쪽 모두 정상/제한인 쌍만 Cohen's kappa(부트스트랩 2000회 95% 구간)·일치 수를 센다. 한쪽이라도 모름/자격아님/미확인이면 따로 센다. 방향별 불일치(제한→정상, 정상→제한)도 보고한다.

## 판정 기준 (결과를 본 뒤 바꾸지 않음)
| 결과 | 해석·다음 |
|---|---|
| 사용 쌍 ≥36 이고 kappa ≥0.60 | 판정 규칙 재현 가능으로 보고 새 사진 48장 파일럿 단계로 진행 가능 |
| 0.40 ≤ kappa < 0.60 | 불일치 유형부터 보고 판정 문구·표시 조건을 정한 뒤 새 사진으로 재확인 |
| kappa < 0.40 | 후보 튜닝 보류 유지, 관찰 제한 target 정의를 재검토 |
| 사용 쌍 <36 (모름·자격아님 ≥5건) | 사진·화면 문제를 먼저 점검, kappa 해석 보류 |

근거와 한계: kappa 구간 값은 관행(Landis–Koch)에 맞춘 제안이며 프로젝트 자료에서 유도한 값이 아니다. n=40이라 구간이 넓어(예: 일치 80%여도 kappa 95% 구간은 크게 열림) 한 번의 결과로 단정하지 않는다. 표본은 AI 선별을 거친 자료이고 두 판정자는 한 번만 응답한다(재판정 일치율은 이 단계에서 측정하지 않음). 이 결과로 라벨을 수정하지 않는다.
