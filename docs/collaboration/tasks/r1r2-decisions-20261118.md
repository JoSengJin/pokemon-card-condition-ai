# R1/R2 독립 평가 연결 — 사용자 결정 기록 (2026-11-19)

사용자가 에이전트 권고를 그대로 선택했다("권고대로", 2026-11-19). 새 수집·라벨·학습·외부 호출은 승인하지 않았다. 아래 미정 값은 `null`로 남기고 에이전트가 채우지 않는다.

## 결정
| 항목 | 결정 | 상태 |
|---|---|---|
| R1 기기 | 사용자 본인 휴대폰(실기기) | 기종·OS·브라우저 `null` — 사용자 제공 대기 |
| 사람 배정 | 라벨러와 개발자 분리(다른 사람) | 라벨러 ID `null` — 사용자 지정 대기. 겸직이면 independent=False |
| 집행 수단 | 별도 macOS 사용자 계정(distinct_os_identity) | 계정 생성·권한 설정은 사용자 몫(시스템·보안 설정이라 에이전트 불가) |
| 표본 | 새 eBay 수집(기존 소비된 자료 사용 불가) | 개수·기준은 에이전트가 사전 고정안을 만들어 사용자 승인을 받는다 |
| 서브에이전트 | 예행·초안·검사에만 사용. R2 완료·독립성 근거로 쓰지 않음(same_privilege_subagent) | 예행 결과 `r2-subagent-rehearsal-20261118.md` |

## 사용자만 할 수 있는 것 (최소 목록)
1. R1: 본인 폰으로 검토 화면 1회 확인 — 기종·OS·브라우저를 알려 준다.
2. R2: 라벨러가 될 사람을 정하고, 별도 macOS 계정을 만들어 시험 자료 폴더 권한을 분리한다.
3. 정답 라벨: 독립 평가용 새 사진에 대해 라벨러(사람)가 판정한다.

## 에이전트가 하는 것
- 새 eBay 수집 계획·사전 기준 초안(승인 대기), 접근 시험 시나리오(`observation_roles.py` 합성 sentinel), R1 확인용 페이지 준비.
- 합성 준비 코드(S0~S5, R1/R2 준비)는 main에 통합됨(`bfdd126`, 관찰 테스트 114건 OK).

## 이 문서가 바꾸지 않는 것
진척 점수·기준, 모델, 기존 라벨, 승인 범위. 독립 평가 증거가 생기기 전까지 일반화 개선은 미확인이다.
