## 한계·미검증
- 실제 사진·실제 휴대폰 화면 확인 없음. 사진 크기: 전체 사진 무축소라 쪽 용량은 사진 크기에 비례한다(예: 1600×2000 사진 한 장당 대략 0.5~1MB로 추정, **미측정**). 앱 미리보기가 큰 파일을 못 연 전례가 있어 `per_page`를 쓰되 알맞은 장수는 실제 사진으로 재야 한다. 두 손가락 확대가 휴대폰 보기 화면에서 되는지도 미확인(뷰포트 확대 제한은 없으나 직접 확인 안 함).
- px/mm는 03 M1 방식(처음 카드 상자 = 카드 63×88mm, 가로·세로 중 작은 값)의 추정이다. 사용자가 상자를 고치면 달라지며 기록값은 처음 상자 기준이다(`px_per_mm_basis`에 적음).
- 원본이 15.27 px/mm보다 고와도 축소하지 않는다(`SCALE=1.0`). 용량이 문제가 되면 축소를 허용할 수 있으나 상자 오차 때문에 지금은 하지 않았다.
- `.states.json` 건수와 판단 불가 비율 15% 경고(01 G1)는 만들지 않았다(표시 규칙은 승인 대상 아님, 건수만 기록).
- 정본의 미정 항목(위 문장 외)과 `판정 판본 V`는 그대로다. 이 화면으로 받은 라벨의 개선·정확도 효과는 말할 수 없다(기준과 화면이 함께 바뀜).
