## 목표

모델·worker 변경과 사람 정답/평가 보호, 자동 교차 검토의 오류 재개를 다루는 개발을 시작하기 전에, 페어코딩 인계와 진척 보고에 적용할 프로젝트 절차·권한·금지 사항을 읽기 전용으로 확인한다. 실제 구현이나 새 실험을 시작하는 작업이 아니다.

## 이번 권한과 경계

저장소의 추적 파일을 읽는 것만 허용한다. 어떤 파일도 수정하지 않는다. 파일 열람과 Git 상태 확인을 위한 읽기 전용 명령만 허용하며 테스트·학습·사진 추론·자동 검토·추가 모델/외부 API·다른 에이전트는 실행하지 않는다. 데이터·키·계정 파일·Git 제외 artifacts와 다른 대화/세션 기록은 읽지 않는다. 이 과제의 승인으로 기존 일반 push 승인·호출/재개 제한을 확대하거나 줄이지 않는다. 현재 역할을 인수하거나 다른 작업을 재개하지 않는다.

## 결과

적용할 절차와 금지 사항을 근거 파일/구역과 함께 보고한다. 실제 확인한 문서와 접근할 수 없어 확인하지 못한 실행 근거를 구분한다. 문서를 읽지 않고 기억이나 추측으로 대체하지 않는다. 출력이 잘렸다면 그 구간은 미확인으로 남기거나 읽기 전용으로 확인한다. 실제 구현·실험·성능 개선·역할 이양을 완료했다고 보고하지 않는다.
