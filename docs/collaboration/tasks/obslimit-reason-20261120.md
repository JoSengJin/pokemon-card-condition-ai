## 질문

- 사유(여러 개 선택): 빛반사·흐림·가림·잘림·저해상도·심한각도·그림자·기타·모름.
- 범위(하나): 일부·대부분·모름.
- 붙여넣기 형식: `<id>=<사유+사유>|<범위>`. 사유를 고르지 않으면 `미확인`이 저장된다. 이를 정상이나 특정 사유로 채우지 않는다.

## 분석 (결과 전 고정)

1. 사유별로 누락/비교 집단의 선택 수를 센다. 분모는 각 집단에서 사유가 `미확인`이 아닌 사진 수다.
2. 사유마다 Fisher 정확 검정(양측)을 하고, 범위의 `일부` 비율도 같은 방식으로 비교한다.
3. 판정 규칙:
   - **누락 집중 사유:** 누락에서 비교보다 5장 이상 많고 Fisher p < 0.05인 사유. 이 사유를 다음 단일 가설의 대상으로 제안한다.
   - **일부 범위 집중:** 누락의 `일부` 비율이 비교보다 높고 p < 0.05이면, H2(국소 신호)가 기준을 넘지 못한 것과 별개로 국소 신호 문제를 시사한다고 기록한다. 일반화 주장은 하지 않는다.
   - **해당 없음:** 누락 집중 사유도 일부 범위 집중도 없으면 "특정 사유로 누락을 설명하지 못함"으로 기록한다. 이때는 순위 점수를 재촬영 우선순위로만 쓰고 보류로 감싸는 방향을 사용자에게 제안한다.
4. 여러 사유를 동시에 검정하므로 p 값은 다중비교 보정 없이 탐색용이다. 표본도 17 대 17로 작으므로 인과를 주장하지 않는다.
5. 사람 사유와 모델 점수를 이유로 기존 `제한` 라벨을 바꾸지 않는다.
