# 성과·진척 HTML 보고 계약

2026-10-25 사용자 요청. Codex와 Claude 모두 다음 개발 작업부터 적용한다.

- 개발 묶음의 중간 성과/최종 인계 시 실제 결과로 성과·진척 HTML을 생성 또는 갱신하고 사용자에게 연다. Markdown 링크만 주고 열기 단계를 생략하지 않는다. 지침/프롬프트 준비만 하는 턴은 실행 성과를 만들지 않는다.
- 첫 화면에 작업명·검증 코드 SHA·개발 진척률·이번 성과를 표시한다. 전체 진척률은 PROGRESS_CRITERIA.md/development-progress.json을 읽어 고정 기준 그대로 표시하고 기준 버전/근거를 함께 적는다. 테스트 통과 수·작업 단계 완료율·모델 정확도를 전체 진척률과 섞지 않는다.
- 변경 파일·핵심 diff·실제 검사 명령/결과·미실행 검사·남은 의존·리스크·롤백·근거 파일을 표시한다. 수치를 임의 생성하거나 이번에 실행하지 않은 과거 검사를 이번 성과로 표시하지 않는다. 테스트 결과가 커밋 전이면 검증 소스 SHA/변경 상태와 문서 커밋을 구별한다.
- 합성 테스트만 수행한 턴은 합성 계약/회귀 검사임을 표시하고 모델 학습/추론 여부와 실제 모델 성능 개선 미평가를 명시한다. 실제 모델 비교를 하지 않았는데 정확도/FN/FP 개선 그래프를 만들지 않는다.
- 실제 모델 성능을 새로 평가/비교한 턴은 기존 지침대로 사진 위 구역별 사람 정답·모델 출력·누락/오탐 분모·이전 대비 %p를 포함한다. 독립 시험/모델 선택/탐색 자료를 구분한다. 새 추론이 없으면 라벨/기존 근거만 표시한다.
- HTML은 외부 CDN·API·분석 스크립트 없이 로컬에서 읽을 수 있게 한다. 기본은 정적 HTML/CSS다. 원본 사진·사람 응답·비밀값·홈 절대경로를 Git에 넣지 않는다. 실자료 HTML은 Git 제외 artifacts에 두고, 추적 HTML에는 공개 가능한 합성 결과와 상대경로만 쓴다.
- 새 task에는 HTML의 정확한 산출물 경로를 allowed_files 또는 ignored 산출물 경로로 지정하고, 생성·내용 대조·열기를 checks/handoff에 포함한다. 보고서를 위해 새 범용 프레임워크나 제품 UI를 만들지 않는다.
- Codex는 사용 가능한 로컬 브라우저/앱 열기 도구로 HTML을 연다. Claude는 허용된 브라우저 도구가 있으면 사용하고, 없으면 macOS open 명령 등 현재 환경의 열기 수단을 사용한다. 파일 경로는 안전하게 인자 배열/인용해 전달하며 동적 문자열을 셸로 실행하지 않는다.
- 열기 명령 성공과 실제 렌더링 확인을 구분한다. 화면 확인 도구가 없다면 열기 요청 성공/렌더 미확인으로 적는다. 차단되면 구체 오류와 절대경로 링크를 제공하고 열었다고 주장하지 않는다. 이 보고 의무만으로 외부 서버·터널·네트워크 전송을 시작하지 않는다.
- 기존에 실행 중인 별도 세션에는 지침이 자동 전달되지 않는다. 사용자가 보내는 다음 프롬프트에 이 계약과 해당 task의 HTML 산출물/열기 지시를 포함한다.
