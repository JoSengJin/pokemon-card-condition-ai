# 앞면 새 오류10곳 원인 추적 및 개선 비교

## 확인된 사실

기존 train 앞면 정상은37구역/5실물, 결함51구역/12실물이다. 같은 앞면 실물 안에서 정상/결함 정답이 함께 존재하는 실물은0이다. 따라서 카드 무늬와 손상 효과를 분리하는 근거가 부족하다. 이것이 유일한 원인이라고 단정하지 않는다.

기존 가중치는 정상1구역인 k와 정상9구역인 a/b/c/ㄴ에 각각 정상 클래스 질량20%를 주었다. 오류10곳을 예측할 때 해당 실물은 완전히 제외하고, 다른 학습 실물을 추가로 하나씩 빼는 민감도 진단을 수행했다. 특정 정상 실물 제외만으로 일부 누락이 회복되기도 했으나 서로 영향 방향이 달랐다. 사람 정답이 잘못됐다는 뜻은 아니며 실제 학습 카드 제거는 채택하지 않았다.

## 실행 전 고정한 순차 가설

1. 희소 라벨 실물의 영향 완화: 앞면만 구역별 1/n → 1/√n, 클래스 균형 재계산. 그 외 조건 유지.
2. 가중치만으로 개선되지 않아 RGB 색상 의존성 비교: 앞면만 흑백, 기존 가중치 유지.
3. 흑백이 회복과 퇴보를 동시에 보여 색정보 손실 보완: 앞면 원본+흑백 특징을 각각1/√2배해 연결. 나머지 조건 유지.

모두 frozen MobileNet224·수렴 logistic L2=1·임계값.5·train 실물 제외 동일143구역/30실물. val/test 미사용. 각 가설은 앞 결과를 보고 정했으므로 탐색적 순차 실험이며 독립 확증 시험이 아니다. 원본 정답/운영 모델 불변.

| 후보 | 누락/93 | 오탐/50 | 원래 오류10곳 회복 | 기준 대비 새 누락/오탐 |
|---|---:|---:|---:|---:|
| 기준 RGB 앞뒤 분리 |20|19|0|—|
| 가중치 완화 |20|19|1|0/1|
| 흑백 |17|18|4|3/2|
| 원본+흑백 |19|19|2|2/1|

흑백의 누락율21.51→18.28%(-3.23%p), 오탐율38→36%(-2%p), 정확도72.73→75.52%(+2.80%p). 이것은 개발용 교차검증 수치이며 운영 정확도가 아니다. 원본+흑백 결합은 흑백 단독보다 좋은 총합을 보이지 않았다. 새 오류0 보호 기준을 모두 통과하지 못해 운영 교체하지 않는다.

## 사람 개입이 필요한 정확한 범위

카드 v와 마그마의 앞면 하단 중앙은 현재 region_labels 자체가 없고, 관찰 제한도 없는 미확인 구역이다. 이미 완료한 정답을 재요청하는 것이 아니다. 사진으로 정상/결함/판단어려움만 확인 요청했다. 답변 전 정상 또는 결함으로 저장하지 않는다. 이 정보가 있어야 같은 손상 카드 안의 정상과 결함을 함께 학습하는 대조를 진행할 수 있다. 둘 다 결함 또는 미확인일 수 있고 정상 답변을 유도하지 않는다.
