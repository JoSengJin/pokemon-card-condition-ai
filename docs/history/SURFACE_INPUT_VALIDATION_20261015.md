## 초기값 짝 비교

경계값 한 곳의 개선을 과장하지 않도록 추가 seed7·19를 먼저 계획하고, frozen/spatial을 같은 조건으로 비교했다. seed를 최고 결과 기준으로 고르지 않는다.

| 초기값 | frozen→spatial 누락 /19 | frozen→spatial 오탐 /19 |
|---|---:|---:|
| 42 | 10→9 | 2→2 |
| 7 | 2→4 | 12→12 |

일관된 개선이 아니므로 연구 후보를 운영에 채택하지 않는다. 각 seed는 같은 val 정답·사진·영역·실물을 검산했고 train만 gradient에 사용했다. 표본 다양성 부족이 실패 원인이라는 인과 확정도 하지 않는다.

## 구현·검증

- `point-experiment --surface-input context|tiles`: 표면만 학습·점수 지원. 기존 엣지 옵션과 함께 켜거나 표준화/비선형/focal/side-balance를 동시에 섞는 실험은 거부한다. 타일은 기존 고정2×2 최대 특징을 재사용하고 사람 결함점 좌표로 입력을 고르지 않는다.
- 기존 `--fine-tune-spatial`을 표면 context/tiles에도 연결. 마지막 MobileNet 공간 블록만 기존 학습률0.0001로 갱신하고 BatchNorm은 eval 상태 유지. 입력·라벨·분류기 구조를 그대로 둔다.
- 새 surface-tiles architecture를 공유 로더·RegionAnalyzer·독립 test 평가에 연결. surface 모델을 edge 모델로 잘못 읽는 메타데이터는 거부하고, 지원하지 않는 엣지는null이다. 기존 architecture·기본값·운영 fallback 유지.
- 실험 함수의 seed 기본42 유지, 유효범위 검사·보고서/향후 체크포인트에 기록. 추가 실험 seed는 Python 연구 스크립트로 지정했으며 CLI에 불필요한 옵션을 추가하지 않았다.
- 영향 범위37회귀 통과: context/tiles/공간 학습 순차·배치 API 왕복, 독립 평가의 human_point 보존과 개발 실물 유입 거부, test 파일 미사용, 기존 엣지/균형/표준화/비선형 경로.
- 실제 MPS API 각38구역 재추론: context/tiles 최대 차이0, spatial5.96e-8. 보고서의 누락·오탐과 일치. 기존 동결 manifest SHA 불변.
- wheel0.4.96 외부 다운로드 없이 빌드. 최종 변경 Python5파일을 wheel과 byte 비교한다.
- 두 전후 HTML은 원본 사진·박스·사람 정답·점수·오류를 표시하고38구역/SHA/혼동행렬/사람6점 수를 검사한다. 공간 비교에는 세 seed 결과 전체와 판정 경계 개선의 한계를 추가했다. 실제 브라우저 시각 QA는 하지 않았다. file:// 정책 차단을 우회하지 않으며 Codex 패널 열기 요청과 파일 링크를 제공한다.
