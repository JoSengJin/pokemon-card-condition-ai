# 라벨 검증 오류 이동 — 2026-10-09

## 저장 후 다음 결함 위치 자동 이동
review.html에 nextRegionTask/advanceRegionReview를 추가했다. 성공 저장 후 현재 카드 다음부터 순회해 면별 결함1이고 같은 결함의 구역1이 없는 train/val 카드로 이동한다. 제외/test/분할 미지정은 건너뛴다. 앞뒤 패널과 구역 입력을 펼치고 확인할 결함을 파란 안내로 표시한다. 사진 decode 후 스크롤해 이미지 로딩에 따른 위치 밀림을 방지한다. 다음 카드가 없으면 현재 카드의 남은 항목을 다시 찾고, 모든 항목이 끝났으면 완료 메시지와 최상단 이동을 제공한다. 라벨 값은 자동 변경하지 않는다.

tests/review_validation.test.cjs에 순서/순환/제외/test/완료/null 보존 검증 추가. 문법·JS 테스트 통과. 합성 localhost:8767에서 카드0 저장 후 카드1 앞면 모서리 결함 위치로 실제 이동·패널 펼침·파란 안내 확인. 실제 사용자 데이터는 변경하지 않았다. 사용자 서버 재시작은 불필요하고 저장 후 새로고침해야 적용된다. 정상 구역 보강·반사 위치·분할 미지정은 이 결함 위치 큐와 별도이며 아직 자동 이동 대상이 아니다.

롤백: nextRegionTask/advanceRegionReview와 안내 스타일을 제거하고 성공 저장 후 window.scrollTo 호출을 복원한다. 변경 파일은 review.html, tests/review_validation.test.cjs, 이 문서다.

## 변경
- card_condition/review.html: 저장 전 구역/면별 결함 충돌과 위치 라벨의 카드 영역 누락을 검사한다. 다른 카드의 오류도 그 카드로 이동하며 입력 상태는 state.rows에 유지한다.
- 좌표 입력의 브라우저 유효성 검사가 실패하면 접힌 패널을 펼치고 해당 입력으로 이동한다.
- 수정할 입력과 충돌 구역에 빨간 테두리, aria-invalid를 지정한다. 수정 방법 문구를 입력 아래와 저장 버튼 옆에 표시하고 입력에 포커스를 준다.
- 입력을 수정하면 이전 오류 강조를 지우며, 재저장할 때 다시 검사한다. 정상 저장 후 최상단 이동과 서버 검증은 유지한다. 라벨을 자동 수정하지 않는다.
- tests/review_validation.test.cjs: 행/면/구역 타깃, 일치 여부, null 보존, 카드 영역 누락 검사.

## 검증
node --check 통과. node tests/review_validation.test.cjs 통과. 합성 자료 localhost:8767에서 구역 모서리 관찰됨/면 모서리 정상 충돌을 만들고 저장 클릭: 입력으로 이동, focus=true, aria-invalid=true, 빨간 안내 문구 및 관련 구역 표시 확인. 해당 면 입력 수정 후 강조 해제 확인. 합성 화면에서는 저장 API를 호출하지 않았고 실제 사용자 라벨에는 접근·수정하지 않았다.

## 적용·리스크·롤백
HTML 변경이므로 서버 재시작은 필요 없다. 기존 열린 탭은 현재 입력을 먼저 저장한 뒤 새로고침해야 적용된다. 아직 저장 전이라면 기존 검증 오류를 수정해 저장하거나 입력을 별도로 보존해야 한다. 네트워크/파일 충돌 같은 비입력 오류는 저장 버튼 옆 메시지로 남는다. 3×3 스키마·모델·학습 데이터는 바꾸지 않았다.

롤백은 review.html의 clearFieldErrors/showFieldError/regionValidationIssue, 입력 ID와 오류 CSS 및 저장 전 검사 호출을 제거하고 이전 save handler로 복원한다. 기존 라벨 파일은 그대로 유지한다.
