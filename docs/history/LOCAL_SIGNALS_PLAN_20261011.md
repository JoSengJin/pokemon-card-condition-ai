# 3x3 국소 색·질감 입력 가설 — 사전 계획

0.4.44. 입력 진단에서 전역 밝기/명암이 반사·관찰 제한 없음 사진 사이에 겹쳤다. 가설: 전역 특징에 가려진 국소 밝기·채도·질감·중성 밝기 패턴을 함께 넣으면 제한 분리 순위와 실제 오류가 개선된다. 인쇄 무늬와 분리된다는 것은 가설이며 정답이 아니다.

고정 입력: observation-geometry-20261011-source.jsonl, train46/val24, 기존 box·정답·그룹·이미지 해시·MobileNet·가중 centroid 동일. 같은224px 회색padding 입력에 3x3 row-major 셀별 평균밝기/255, 인접밝기차/255, HSV채도평균/255, min(R,G,B)평균/255 총36값만 추가한다. 중성밝기는 V*(1-S)의 RGB 최소값 표현이며 반사 정답이 아니다. 특성576→612, 거리식 /D는 실제612로 그대로 적용한다. 학습 scaler·온도·새 백본·SPP·멀티태스크·검증 임계값 탐색 금지. 각 셀에 사진 라벨을 복제하지 않는다.

연구 채택 조건: baseline observation-geometry report 대비 AUROC/AP 모두 증가, 균등 BCE<ln2, FP<=7/FN<=4 중 적어도 하나 감소. 미달이면 후보 보류하고 OBSERVATION_CONSENSUS 입력 근거 경로 유지. 통과해도 독립 일반화/운영 승인이 아니다. 사진 반복분석·자료 부족을 이유로 완료 라벨 재요청하지 않는다.
