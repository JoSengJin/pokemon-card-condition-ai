# 그림자 카드 3실물 혼합 학습 검증 (2026-10-14)

## 목표와 입력

기존 기준 모델의 엣지 결함 누락을 늘리지 않으면서 그림자·그림 효과로 인한 정상 오탐을 줄이는지 확인했다. 기준은 `artifacts/kieuk14-train-20261013/combined.jsonl`과 그 `candidate224/model.pt`이다. 새로 확인한 서로 다른 실물 앞면 3장을 **train에만** 추가했다. `ㅋ-15-shadow-batch-7`은 우측 중간 엣지 결함 1구역, `ㅋ-15-shadow-batch-8`은 사람이 확대해 확인한 바깥 엣지 정상 8구역, `ㅋ-15-shadow-batch-9`는 좌하단 모서리와 맞닿은 엣지 결함 1구역이다. 다른 결함 종류·구역은 미확인으로 유지했다. 세 카드의 영역은 사용자가 직접 확인했다. `prepare.py`는 실물 ID·이미지 중복과 영역 확인·필수 라벨을 검사한다.

## 고정 비교와 결과

- 한 번에 바꾼 요소: 위 세 실물의 사람 확인 train 입력 추가. `tiles`, 224px, 20 epoch, `--balance --balanced-selection`, seed 42는 동일하다.
- 모델선택용 기존 val의 이미지·영역·정답 50구역은 학습 전후 동일하다. 이 중 엣지 정답이 있는 27구역(결함 15, 정상 12)만 비교했다. test 사진은 학습·모델선택에 사용하지 않았다.
- 기존 기준: TP 15 / TN 7 / FP 5 / FN 0. 결함 누락 **0/15(0%)**, 정상 오탐 **5/12(41.7%)**.
- 새 후보: TP 14 / TN 8 / FP 4 / FN 1. 결함 누락 **1/15(6.7%, +6.7%p)**, 정상 오탐 **4/12(33.3%, −8.3%p)**.
- 바뀐 구역은 `d/front` 좌측 중간 정상 오탐 해소(엣지 점수 0.5418→0.4943)와 `ebay-7db839f540a696/back` 하단 중앙 실제 결함 누락(0.5009→0.4447)뿐이다.
- 후보에서 판정 기준을 0.44로 낮추면 같은 val에서 누락 0/15가 되지만 오탐은 7/12로 늘어난다. 같은 val을 보고 경계를 바꾸는 것은 독립 성능 증거도 아니다.
- 27구역의 점수 변화는 정상 12구역 중 10곳, 실제 결함 15구역 중 10곳에서 모두 하향했다. 평균 변화는 각각 −0.0339, −0.0176이다. 결함/정상 분리가 일방적으로 좋아졌다기보다 점수 경계 이동의 영향이 크다는 **진단**이며, 원인을 확정한 것은 아니다.
- 기존 동일 train의 448px 후보도 놓친 뒷면 하단 중앙 결함 점수가 0.4995였다(224px 기준 0.5009). 두 해상도가 모두 판정 경계에 걸쳐 있어, 이 한 사례의 누락을 단순히 224px 축소만의 탓으로 단정할 근거는 없다. 448px 전체 val 결과도 누락1/15·오탐7/12로 기준보다 나빴다.

사전 수용 기준인 `FN≤0` 및 `FP<5`를 동시에 만족하지 못하므로 **후보 미채택**. 사용자 우선순위인 중요한 결함 누락 방지에도 맞지 않는다. 기존 기준 모델과 운영 Gemini fallback은 유지한다. 독립 정확도 향상은 확인되지 않았고 실제 Gemini 호출 절감은 0건이다. 이 val은 반복 모델선택에 사용했으므로 새 실물 독립 시험의 대용이 아니다.

사진 위 사람 정답·구역 점수·두 모델의 오탐/누락은 [시각 HTML](../../artifacts/kieuk15-shadow-batch-20261014/index.html), 원시 수치는 `artifacts/kieuk15-shadow-batch-20261014/result.json`과 각 `candidate224/report.json`에 있다.

## 검증·리스크·롤백

- `prepare.py` 실행으로 중복·영역·라벨 guard를 통과했고 학습 스냅샷을 생성했다.
- `point_rows(..., splits={'val'})` 50행 전체가 전후 동일함을 확인했다. `make_review.py`가 엣지 정답 27행의 이미지 해시·영역·정답 일치와 혼동행렬을 재검산했다.
- 후보 학습 명령: `.venv/bin/card-condition point-experiment artifacts/kieuk15-shadow-batch-20261014/combined-reviewed.jsonl artifacts/kieuk15-shadow-batch-20261014/candidate224 --edge-input tiles --image-size 224 --epochs 20 --balance --balanced-selection`.
- 리스크: 기존 val에 대한 반복 시험이라 수치가 낙관적일 수 있다. 0.5 근처 점수와 저해상도 그림자 사진에서 작은 결함 판정이 불안정하다. img_9의 엣지 결함은 구역 라벨로 확인됐으며 별도의 엣지 클릭 좌표는 받지 않았다.
- 롤백: 이 후보는 운영 경로에 연결되지 않았다. 실험을 되돌릴 때 `artifacts/kieuk15-shadow-batch-20261014/`와 `data/kieuk15-shadow-batch-intake-20261014.jsonl`만 제거하면 된다. 기존 기준 모델·manifest는 변경하지 않았다.

다음 단계는 같은 val에서 임계값을 재조정하기보다, **새 실물에서 사전 동결한 엣지 결함·정상 구역**으로 누락/오탐을 독립 확인하는 것이다. 새 사진이 없으면 운영 채택을 보류한다.
