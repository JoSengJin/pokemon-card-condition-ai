## 이번 결론
계속 모든 후보를 라벨링할 필요가 없다. a/b/c 등의 추가 저장 자료를 학습에 반영했다. 이번 snapshot의 train 정상 구역은 모서리13·엣지25·표면28개이며, 각 항목은 실물 그룹4개에 걸친다. 구역 수보다 실물 다양성이 중요하다. 구역123개(train85/val38), 위치 미지정0개. 현재 작업 중인 f 입력과 독립적인 고정 snapshot을 사용했다.

## 차용한 원칙과 적용 범위
Label Studio의 모델 연계 검토, Cleanlab ActiveLab의 제한된 라벨 비용 배분 원칙을 참고했다. 특정 회사/AI가 우리 프로젝트에서 성능을 보장한다는 뜻은 아니다.
- https://labelstud.io/guide/ml.html
- https://cleanlab.ai/blog/learn/active-learning/

이번 구현은 모델 불확실성 점수 기반의 완전한 능동학습이 아니라, 부족한 정상 종류와 실물 다양성을 기준으로 묶음을 고르는 작은 첫 단계다. 현재 모델 점수만으로 정답을 자동 채우거나 사람 정답을 덮어쓰지 않는다. 낮은 점수가 사람이 틀렸다는 증거는 아니다.

## 코드 변경 / 동작
card_condition/review.html: 정상 보강 묶음을 시작할 때 최대3개 실물 그룹을 고정한다. 한 그룹당 한 면을 선택한다. 정상 그룹이 적은 결함 종류, 그 종류에 아직 정상 정답이 없는 그룹을 우선한다. 같은 면의 필요한 항목을 함께 안내하고 남은 후보 수를 표시한다. 저장 후 다음 후보로 이동하며 고정 묶음이 끝나면 자동 중단한다. 건너뛰기는 정답을 만들지 않으며 이번 묶음에서 해당 카드만 뺀다. val/test/제외 자료는 후보가 아니다. 이미지·그룹·분할 변경으로 오래된 후보가 되면 적용하지 않는다.
3장은 사람 작업량 제한이며 모델 정확도나 자료 충분성 기준이 아니다. 일부 구역 정답만 있어도 다음 실험으로 진행할 수 있으며 모든 칸을 채울 필요가 없다. 묶음은 페이지에서 유지되고 새로고침하면 종료된다. 정답은 기존 JSONL 저장 방식으로 영속한다.
tests/review_validation.test.cjs: 3그룹 상한, 동일 실물 중복 제외, val/test 제외, 건너뛰기의 라벨 무변경, 더 많은 후보가 있어도 묶음 종료, 사진 변경 방어 검사.
문서: REGION_HUMAN_REVIEW_20261009.md, master CONDITION_ANALYSIS_TODO.md를 현재 단계에 맞춰 갱신.

## 동일 검증 자료 비교
아래 수치는 오탐(FP)/누락(FN)이다. 세 실험의 검증 사진·영역·정답은 일치함을 검사했다.

| 종류 | 보강 전5회 | 보강 후5회 | 보강 후20회 |
|---|---:|---:|---:|
| 모서리 | 4 / 0 | 2 / 2 | 2 / 1 |
| 엣지 | 8 / 3 | 3 / 10 | 4 / 5 |
| 표면 | 10 / 2 | 12 / 0 | 9 / 2 |

보강 전/후5회는 학습 자료 변화, 보강 후5/20회는 학습 회차 변화만 비교했다. 20회 모델은 선택 epoch20. 일부 정상 오탐이 감소했지만 손상 누락이 남거나 늘어 운영 채택하지 않았다. 작은 val을 반복 참고한 개발 결과이며 독립 최종 성능이 아니다. 모서리 정상 검증 구역6개가 한 실물 그룹(d)에 몰려 있으므로 구역 수를 독립 표본 수로 해석하지 않는다.
근거 artifacts/region-efficient-round-comparison-20261009.json, 각 run의 model.pt/report.json. 실제 Gemini 호출 절감0건.

## 검증
Node 회귀검사 통과. 합성6장 임시 서버에서 0→1→2 카드의 구역 라벨을 브라우저로 저장했고 남은 수3/3→2/3→1/3→종료를 확인했다. 영속 파일에서 지정한3개 정답만 저장되고 나머지3장의 구역과 미확인은 바뀌지 않았음을 확인했다. 실제8766은 미저장 입력 없음 확인 후 새로고침했으며 f 화면을 유지했다. 사용자 정답은 수정하지 않았다. 서버 재시작 없음.
