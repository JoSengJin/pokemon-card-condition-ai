# 검증 매물 전체 지원 구역 추론 — 2026-10-10

## 완료 결과

0.4.29에 `listing-infer <manifest> <checkpoint> <새 report.json> --device mps`를 추가했다. 기존 비교 보고서는 정답 있는 일부 구역의 예측만 매물 집계에 전달했으므로 미예측 구역이 많았다. 새 명령은 val 매물의 카드 box와 관찰 제한만 사용해 모델이 지원하는 모든 해당 구역을 추론한다. 정답의 0/1/null, 사람 결함 점, 구역 검토 완료 여부로 추론 구역을 고르지 않는다. 점수는 새로운 학습 라벨로 저장하지 않는다.

기존 point_probe의 체크포인트 로더와 edge_views.patch_features, listing_readiness의 보수적 집계를 재사용한다. context/views/tiles 및 구형224 checkpoint 정책을 동일하게 적용한다. 반사 위치가 있으면 해당 구역만 건너뛰고, 위치 없는 반사나 다른 관찰 제한은 해당 면 전체를 건너뛴다. 카드 box가 없거나 사진이 없는 면은 추론하지 않는다. 미지원 항목·가림·사진 부족·모델 보류를 구분한다. 반사는 카드 손상 또는 구매 거절로 변환하지 않는다.

학습·임계값 선택·운영 분기·Gemini 호출은 없다. train/test 분할 사진은 이 명령에서 읽지 않는다. val 자료를 실행하는 개발용 명령이며 임의 매물 운영 API나 최종시험 평가 명령으로 취급하지 않는다. 전체 gradable 라벨의 미확인 여부와 무관하게 require_gradable=False로 읽지만, 데이터 형식과 카드영역·관찰 제한 형식은 기존 검증을 유지한다. 실패 시 Gemini 생략 결과를 반환하지 않고 오류로 중단한다. 입력 manifest/checkpoint/val 원본 사진이 실행 중 바뀌면 보고서를 저장하지 않는다. 기존 출력 파일 덮어쓰기도 거부한다.
