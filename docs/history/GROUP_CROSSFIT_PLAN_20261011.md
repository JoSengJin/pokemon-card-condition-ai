# train 실물 전체 제외 교차검증 — 사전 계획0.4.47

앞뒤별 centroid의 고정val 개선 후 확인할 질문: 학습 자료에서 실물 한 장을 통째로 제외해도 공통 기준 대비 오류 감소가 나타나는가?

train만 읽고 같은 실물의 앞뒤/다른 사진 전체를 같은 fold로 제외한다. 검증·test 이미지/라벨은 읽지 않는다. 고정 MobileNet576차원/box/224px에서 공통 centroid와 면별 centroid를 각 fold 나머지 train으로 fit한다. 제외 실물의 특징/정답은 해당 fit/가중치/대표값에 사용하지 않는다. 관찰 제한은 카드 불량이 아니다.

leave-one-group-out 모든 실물에 대해 실행. 어느 면의 학습 제한/비제한이 부족하면 해당 fold는 두 후보 모두 비교 제외하고 이유/분모를 기록한다. 모든 fold 불가면 실행 실패. fold 간 중복 이미지/실물은 기존 manifest 검증을 따른다. 사진 정답 변경/기존 val 분할 이동/임계값 선택/새 배율 탐색 없음. 모델/학습 checkpoint를 운영용으로 저장하지 않는다.

진단 기준: 공통 기준보다 면별 후보의 FP/FN이 모두 비증가하고 하나 감소, AUROC/AP가 모두 증가하고 클래스·실물 균등 BCE<ln2이면 일관된 방향으로 기록한다. 아니라면 fixed-val 개선만 보고 일반화 근거를 확장하지 않는다. 개발에 이미 사용한 train이므로 이 검산도 독립 최종평가가 아니다. 완료 라벨 재요청 금지.
