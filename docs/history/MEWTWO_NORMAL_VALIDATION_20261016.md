# 뮤츠 앞면 정상 구역 반영

사용자 답변을 표시했던 구역에만 적용: 뮤츠 앞면 좌측 중간 surface=0. 고우스트 앞면 우측 중간은 디자인인지 기스인지 판단 어려움(null) 유지. 전체 카드 정상으로 확장하지 않았으며 기존 결함점을 변경하지 않았다. 별도 manifest/human-intake와 pending-human 상태에 기록.

변경 요인은 정상 구역1개뿐. 기존 흑백224앞면/RGB뒷면·평균 특징·고정 MobileNet·앞뒤 head·실물/클래스 균형·logistic L2=1·임계값.5를 유지했다. 실물 전체를 제외하는 개발 평가에서 기존144구역을 동일 분모로 비교하고 새 뮤츠1구역은 별도 표시했다.

결함 누락17→17/93(18.28%, 변화0%p), 정상 오탐18→17/51(35.29→33.33%, -1.96%p). 정확도75.69→76.39%(+0.69%p). 이전143구역 보고와 분모가 다르므로 이전 숫자에 직접 이어붙이지 않는다. 총합 개선 중 새 누락1곳·새 오탐1곳 발생, 기존 오류3곳 회복. 퇴보 방지 기준 미통과로 운영 교체 없음. 개발 단계4/6 유지, 독립 일반화 개선은 미확인.

검증: 새1구역 외 기존 row 불변, 실물/이미지 train-heldout 분리, 수렴, 뮤츠 제외 fold에서 새 정답도 제외되어 기존 뮤츠 점수1e-5미만 불변, 원본 manifest 바이트 불변 assert 통과. 관련 unittest16개 통과. HTML에 변경된 모든 구역의 정답과 전후 점수 표시.

파일: artifacts/mewtwo-confirmed-20261016의 run.py, combined-reviewed.jsonl, human-intake.json, plan.json, result.json, index.html/구역사진. 이전 front-input-review pending-human.json의 답변 처리 상태. 본 문서 및 소비 TODO. 패키지/운영/원본 라벨은 변경하지 않음.
