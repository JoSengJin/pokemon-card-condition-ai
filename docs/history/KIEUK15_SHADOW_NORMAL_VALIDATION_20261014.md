# 약한 그림자 아래 정상 엣지 1구역 보강 (2026-10-14)

사용자가 `learn/ㅋ/15/img_6.png`를 기존 카드와 다른 실물로 제공했고 좌하단 바깥 테두리가 그림자 속에서도 충분히 보이며 정상이라고 확인했다. 사용자가 검토 화면에서 제안 카드 영역도 확인·저장했다. 이 사진은 `ㅋ-15-front-shadow-normal-6` train 그룹으로 별도 등록하고, **좌하단 엣지 1구역만 정상**으로 보존했다. 나머지 엣지·모서리·표면은 미확인이다. `그늘·어두움`은 관찰을 막는 경우에만 제한 라벨이므로, 이번 판독 가능한 약한 그림자는 사진 설명에만 기록했다.

사전 계획 `artifacts/kieuk15-shadow-normal-20261014/plan.json`은 직전 후보의 manifest·모델 해시, 단일 추가 입력, 고정된 타일224·20epoch·balance·balanced-selection, 누락 0·오탐 5 미만의 채택 조건을 담는다. `prepare.py`는 사람 영역 확인, 좌하단 정상 라벨의 실제 학습 패치 생성, 그룹·디코딩 이미지 중복, 기존 스냅샷 해시를 검증했다. val/test 사진은 학습에 넣지 않았다.

정상 오탐은 **−8.3%p**지만 결함 누락은 **+6.7%p**다. 기존 기준 모델은 누락 0/15·오탐 5/12였다. 이번 후보는 사전 조건을 만족하지 못해 **미채택**이다. 반복 사용한 val이므로 독립 정확도 향상은 미확인이고 운영 모델·Gemini fallback은 불변이다. 실제 Gemini 호출 절감은 0건, 개발 진척률은 4/6(약 67%)다.

`artifacts/kieuk15-shadow-normal-20261014/index.html`은 동일한 27구역 사람 정답과 전후 출력·바뀐 네 구역의 사진 위 3×3 위치를 보여준다. `make_review.py`가 정답·카드 영역·이미지 해시·분모·혼동행렬 일치를 검산했다. `tests/test_point_dataset.py` 7개와 기존 검토 화면 JavaScript 회귀 검사는 통과했다.
