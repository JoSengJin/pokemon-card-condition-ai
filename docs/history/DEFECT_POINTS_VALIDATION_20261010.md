# 다중 결함 지점 기록 — 2026-10-10

## 동작과 계약

사용자가 s 뒷면 안쪽 인쇄면 벗겨짐을 표면 결함으로 확인했다. 모서리 정상0 / 표면 결함1 / 엣지 null 구역 라벨을 유지했다. 정확한 위치는 모델이 추정하지 않고 사람이 마우스로 여러 곳 찍는다.

각 면의 `defect_points`는 선택 필드이고 `{label,x,y}` 목록이다. label은 corner_defect/edge_defect/surface_defect. x,y는 EXIF 방향을 적용한 원본 사진에 대한0~1 좌표이며 카드 영역 안이어야 한다. 이 점은 위치 설명용이고 기존 면/구역 라벨을 자동으로 바꾸거나 학습 정답으로 생성하지 않는다. 없으면 기존 데이터와 동일하다. 학습에 사용하는 후속 변경은 별도 위치 입력 실험으로 검증해야 한다.

UI: 종류 선택, 클릭 모드 켜기, 다중 클릭, 번호 표시, 개별 삭제, 키보드% 추가, 라벨 저장, 재로드 복원. 점 목록은 사진 아래에 두어 추가 시 사진이 밀리지 않는다. 카드 영역 변경 시 점 삭제, 사진 변경 시 면 주석 초기화. 저장은 기존 revision 충돌 검사·백업·atomic write를 사용한다. 내보내기도 같은 메타데이터를 보존한다.
