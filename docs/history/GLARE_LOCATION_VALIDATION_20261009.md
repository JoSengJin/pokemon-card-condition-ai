# 반사 위치 라벨 — 2026-10-09

앞면·뒷면별 카드 영역 안에서 반사 때문에 확인하기 어려운 위치를 3×3 구역으로 복수 선택한다. 이 정보는 관찰 제한이며 결함 정답이 아니다. 보이는 결함은 기존 면별 라벨에 기록하고, 가려져 확인할 수 없는 결함은 미확인으로 남긴다.

## 변경
- `card_condition/regions.py`: 선택적 `glare_areas` 형식 검증. 위치가 있으면 카드 영역과 `glare` 사유가 필요하다. 알 수 없는 코드·중복·잘못된 형식을 거부한다.
- `card_condition/review.html`: 위치 선택, 반사 해제/카드 영역 삭제 시 위치 초기화, 안내 문구.
- `tests/test_regions.py`: 저장·내보내기 보존, 잘못된 위치 거부, 구형 라벨 호환성.
- `README.md`: 사용법과 TODO 진행 기록.

## 검증
- `.venv/bin/python -m unittest discover -s tests -q`: 26개 통과. 실제 로컬 HTTP 테스트 포함.
- 현재 review.html의 script를 `node --check`로 검사: 통과.
- 실행 중인 8766 서버에서 수정 HTML 제공 확인. 브라우저 클릭 동작의 시각 검증은 수행하지 않았다.

## 한계와 다음 단계
3×3 위치는 정확한 반사 경계나 면적을 표현하지 못한다. 기울어진 카드의 위치는 사진에 보이는 방향을 기준으로 기록한다. 선택 사항이므로 기존 라벨을 다시 저장할 필요는 없다.

현재 학습 모델은 이 정보를 입력으로 사용하지 않는다. 자동 마스킹이나 미확인 라벨 생성도 하지 않는다. 위치 라벨이 확보되면 train/val 분할을 유지한 채 가려진 위치별 오류를 먼저 확인하고, 필요한 경우에만 영역 모델을 실험한다. 이 변경으로 정확도 향상이나 Gemini 호출 절감을 입증한 것은 아니다.

## 롤백
모델 파일과 기존 라벨은 보존한다. UI의 glareAreas/위치 선택 컨트롤을 제거하고 regions.py에서 glare_areas를 선택적 메타데이터로 계속 허용하면, 이미 저장한 라벨을 손실 없이 유지하면서 기능을 중지할 수 있다. 해당 테스트와 README 항목을 함께 되돌린다. 이 디렉터리는 Git 저장소가 아니므로 git revert는 사용할 수 없다.
