# 중요한 관찰 제한 누락 우선 검증 — 0.4.82

실제 Google·Claude 모델/관계자를 호출하지 않은 내부 모의 기술 검토다. 입력 개선과 평가 설계 관점의 검토를 반영했다. 마지막 후속 에이전트 검토는 사용량 한도로 종료되어, 후속 결과는 본 세션에서 파일·실행으로 확인했다.

## 결과와 채택 결정

프테라의 저장된 앞면 `visibility_issues=['glare']`와 확인된 box를 사용했다. 면별 gradable은 null이지만 비어 있지 않은 제한 사유를 양성으로 취급하는 기존 계약에 부합한다. 원본 라벨/검토자를 임의 수정하지 않았다. 관찰 제한은 물리적 손상이나 구매 부적합 정답이 아니다.

| 같은 평가 집합 | 변경 | 누락 FN | 오탐 FP | 해석 |
|---|---|---:|---:|---|
| 기존 train 24면, 제한4/정상20, 실물 제외 평가 | 프테라 한 장 보강 전→후 | 4→2 | 5→3 | 누락률100→50%(-50%p), 오탐률25→15%(-10%p), 정확도62.5→79.17%(+16.67%p) |
| 보강 train25면, 제한5/정상20, 실물 제외 평가 | global→원본2×2 | 2→2 | 3→0 | 타일로 누락이 줄지는 않음 |
| 동일 train25면 | 원본2×2→원본3×3 | 2→3 | 0→1 | 세분화 가설 기각 |
| 재사용 val11면, 제한2/정상9 | global→원본2×2 | 0→1 | 1→1 | 중요 제한 누락 악화, 타일 교체 기각 |

신규 25면 전체의 수치와 이전24면의 정확도를 직접 비교하지 않는다. train 실물 제외 결과는 개발 중 반복 사용된 자료의 진단이며 독립 시험 성능이 아니다. val11도 재사용 모델선택 자료다. **물리적 기스·엣지·모서리 누락 개선은 이번 실험으로 입증하지 않았다.**

자동 정상 통과 정책은 내부 실물 제외 점수로만 경계를 정했다. 외부 실물 제외 평가에서 제한1/5를 위험하게 통과시키고 정상0/20을 통과시켰다. 나머지24/25 보류를 정답으로 계산하지 않는다. 안전성·효용 모두 부족하여 미채택.
