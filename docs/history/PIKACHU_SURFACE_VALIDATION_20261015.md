# 피카츄 표면 결함 보강 검증

사용자가 직접 확인한 뒷면6점은 모두 표면 결함으로 유지하고, 뒷면 카드 영역 확인만 기록했다. 앞면 영역·정상 엣지 제안·앞뒤 동일 실물은 미확인 유지. 사용자 저장 파일의 기존6점 좌표·종류를 보존했다. 검토자는 기존 J 관례로 기록하고 근거를 notes에 남겼다.

## 실험 결과

기존 마그마 표면 보강 자료에 피카츄 뒷면만 train으로 추가했다. 6점은3×3 표면4구역으로 합쳐졌으며, 모서리/엣지 라벨은 추가0개다. val38구역(손상19·정상19)의 사진·영역·정답·실물은 변경하지 않았다. test는 미사용. 고정 MobileNet·224px·20회·seed42·기존 균형/val BCE 선택 설정 유지.

보강 전후 TP9/TN17/FP2/FN10 동일. 누락10/19=52.63%, 오탐2/19=10.53%, 각각 변화0.00%p. 사전 조건인 누락 비증가·오탐 감소 미달로 채택하지 않았다. 선택 회차1이며20회차는 누락10/오탐12로 악화했다. 기존 모델 유지·독립 정확도 개선 미확인·실제 Gemini 절감0건·개발단계4/6 약67%.

## 진단·검증

- 학습 표면 정상은 앞면37구역/5실물·뒷면1구역/1실물, 손상은 앞면51구역/12실물·뒷면41구역/15실물. 정상 뒷면이 적다는 사실을 확인했지만 실패 원인이라는 인과 주장은 하지 않는다.
- 중복 실물/id/decoded 사진 차단·동결 자료 SHA·val 불변·미확인 앞면 제외·새 표면4구역만 추가를 prepare.py로 검증.
- 관련 부분 라벨/승인/저장 Python25회귀 통과.
- 실제 저장 체크포인트 RegionAnalyzer MPS38구역 재추론: 최대 점수차0, 혼동행렬 동일. 실험 중 사용자 저장 파일 SHA 불변.
- HTML은 원본 검증 사진의 보강 전후 구역별 정답·모델 점수·누락/오탐과 사용자6점을 포함한다. 생성 시 두 보고서/manifest SHA·동일38정답·혼동행렬·표시한6점 수를 검산한다. 실제 브라우저 시각 QA는 하지 않았다. file:// 방문은 이전에 browser-use 정책으로 차단돼 우회하지 않으며 Codex 패널 열기 요청과 파일 링크를 제공한다.
