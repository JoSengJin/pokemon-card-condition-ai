# 한국어 검토 응답과 단계별 다음 행동

이번 수용기준3/3 완료: 새응답한국어요청/기존상태호환, 단계별지금하는일안내, 출력에서할수있는다음행동안내. 새실제Gemini생성을요청한작업은아니므로추가실호출0회·한국어실응답검증은mock범위다. 모델성능을개선한작업이아니다.

## 출력 언어

새수동검토의prompt_version을cross-review-ko-v2로지정한다. JSON키/가설ID/근거ID/파일명/기술명은유지하고자연어설명은한국어로요청한다. 원인가설은높은점수라는증상과인과를구분하고학습손실/추론임계값을혼동하지않도록한다. 최소실험은변수하나/대조조건, 성공실패는동일전체평가/실제사람점의새누락으로정의하도록요청한다.

핵심cause/실험설명이비어있지않으면서한글이전혀없으면응답은원문으로저장하되터미널영문설명대신한국어조건미충족을표시하고종료한다. 자동번역이나자동재호출로호출예산을소비하지않는다. 이검사는모든문장의완전한한국어품질을보장하지않으며기술ID/수식/파일명은영문그대로필요하다.

기존cross-review-v1프롬프트/기존cache해시/run ID계산은보존한다. prompt_version없는기존config는v1로해석해checkpoint를재개한다. KO프롬프트는별도버전/cache를쓴다. 과거영문응답을조용히번역된실제응답으로바꾸지않는다. 기존검토를재개하면이전응답임을안내하며추가호출없이원문복원, 새검토부터한국어요청을적용한다.

## 지금 하는 일 · 다음 행동

1. 근거준비: 최신실험경로와기존오탐/누락전후수치, 실제사람점누락을표시한다. 현재저장결과를읽은것이며새성능평가가아님을표시한다.
2. Gemini검토: 자료를비판검토하거나저장된검토를복원하는단계임을표시한다. 여기서는학습·코드수정·제안실험을실행하지않는다.
3. 사용자근거대조: 원인가설은미검증, 최소실험은미실행제안이라고표시한다. 근거와반대근거/단일변수/대조조건/성공실패기준을확인하도록안내한다. 사용한호출/남은횟수를표시한다. r은새반증질문과근거ID로다시검토, Enter는검토종료, q는저장이다. 상한이나사람근거의존이있으면r을메뉴에서숨기고사유를표시한다.
4. 저장·종료: 종료이유를한국어로보여주고결과파일/호출시도/실제usage를표시한다. 미기재usage는미확인이다.

모델실험은별도구현·검증작업으로요청해야한다. Enter를눌렀다고모델을훈련하거나가설을실행하는것이아니다. 합의도모델성능증거가아니다.

## 사용자가 제시한 현재 가설 해설

현재보존된응답의“normal-bag objective ... high patch logits ... smooth upper bound threshold”는대략“정상구간안의일부패치가높은손상점수를내므로오탐이남는다”는뜻이다. 그러나높은점수는증상이며그원인이logsumexp인지입증하지못한다.

card_condition/point_patch_head.py:20의logsumexp는학습할때정상bag손실을계산하는함수다. artifacts/edge-normal-objective-20261019/run.py:33의실제출력은유효패치최대logit에sigmoid를적용한다. 저장평가는0.5임계값이다. smooth upper bound를추론임계값으로묘사한부분은구분해야한다.

이실험은이미기존저장기록에서오탐5→3/22, 결함누락0/4와실제점누락0/4유지였다. 손실자체가오탐원인이라고단정할근거가없다. 후속geometry진단은추가오탐개선0, positive geometry검증0이었다. 지금턴에서새추론·학습·성능평가는없다.

r로물어볼수있는구체적인질문:

“max_bound는이미오탐5→3을줄였다. 높은점수라는증상과손실함수가원인이라는가설을구분해라. 나머지를고정하고변수하나만바꾸는대조실험과실패판정기준을제시해라.”

현재근거ID예시는related_code,latest_result,latest_diagnostic이다. 이는실험설계검토질문이며자동실험실행명령이아니다.
