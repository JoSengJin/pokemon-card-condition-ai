# train-only 특징 표준화 — 사전 계획 0.4.45

가설: 기존 국소 특징 추가가 거리 단위에 묻혔으므로, 같은612차원을 train 통계만으로 표준화하면 관찰 제한 분리 성능이 개선된다. 색·무늬와 촬영 제한을 구별한다는 주장은 검증 대상이다.

단일 변경: train 실물별 동일 총가중치로 차원별 평균/표준편차를 계산한다. 같은 실물 여러 사진의 통계 독점 방지. 상태/관찰 정답을 통계 가중치에 사용하지 않는다. 표준편차 하한1e-6(상수 차원 0나눔 방지), 임의 클리핑/배율 탐색 없음. 학습·val·재추론 모두 (x-mean)/scale 적용. 체크포인트에 train 통계를 저장. centroid 학습의 클래스·실물 가중치와 /612 거리식은 유지.

동일 observation-geometry-20261011-source.jsonl, train46면/25실물·val24면/14실물·사진/box/라벨/576+36특징·MobileNet·0.5판정 유지. --local-signals --centroid 조건에서만 --standardize 선택. 기본은 꺼짐. val로 fit/재학습/임계값 선택 금지, test 사용 금지.

기준 모델은 observation-geometry-20261011. 연구 채택: AUROC/AP 모두 증가, 균등BCE<ln2, FP<=7/FN<=4이며 하나 이상 감소. 동일 검증 재사용으로 독립 일반화·운영 승인은 아님. 미달이면 후보 보류. 완료 라벨·기존 원본 부재 답변 보존.
