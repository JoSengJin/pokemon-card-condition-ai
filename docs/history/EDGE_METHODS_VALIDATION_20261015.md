# 0.4.95 · 엣지 학습 방법 비교와 꼬부기 승인 자료 보강

## 결과와 판정

유지 기준의 같은 val27구역(손상15·정상12)은 누락0/오탐5다. 사전 연구 채택 조건은 누락0 유지·오탐5 미만이며, 반복 사용한 val의 개선도 독립 성능 향상을 뜻하지 않는다. 아래 후보는 운영에 적용하지 않았다.

| 모델 | 누락 /15 | 오탐 /12 |
|---|---:|---:|
| 유지 기준 | 0 | 5 |
| 꼬렛 승인 보강 · 기존 선형 | 2 | 6 |
| 같은 자료 · train 전용 표준화 | 6 | 4 |
| 같은 자료 · 8단위 Tanh 분류기 | 1 | 5 |
| 같은 비선형 · gamma2 focal loss | 3 | 4 |
| 꼬부기 정상7구역 추가 · 기존 선형 | 2 | 5 |
| 같은 보강 자료 · 작은 비선형 | 3 | 5 |

비선형 분류기는 동일 자료 선형 대조군보다 누락1곳·오탐1곳을 줄였다. 표준화와 focal loss는 오탐 감소와 함께 누락이 늘어 탈락했다. 낮은 BCE만으로 중요한 결함을 덜 놓친다고 판단하지 않는다. 해상도224·타일 입력·고정 MobileNet·20회·seed42·기존 실물/클래스 균형·val BCE 선택은 고정했다. 기존 기준 자료와 꼬렛 보강 자료는 서로 다르므로 그 비교를 순수 분류기 효과로 주장하지 않는다.

## 구현과 누수 방지

- `--standardize-features`: 학습 실물 균등 가중치만 사용해 특징 평균/표준편차를 구하고 최소표준편차0.001을 적용한다. val/test로 통계를 학습하지 않는다. 저장 시 선형 가중치에 수학적으로 합쳐 기존 추론 입력을 유지한다.
- `--nonlinear-head`: 기존 선형 대신 Linear→Tanh→Linear의 8단위 분류기를 선택한다. 체크포인트 head_hidden으로 공유 로더가 동일 구조를 복원하며 구형 체크포인트는 기존 선형이다.
- `--focal-loss`: train BCE에 (1-p_t)^2를 곱한다. val의 기존 BCE 선택 기준은 바꾸지 않는다. 표준화·비선형을 무계획하게 함께 켜는 조합은 거부한다. focal은 별도 비선형 대조군과 비교했다.
- 모두 선택 실험 옵션이다. 기존 기본값·운영 모델·Gemini 분기는 바꾸지 않았다. 데이터 증강을 정상 정답으로 만들거나 사용자 결함점을 자동 수정하지 않았다.

## 꼬부기 휴먼인루프

사용자 답변 ‘내가 클릭한 우측상단 말곤 정상이야’를 근거로 꼬부기 뒷면 엣지7구역만 기존 승인 API를 통해 기록했다. 우측상단의 정상 제안은 거절하고 엣지는 미확인, 기존 앞면 모서리2점·뒷면 모서리1점은 그대로 유지했다. 피카츄와 앞면 정상 후보는 승인하지 않았다. 모서리 손상과 엣지 손상을 임의로 동일시하지 않았다. snapshot·사진 SHA·영역·출처·검토 기록은 artifacts/squirtle-approved-20261015에 보존한다.

train-only 신규1실물·10패치 중 엣지 정상7/손상0만 추가했다. 실물/id/decoded image 중복 차단, 기존 val50패치(엣지 정답27) 동일, test 미사용을 prepare.py로 검증했다. source 작업파일을 모델 실험 중 수정하지 않는다.

## 검증

- 관련 Python 회귀33건 통과: 표준화 누수 방지·동일 실물 가중치·접은 선형 출력 일치·옵션 검증·체크포인트 기존 API 왕복·focal 유한 gradient·기존 구역/point/API/균형 경로.
- 학습 방법3모델과 꼬부기 보강2모델을 실제 MPS RegionAnalyzer로 각27구역 재추론. 최대 출력 차이 표준화1.49e-7, 비선형0, focal0. 꼬부기 보강 두 모델의 최대 출력 차이도0이었다. 누락·오탐 모두 보고서와 동일.
- HTML은 모든 모델의 원본 val 사진·영역·정답·SHA 일치 및 지표 재계산을 검사한 뒤 생성한다. 선택 변경을 Node DOM 대역에서 실제 실행해7모델×27셀 점수·오탐·누락을 검산했다. 실제 브라우저 시각 QA와 구분한다.
- wheel0.4.95를 외부 다운로드 없이 빌드하고 변경 Python5파일이 소스와 byte 일치함을 확인했다.
- 기존 기준 manifest/model SHA 불변 확인. 운영 모델 채택·자동 구매 제외·실제 Gemini 절감은0건.

## 변경 파일·리스크·롤백

독립 프로젝트 기준 변경 파일: card_condition/feature_scaling.py, region_head.py, region_experiment.py, point_probe.py, cli.py, tests/test_feature_scaling.py, pyproject.toml, README.md, 이 문서. 실험 계획/실행/시각화는 artifacts/edge-*-20261015와 artifacts/squirtle-*-20261015, 소비 프로젝트 CONDITION_ANALYSIS_TODO.md에 기록했다. 사용자 작업 파일은 명시적 확인7구역 승인과 우측상단 제안 거절만 변경했다.

리스크: 작은 반복 val에 모델선택이 누적돼 일반화 주장을 할 수 없다. 비선형 모델은 표본이 적어 과적합할 수 있고 focal/표준화는 중요한 누락을 늘렸다. 따라서 최적 기존 기준을 유지하며 별도 독립 자료 없이는 운영 정확도 개선이라 하지 않는다.

롤백: 세 선택 옵션을 빼고 기존 기준 체크포인트를 사용하면 기존 선형 학습·추론으로 돌아간다. 소스 자체 복원은 직전0.4.94 wheel의 원본을 사용한다. 사용자 확인 기록·원본 사진·실험 결과는 삭제하거나 예전 라벨로 덮어쓰지 않는다.

꼬부기 보강 자료에서는 비선형이 선형 대비 누락2→3·오탐5→5로 악화했다. 이전 자료에서의 개선이 새 자료에서도 유지된다고 일반화하지 않는다. 모든 후보는 사전 누락 우선 채택 조건 미달이며 유지 기준을 교체하지 않는다.

시각 HTML은 Codex 패널 열기를 요청했으나 queued 반환이며, browser-use의 file:// 방문은 URL 정책으로 거부됐다. 우회 서버나 다른 브라우저로 재시도하지 않았다. 파일 링크로 제공하고 실제 브라우저 시각 검증 완료로 보고하지 않는다.
