# 클릭 중심 라벨 입력 — 0.4.85

사용자 지정 순서: OpenCV 실험 보류 → 클릭 중심 라벨 개선 → 다양한 정상·결함 자료 보강 → 카드 상태 AI 모의 컨설팅 합의안 후속 개발. 실제 Google·Claude 외부 API/관계자 호출을 뜻하지 않는다.

## 입력 동작

- 결함 종류 선택 + 결함 지점 클릭: 좌표 저장과 해당 면 결함1을 함께 기록한다. 전체 결함도1로 반영하여 같은 사실의 중복 입력을 줄였다. 같은 종류·같은 구역의 기존 정상0은 null로 해소하고, 다른 종류의 정답은 보존한다. 점은 기존 point_rows를 통해 선택한 종류만 양성으로 학습 자료화된다.
- 정상 구역 모드: 선택한 종류를 해당 구역 전체에서 확인했다는 사람 입력으로 그 구역만0. 모서리는 네 구석, 엣지는 테두리8구역만 허용한다. 반사로 가려진 구역이나 다른 관찰 제한 사진은 정상 클릭을 막는다.
- 미확인 구역 모드: 선택한 구역·종류만null. 같은 종류의 결함점이 있으면 먼저 점 종류 수정/삭제를 요청한다.
- 여러 지점·복수 종류 수정 지원 유지. 점 삭제/종류 해제만으로 정상0을 만들지 않는다. 기존 면 결함1은 남으므로 마지막 결함을 취소했다면 면 라벨도 직접 재확인한다.
- 정상/미확인 모드에서는3×3안내선 자동 표시. 모드 전환만으로 dirty/저장 가능 상태를 만들지 않는다. 클릭하지 않은 구역과 다른 종류는 미확인 유지.

사진별 관찰 제한·카드 영역·실물 구분·분할/검토자 등 별도의 사실은 자동 추정하지 않는다. OpenCV는 추가하지 않았다. 저장만으로 모델 재학습되지 않는다.
