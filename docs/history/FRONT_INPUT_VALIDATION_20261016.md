# 앞면 국소 특징·해상도 후속 검증

기준: 또도가스 하단 중앙 정상0을 포함한 최신144구역. 기존143구역(결함93/정상50)을 동일 분모로 비교하고 새 정상 구역은 별도 all_comparison에 기록했다. 흑백 앞면/RGB 뒷면, 실물별 제외, 앞뒤별 logistic L2=1, 클래스·실물 가중치, 임계값.5 유지.

| 방식 | 누락/93 | 오탐/50 | 새 누락/새 오탐 |
|---|---:|---:|---:|
| 기준: 앞면224 평균 특징 |17|17|—|
| 앞면224 최대 특징 |18|28|5/12|
| 앞면448 평균 특징 |17|22|5/7|

최대 특징은 누락률18.28→19.35%(+1.08%p), 오탐율34→56%(+22%p). 448은 누락률 동일·오탐율34→44%(+10%p). 둘 다 사전 채택 기준 실패, 운영 미적용. 정확도 향상0%p(채택 후보 없음). 연구 기준 모델을 덮어쓰지 않았다.

최대 특징은 강한 공간 반응을 보존하지만 그림/글자도 강조할 수 있다. 입력 축소되는 앞면 결함은43/51구역이었지만 448 확대도 결함 누락을 줄이지 못했다. 따라서 이번 결과로 원인을 단순한 평균 풀링이나 해상도 부족으로 확정하지 않는다. 빛·그림·손상 구분의 근거 부족은 여전히 가설이며 정상/결함 정답 자체를 모델에 맞춰 수정하지 않는다.

학습코드가 아닌 동일 frozen backbone에서 pooling 또는 input size만 바꾼 별도 연구 스크립트. 매 fold마다 기준 평균224 점수를 재계산해 기존 기록과 최대차1e-5미만을 확인했다. 실물/사진 해시 분리, 수렴, 입력·계획 해시 불변, 결과 재집계 assert 통과. 관련 unittest13개 통과(test_regression_audit, test_surface_logistic, test_surface_tiles, test_region_api).

사람 개입: 기존 surface 정답이 없는 뮤츠 앞면 middle_left와 고우스트 앞면 middle_right 두 곳만 준비했다. 두 카드에는 이미 다른 구역의 surface 결함이 확인돼 있어 같은 카드 안의 정상/결함 대조 근거를 확인하기 위함이다. 정상으로 가정하지 않았고 답변은 대기 중이다. 기존 결함·또도가스 정상·마그마 판단 어려움은 변경하지 않았다. 전체사진+빨간 확인 범위+확대 사진을 HTML에 표시했다.

변경: artifacts/front-maxpool-20261016, artifacts/front-resolution-20261016의 계획/실험/결과/HTML, artifacts/front-input-review-20261016 통합 HTML/재검산 스크립트/미확인 구역 자료, 본 문서와 소비 TODO. 운영 코드·라이브 라벨·패키지는 불변.
