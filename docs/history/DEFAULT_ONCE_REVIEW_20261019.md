# 기본 1회 교차 검토

개발 수용기준 4/4 완료: 기존 명령으로 입력 없이 기본 1회, 같은 근거·모델·프롬프트 재사용, 선택 추가 검토 총 3회 상한, 다음 할 일의 로컬 자동 정리. 정확도·토큰 절감률을 뜻하지 않는다.

## 사용법

```sh
./review
```

최신 자료를 한 번 검토하고 응답과 `next_steps.md`/`next_steps.json`을 저장한 뒤 터미널을 반환한다. 입력은 필요 없다. 같은 자료라면 저장된 결과만 보여주므로 추가 호출은 없다. Codex에는 화면에 표시된 `next_steps.md` 경로를 읽고 기존 코드·실패 이력과 대조해 달라고 하면 된다.

추가 반증이 필요할 때만:

```sh
./review --interactive
```

`r`은 자동 선택된 질문·근거로 추가 검토, `q`는 보존, Enter는 토론 종료다. 첫 호출을 포함해 검토 한 건 최대 3회다. 자동으로 3회를 채우지 않는다. 기본 실행에서 반환하더라도 LangGraph는 비교 노드에 대기할 수 있다. 기본 명령 재실행은 결과 조회만 하며, 대화형 모드는 그 체크포인트를 재개한다. 이미 토론을 종료한 기록은 r을 위해 새로 시작하지 않는다. 실행의 시간 예산 600초는 사람 대기 시간에도 흐르므로 오래 지난 검토는 r에서 시간 예산 종료될 수 있다.

## 중복 방지·다음 행동

동결 packet 전체에서 임의 실행 topic과 manual_run_purpose만 제외하고 해시를 만든다. 모델·프롬프트 버전도 함께 비교한다. 기존 수동 검토 폴더들을 찾아 같은 입력을 재사용하므로 active 포인터가 다른 자료를 가리켜도 이전 응답을 찾는다. 이전 버전에서 생성한 같은 한국어 packet 기록도 검색한다. 날짜나 임의 폴더 이름 때문에 새로운 호출을 만들지 않는다.

실험 수치·코드 해시 등 입력이 바뀌면 별도 검토다. 기본 명령은 최신 자료를 다시 수집한다. 대화형 미완료 재개는 동결된 이전 자료를 유지한다. 오류·요청 결과 불명 기록도 같은 자료로 자동 재시도하지 않는다. 저장된 응답의 DB가 없어지면 기본 조회는 가능하지만 대화형 재개는 중복 호출 방지를 위해 차단한다. 기록을 삭제하면 중복 방지 근거도 잃으므로 보존한다.

다음 할 일은 추가 AI 없이 다음과 같이 정리한다.

- API/형식/언어/예산 오류: 기록과 차단 사유 확인부터. 실험 결론으로 쓰지 않는다.
- 사람 확인 요구: 기존 승인 근거와 비교하고 실제 부족한 자료만 확인. 완료 라벨을 다시 요청하지 않는다.
- 실패한 가설의 재제안: 새 반증 근거 없으면 제외한다.
- 반복 주장: 부족한 진단 근거를 확보하고 동일 토론 반복을 멈춘다.
- 실험·성공/실패 기준 있음: Codex에서 코드·실패 이력과 대조 후 변수 하나·대조 조건 확정. 자동 채택은 아니다.
- 기준 불충분: 기존 근거로 실험 계획 보완. 없는 정답·수치는 추정하지 않는다.

파일에 제안 원문과 결과 경로, 미채택·성능 개선 미확인을 함께 기록한다. 프로그램이 Codex를 자동 호출하거나 모델·라벨을 수정하지 않는다. 실험 결과 전 자동 새 토론도 없다.

## 검증

`PYTHONPATH=tests .venv/bin/python -m unittest test_cross_review_manual test_cross_review test_cross_review_evidence -v` — 69개 통과. 로그: artifacts/cross-review-default-once-20261019/tests.log.

실제 프로젝트 최신 packet과 mock SDK를 결합한 별도 실행도 확인했다. 기본 첫 호출1, 같은 자료 재실행 추가0, r 추가1, q 후 재개 r 추가1, 4번째 차단, 완료 후 재실행 추가0, 다음 행동 파일 저장을 확인했다. 로그와 verification.json은 같은 검증 폴더에 있다. HTTP 전송은 테스트에서 차단했다.

이번 실제 Gemini 호출 0회, 실제 usage 미측정. mock 토큰은 실측으로 보고하지 않는다. 새 모델 추론·학습·성능 실험이 없으므로 정확도·일반화 개선은 미확인이다. 토큰 절감률도 주장하지 않는다.

## 리스크·롤백

다음 행동 분류는 규칙 기반이며 의미의 진위를 판정하지 않는다. 가설 ID가 달라도 의미상 같은 실패 가설일 수 있으므로 Codex가 기존 코드·실험과 대조해야 한다. 근거 파일/DB를 수동 삭제하면 재사용이나 재개가 제한될 수 있다. 다른 자료·모델·프롬프트는 새 검토라 호출 한도를 소비할 수 있다. 기본 완료는 프로그램 반환을 뜻하며 토론 그래프의 END나 실험 완료와 다르다.

롤백은 .backups/cross-review-default-once-20261019/의 cross_review_manual.py를 card_condition/, test_cross_review_manual.py를 tests/로, 안내 문서들을 루트로 복원한다. 새 결과·DB·usage·next_steps는 보존한다. 기존 소스로 돌아가면 기본 명령이 다시 입력을 기다리고 같은 자료로 새 검토를 만들 수 있다.
