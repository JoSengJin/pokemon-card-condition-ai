# 0.4.98 · 망나뇽 승인 정상 표면 보강과 train-only ridge 비교

## 승인 반영

8791에서 망나뇽 뒷면 중앙·좌측중간의 정상 표면2승인을 확인했다. 이미 train에 있는 같은 실물 레코드의 해당 값만 갱신하고, 새 id/실물로 중복 추가하지 않았다. 기존 앞뒤 엣지16정답·다른 결함·영역·사진은 보존했다. 승인 출처·사진 SHA·영역이 일치하는지 검사하고, 기존 val·다른 모든 학습 라벨 불변을 prepare.py에서 검산했다. 정상 뒷면 표면 정답은5구역·3실물이 됐다. 기존 승인 파일은 실험에서 수정하지 않았다.

## 같은 조건 보강 전후

동일한 고정 MobileNet·전체 구역224px·표면 선형·20회·기존 실물 기반/클래스 균형 가중치·val BCE 선택. 같은 val38구역(결함19·정상19), 세 초기값 전체를 짝 비교한다.

|---|---:|---:|
| 42 | 9→9 | 3→3 |

42·19에서는 변화0%p, 7에서는 누락 +5.26%p. 모든 짝에서 누락·오탐 비증가라는 사전 기준 미달로 미채택. 성능 때문에 사람 정답을 바꾸지 않는다. 같은 카드의 정답 영역 추가는 새로운 독립 실물이나 시험 자료가 아니다.

## 정규화된 선형 분류기 별도 실험

동일한 보강 자료·동일 고정 특징을 유지하고 분류기 적합만 가중 ridge 최소제곱으로 변경했다. 목표는 정상-1/결함+1, 기존 train 전용 실물/클래스 가중치를 합1로 정규화하며 정규화 강도1.0을 실행 전에 고정했다. 가중 평균 중심화를 통해 절편은 벌점 없이 구하고 dual 선형계로 계수를 직접 구한다. 검증 가중치0행은 특징·정답을 통계 계산 전에 제외한다. val로 계수·정규화·회차를 선택하지 않는다. 학습 반복0회이며 출력은 보정된 확률이 아닌 sigmoid 마진이다.

기존 보강 seed42 TP10/TN16/FP3/FN9 → ridge TP14/TN11/FP8/FN5. 누락47.37→26.32%(-21.05%p), 오탐15.79→42.11%(+26.32%p)로 미채택. 누락만 줄었다는 이유로 정상 오탐 증가를 숨기거나 운영을 교체하지 않는다. 정규화 값을 바꿔 같은 val에 맞추는 추가 탐색은 하지 않았다.
