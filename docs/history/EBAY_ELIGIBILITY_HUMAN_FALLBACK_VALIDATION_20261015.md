# eBay 사진 적합성 보완 · 사람 확인 대체 경로

이 문서는 0.4.91 당시 기록이다. 이후 실제 자동 경계 v2의 합성 오통과를 v3로 보완한 결과와 마그마 학습 비교는 `MAGMAR_SURFACE_VALIDATION_20261015.md`를 따른다.

## 수용 기준과 결과

- 판매자 상태 예시 사진·확대 삽입 합성 사진을 실제 단일 카드 사진과 구분한다. 새 판독 계약에 `stock_or_example`, `collage_or_inset`를 필수로 추가했다. 과거 캐시에서는 명시적인 예시 사진 문구도 제외한다.
- Pokémon/POCKET MONSTERS 글자 로고를 직접 전사한 `logo_text`를 새 계약에서 요구한다. 에인션트 뮤 같은 상징 무늬를 로고라고 주장한 boolean만으로 새 판독을 통과시키지 않는다.
- 호출 한도에 막혀도 사람이 직접 확인한 뒷면만 `--confirm-back ID --confirmed-by 검토자`로 내보낸다. `--reject-back ID`는 해당 후보를 제외한다. 언급하지 않은 후보는 미확인이다.
- 사람 기록을 선택 사진의 디코딩 픽셀 SHA에 묶는다. 사진이 바뀌면 재사용을 거부한다. 확인과 제외의 충돌·없는 ID·빈 검토자도 거부한다.
- 사람의 경계 확인은 손상 정답이나 앞뒤 동일 실물 확인이 아니다. 내보낸 상태 라벨은 전부 null, `pair_verified=false`, 상태 검토자는 공란이다. 사람 확인은 provenance에 별도로 보존하고 모델 확률을 만들어내지 않는다.

## 한계와 롤백

새 v2 프롬프트는 API를 새로 호출해 품질을 검증하지 않았다. 구조화 필드와 거부 규칙의 테스트 통과를 비전 모델 정확도 향상으로 해석하지 않는다. 과거 v1 캐시는 새로 판독한 것으로 표시하지 않으며, 로고/합성 필드가 없는 캐시는 추가 경계 검증 또는 명시적 사람 확인이 필요하다. 사진 적합성이 앞뒤 동일 실물이나 결함 정상 여부를 보장하지 않는다.

롤백은 위 코드 변경과 버전 안내를 되돌리고 새 수집 output에서 사람 확인 기능을 사용하지 않는 방식이다. 마그마 작업 라벨과 원본·provenance는 먼저 백업한다. 신규 자료를 제거해야 한다면 해당 신규 artifact/learn 폴더만 대상으로 하고 기존 모델·기존 라벨·호출 한도 기록은 삭제하지 않는다. 이 독립 디렉토리는 Git 저장소가 아니므로 `git revert`를 롤백 수단으로 전제하지 않는다.
