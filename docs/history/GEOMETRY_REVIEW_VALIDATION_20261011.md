## 이번 완료 범위

중앙90% crop은 제한 단서를 자를 수 있고 성능도 악화했다. 다음 비교에 앞서 전체 사진 box로 등록된 학습 사진에서 카드 경계를 사람이 확인하는 경로를 구현했다. 자동 검출/분할 모델이 아니다. 기존 상태·결함 라벨을 다시 묻지 않는다.

`visibility-geometry-review`는 train만 로드한다. 제외 사진, 기존 결함 좌표/구역 라벨, 확인 완료 사진을 제외하고 관찰 사유가 있으며 box가[0,0,1,1]인 후보를 최대3실물로 묶는다. 현재 대상은ㅈ-그늘어두움/빛가려짐/슬리브껴짐 앞뒤6사진이다. 검증/test 사진과 정답을 읽어 후보를 고르지 않는다.

`box_reviewed` boolean을 면별 스키마에 추가해 저장·다시 열기·내보내기에서 유지한다. 미기입은 false로 취급하며 box가 없는 상태의 true는 거부한다. 카드 영역을 수정하면 확인 체크를 해제한다. 확인 체크만으로 상태 정상·평가 가능·관찰 제한 해제를 만들지 않는다.

기존 사진의 ‘카드를 감싸는 좌상단→우하단’ 두 번 클릭/키보드 좌표 입력을 재사용했다. 기울어진 카드는 모든 모서리를 포함하는 바깥 사각형을 지정해야 하며 원근 보정은 하지 않는다. box를 바꾸면 기존 UI가 결함 지점/검토 좌표를 초기화하므로 해당 기록이 있는 사진은 이번 후보에서 제외한다.

geometry 링크는 id/side/image에 묶는다. 새 geometry 모드에서 확인 체크·저장 후 다음 미완료 사진으로 자동 이동한다. 초기 묶음이 끝나면 다른 카드의 결함 재라벨로 자동 이동하지 않는다. 영역이 이미 정확하면 좌표를 바꾸지 않고 확인 체크만 저장할 수 있다.
