## 저장 후 재개 순서

1. 신규 파일의 실제 저장 내용·정답 종류·관찰 범위를 확인한다. 누락이 있으면 새 항목에서 필요한 부분만 요청한다.
2. 기존 source/history/두 모델과 신규 입력을 동결하고 실물/픽셀 겹침을 검사한다. 유효 정답이 부족하면 성능 수치를 만들지 않는다.
3. 지원하는 뒷면 엣지와 관찰 제한만 고정 모델로 평가한다. 모서리/표면/전체 점수까지 지원한다고 확대하지 않는다. 관찰 제한 평가에는 양쪽 클래스가 필요하다.
4. 이 독립 결과로 모델/임계값을 다시 고르면 이후에는 개발 자료가 된다. 이번 자료를 train/val에 편입하거나 반복 튜닝하지 않는다. 작은2실물 결과로 일반화나 운영 채택을 주장하지 않는다.
