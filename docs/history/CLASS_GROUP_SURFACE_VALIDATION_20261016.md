# 새 오류 원인 분리와 비교 안전장치

같은145구역(결함93/정상52)을 실물별 제외해 비교했다. 기존 gray앞면/RGB뒷면, 고정MobileNet, mean224, 앞뒤head, logistic L2=1, 임계값0.5는 유지했다. 앞면만 클래스 안에서 실물 비중이 같도록 변경했다. 실행 전 plan.json을 작성하고 계획·입력 해시를 결과에 저장했다. fold마다 기존 점수를 다시 계산해 차이1e-5 미만을 검사했다. 학습/제외 실물의 이미지 해시 교집합0, 원본 결과 불변, 수렴을 확인했다.

## 결과
누락17→18/93(18.28→19.35%, +1.08%p), 오탐17→18/52(32.69→34.62%, +1.92%p). 정확도76.55→75.17%(-1.38%p). 새 누락3/새 오탐3/회복4. 가중치 수정 후보는 미채택. 개발4/6유지·운영교체0. 반복 개발 자료 결과이며 독립 일반화 증거가 아니다.

기존 가중치는 같은 실물에 정상 라벨을 추가하면 해당 실물의 결함 비중도 바꾼다. 이 결합을 제거해 이전 마그마 누락과 b 오탐은 회복했지만 전체 오류가 늘었다. 따라서 가중치만으로 원인이 해결됐다고 볼 수 없다. 앞면 정상/결함 혼합 실물은2장뿐이다. 무늬와 손상 분리 부족은 후속 가설이며 확정 원인이 아니다. 완료 라벨은 유지하고 미확인을 정상으로 채우지 않는다.
