# 또도가스 정상 / 마그마 판단 어려움 반영

사용자 답변 ‘또도가스 정상 마그마는 판단 어려워’는 앞서 보여준 **앞면 하단 중앙 표면**에만 적용했다. 또도가스 카드 전체를 정상으로 변경하지 않았다. 마그마는 미확인을 유지하고 정상 학습에 넣지 않았다.

별도 연구 manifest에 v/front/lower_center surface_defect=0 하나만 추가. 원본 manifest, 기존 결함점, 다른 라벨은 그대로다. human-intake.json과 이전 pending-human.json에 답변·범위·처리 상태 기록. 이전143구역은 동일 분모로 비교하고 새 정상1구역은 별도 평가했다. 전체 실물을 제외하므로 v를 평가할 때 새 정상도 학습에서 제외하며 기존 v 점수 불변을 검사했다.

| 조건 | 누락/93 전→후 | 정상 오탐/50 전→후 | 새 누락/새 오탐 |
|---|---:|---:|---:|
| RGB 앞뒤 분리 |20→20|19→19|1/0|
| 흑백 앞면 |17→17|18→17|1/0|

RGB에서는 마그마 결함1곳을 회복하면서 u 앞면 결함1곳을 새로 놓쳤다. 흑백에서는 c 앞면 오탐1곳과 마그마 결함1곳을 회복하면서 고우스트 앞면 결함1곳을 새로 놓쳤다. 흑백 정상 오탐률36→34%(-2%p), 누락률18.28% 동일, 정확도75.52→76.22%(+0.70%p). 같은 train 실물 제외 탐색이며 독립 서비스 정확도가 아니다. 새 정상 v구역은 RGB .5696 / 흑백 .5330으로 두 후보 모두 오탐. 정상 정답을 모델에 맞추어 변경하지 않는다.

기존에 검출하던 결함을 지키는 조건을 만족하지 못하므로 두 후보 모두 운영 교체 보류. 한 구역의 새 정상만으로 그림체 혼동을 해결했다고 주장하지 않는다. 사람의 정답은 장기 연구 자료로 보존한다.

검증: 기존 모든 patch record 동일, 새 정상1구역만 추가 assert, 실물/이미지 해시 학습-평가 겹침0, 수렴, 원본 SHA 불변, 기존143구역 점수로 공통 회귀 검사 재계산, 관련 unittest16개 통과. 최초 긴 실행 명령은 자동 권한 검토 시간초과로 실행되지 않았고, 허용된1회 짧은 재시도로 성공했다.
