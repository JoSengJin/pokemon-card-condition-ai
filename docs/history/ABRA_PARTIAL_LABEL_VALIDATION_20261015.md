# 캐이시 일부 오염 클릭 보존·엣지 보강 비교

## 사용자 확인과 학습 의미

사용자: ‘라벨 저장했어. 캐이시 앞면 전반적으로 오염이 많아서 다 클릭하진 않았어.’ 이후 앞뒤 카드 영역을 모두 확인했다고 답했다.

`artifacts/ebay-front-candidates-20261014/abra-review.jsonl`의 앞면3점·뒷면4점은 좌표·종류 그대로 보존했다. 두 면 영역 확인 체크와 검토자 기록, ‘전체 오염 위치를 클릭한 것이 아님’이라는 메모만 반영했다. 앞면의 표면 결함1은 유지하고 미표시 구역을 정상0이나 결함1로 채우지 않았다. 동일 실물은 확인되지 않아 `pair_verified=false`로 유지하며 두 사진을 같은 train 그룹에 보수적으로 묶었다.

현재 국소 학습은 직접 찍은 위치나 명시적 구역 라벨만 사용한다. 따라서 사용자의 ‘전반적으로 오염’ 설명은 기록되지만, 그 문장만으로 카드 전체 오염 위치가 학습되었다고 말하지 않는다. 기존 클릭 종류를 오염 `stain`으로 일괄 바꾸지도 않았다.

## 고정 전후 비교

- 기준: `artifacts/kieuk14-train-20261013/combined.jsonl`과 `candidate224/model.pt`.
- 새 입력: 캐이시1그룹·6개 3×3 구역. 엣지 결함2구역, 표면 결함5구역이며 일부 구역은 두 종류가 겹친다. 정상 구역은0개다.
- 이번 실험은 엣지 전용 타일 입력이므로 표면 결함을 엣지 정답으로 바꾸지 않았다. 모든 설정은 기준과 동일한 MobileNet frozen backbone, tiles224,20epochs,balance,balanced-selection,seed42다.
- 사전 기준: 같은 val에서 누락0 유지·오탐5 미만. 그룹/id/디코딩 이미지 중복 없음, 기존 val50개 patch 전체 일치, test 미사용.
- 엣지 평가27구역(결함15·정상12): 기준/후보 모두 TP15/TN7/FP5/FN0. 누락0%·오탐41.67%, 변화 각각0.0%p. 기준 미달로 후보 미채택, 기존 모델 보존.
- `artifacts/abra-edge-20261015/index.html`: 전후 동일 판정이어도 모든 평가 사진·구역·점수와 사람 정답을 표시한다. 반복 val이며 독립 성능 개선 증거는 아니다.
- 개발 단계4/6 약67%, 이번 정확도 개선 없음·독립 일반화 개선 미확인·운영 Gemini 분석 절감0건.

## 다음 자료 확보

`artifacts/ebay-mixed-candidates-20261015`에서 기존 eBay 연결·한도 정책으로 새4매물9사진을 확보했다. 전체 사진 선별4회+뒷면 경계v3 묶음검증1회, 합계 API5회다. 두 후보 중 네 변 조건까지 통과한 꼬렛(Rattata)1쌍만 내보냈다. 판매자의 NM/LP 문구를 정상·손상 정답으로 사용하지 않았다.

원본 앞뒤를 확인해 제안한 꼬렛 영역은 `box_reviewed=false`, 모든 상태 라벨null·동일 실물 미확인으로 `labels-review.jsonl`에 별도 저장했다. localhost:8787 실제HTTP200 확인. 정상·손상 혼합 보강에는 새 꼬렛의 실제 결함과 충분히 본 정상 구역에 대한 사람 정답이 필요하며 캐이시는 재요청하지 않는다. 자동 선별1쌍이라는 사실은 카드 상태 모델 성능이 아니다.
