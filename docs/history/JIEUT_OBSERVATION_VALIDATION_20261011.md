# ㅈ 자료 반영과 관찰 제한 모델 비교 — 2026-10-11 / 0.4.37

## 결과

서로 다른 실물 3장의 앞뒤 사진 6장을 학습에 반영했다. 관찰 제한 누락은 일부 줄었지만 오탐이 증가해 두 새 후보 모두 운영 채택하지 않았다. 실제 Gemini 절감은 0건이다.

사용자가 같은 카드의 제한 없는 비교 사진은 없다고 확인했다. 해당 사진 요청은 종료하며 기존 완료 라벨을 다시 요청하지 않는다. 동일 입력의 반복 학습이나 같은 val에 맞춘 임계값 탐색은 하지 않는다.

## 자료와 라벨

사용자 확인에 따라 ㅈ-그늘어두움, ㅈ-빛가려짐, ㅈ-슬리브껴짐을 각각 별도 group/train으로 등록하고 각 카드의 앞뒤를 같은 그룹에 묶었다. 관찰 사유는 shadow, glare, obstruction이다. 슬리브가 실제로 일부 상태 관찰을 방해한다는 명시적 확인을 근거로 obstruction을 기록했다.

카드 자체 상태가 나쁘다는 설명은 notes에 보존했다. 구체적 결함 종류·위치와 전체 gradable은 추정하지 않고 null을 유지했다. 반사 위치나 정밀 결함 점을 창작하지 않았다. 신규 box=[0,0,1,1]은 사진 전체 범위이며 사람이 검증한 카드 윤곽이 아니다. 새 사진에는 배경이 포함되므로 촬영 환경과 제한 여부가 혼동될 수 있다.

live 66→69행, 기존 66행 내용 불변. 백업은 data/learn-review-before-jieut-20261011.jsonl.bak, 동결 데이터는 artifacts/observation-jieut-20261011-source.jsonl, 등록 근거는 artifacts/import-jieut-20261011.json이다. 비교 사진 보유 여부는 artifacts/jieut-comparison-photo-availability-20261011.json에 기록했다.

## 실제 비교

첫 실험은 자료만 추가했다. 설정은 seed42, 20epoch, MPS, 224px, 고정 MobileNetV3 Small, head 학습률0.001, 클래스→실물 균등 BCE를 유지했다. train은40→46면/22→25실물이며 제한 양성은8→14면/6→9실물, 비제한32면은 불변이다.

두 번째 실험은 같은 새 데이터에서 입력 표현만 고정 타일로 바꿨다. 기존 edge_views.patch_features를 재사용해 전체 구역 평균 특징과 고정2×2 타일 특징의 채널별 max를 합친다. 사진당 정답/loss는 하나이며 모든 타일에 제한 양성 정답을 복제하지 않는다. 사람의 사유나 위치를 이미지 특징으로 입력하지 않는다.

세 보고서의 val24면/14실물(제한7·비제한17)은 사진·box·정답·사유·순서가 동일함을 검산했다. test 사진은 읽지 않았다.
