# MobileNet 마지막 특징 블록 부분 미세조정 실험

목표: 고정 특징 + 분류 head 기준선의 결함 누락과 `gradable=0` 오판을 줄일 수 있는지 확인한다. 기존 `artifacts/visibility-complete-20261009.jsonl`의 train 40면/val 18면을 그대로 사용했다. test 6면은 모델 선택에 쓰지 않았다.

`side-experiment --fine-tune-last`는 MobileNetV3 Small의 앞 12개 특징 블록을 고정하고 마지막 1×1 합성곱 블록과 분류 head만 학습한다. 앞부분 특징은 한 번 계산하고, 마지막 블록은 학습 중 갱신한다. 작은 배치에서 BatchNorm 통계가 흔들리지 않도록 특징 추출부는 평가 모드를 유지한다. 다른 설정은 기준선과 동일하게 사전학습 가중치, 전체 사진 224px, 5 epoch, 불균형 가중치 없음, seed 42다.

| val 지표 | 특징 고정 | 마지막 블록 미세조정 |
|---|---:|---:|
| 최저 BCE | 0.6091 | 0.6059 |
| 평가 불가를 가능으로 오판 | 5/5 | 5/5 |
| 센터링 결함 검출 / 오탐 | 2/7 · 0 | 2/7 · 2 |
| 모서리 결함 검출 | 0/3 | 0/3 |
| 엣지 결함 검출 | 0/6 | 0/6 |
| 표면 결함 검출 | 0/2 | 0/2 |
| 반사 면의 평가 불가 오판 | 3/3 | 3/3 |
| 학습 시간(CPU, 같은 장비) | 2.24초 | 7.10초 |

매물 단위 가상 Gemini 생략 후보는 `gradable` 문턱값 0.5에서 3건이며, 사람 라벨상 위험 후보가 2건이다. 문턱값 0.7 이상에서는 후보가 0건이다. 기존 기준선의 후보 5건/위험 3건보다 숫자는 작지만, 안전성과 호출 절감이 동시에 확보되지 않았다. 부분 미세조정은 운영 채택하지 않고 기존 Gemini 경로를 유지한다.

체크포인트: `artifacts/visibility-finetune-last-20261009/model.pt`; val 보고서: 같은 폴더의 `report.json`; 가상 라우팅: `artifacts/routing-audit-finetune-20261009.json`. 저장 모델을 `side-evaluate --kind regression`으로 다시 읽어 기존 회귀 3매물/6면에서 실행했다. 이 자료는 이미 본 회귀 자료이며 최종평가가 아니다. 전체 unittest 26개 통과. 별도 모델 학습 옵션과 체크포인트만 추가했으며 원본 라벨과 PokeCollector 운영 경로는 변경하지 않았다.

다음 판단: 같은 작은 val에서 반복 실험한 수치만으로 모델 종류를 늘리지 않는다. 반사·흐림·가림 등 평가 불가 사례와 실제 보이는 결함 위치가 충분히 다양한 새 실물을 확보한 뒤, 새 독립 평가 자료에서 누락/오탐 허용 기준을 검증한다. 현재 자료만으로 OpenCV나 timm 도입 효과를 입증할 수 없다.

롤백: `.backups/fine-tune-20261009/`에 보관한 `side_experiment.py`와 `cli.py`를 복원하고 `tests/test_fine_tune_last.py` 및 이번 실험 결과·문서를 제거한다. 기존 기준선 모델은 그대로 남아 있다.
