## 변경과 목적

- `card_condition/region_experiment.py`: 선택 옵션 `group_balance` 추가. 학습 split에서 각 결함 종류별로 같은 실물 그룹의 알려진 구역 수를 세고 역수 가중치를 부여한다. 같은 그룹의 해당 종류 가중치 합은 1이다. 정상/결함 클래스 비율을 별도로 균등화하는 옵션은 아니다.

- 실험 보고서에 split·클래스별 실물 그룹 수와 가중치 방식을 기록한다. 체크포인트 추론 구조는 그대로다.
- `tests/test_region_experiment.py`: 그룹별 합, 미확인/미지원 항목 제외, val/test가 학습 가중치에 영향을 주지 않는지, 균일한 입력에서 기존 방식과 일치하는지 검증.

## 데이터 한계와 다음 개발 기준

train 정상 실물 그룹은 모서리/엣지/표면 각각4개. val 정상 그룹은 각각1/2/3개, 결함 그룹은 각각5/7/2개다. 같은 카드의 여러 구역은 독립 표본이 아니며 양쪽 클래스에 나타나는 그룹도 있다. 단순 가중치만으로 사진/디자인 편향이 해결됐다는 근거는 없다.

다음 실험은 현재 val에 반복해서 맞추기보다 신규 실물과 촬영 조건으로 검증 범위를 넓히는 것을 우선한다. 사람에게는 필요한 소량 후보만 요청한다. 기존 val을 train으로 이동하거나 현재 모델 결과로 정답을 자동 수정하지 않는다. 새로운 모델 구조·미세조정 도입은 오류 유형과 독립 검증 자료를 확보한 뒤 결정한다.

빛 반사와 미확인은 결함 정답으로 변경하지 않는다. 이 가중치는 반사를 자동 검출하지 않는다. test는 이 학습에서 읽지 않으며 최종평가와 소비 앱 통합은 보류한다. 실제 Gemini 호출 절감0건.
