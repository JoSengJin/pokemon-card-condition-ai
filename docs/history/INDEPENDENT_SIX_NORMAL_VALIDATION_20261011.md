# 독립 정상 엣지 6구역 확인 반영

사용자 확인: ‘나머지 6구역 확인했고 정상임’. Gastly 뒷면 좌측 상단·상단 중앙·우측 상단·좌측 중간·우측 중간·우측 하단의 edge_defect만 0으로 저장했다. 좌측 하단의 기존 모서리/엣지 결함점, 하단 중앙 미확인, 다른 결함 종류, Persian, test 분할은 보존했다. ReviewStore의 revision 검사·백업·원자적 저장을 사용했으며 전체 행 비교로 허용된 여섯 변경만 발생했음을 검산했다.

## 고정 모델 평가

`artifacts/independent-six-normal-20261011/report.json`: 신규 실물 2장, 지원 정답 엣지 8구역. TP1/TN3/FP3/FN1. 정상 6구역 중 오탐3(50%), 결함2구역 중 누락1(50%). 정확도4/8=50%는 이 작은 표본의 수치이며 서비스 전체 정확도가 아니다. 정상 정답은 같은 Gastly 한 실물에서 나왔으므로 독립 정상 실물 수는 1이다.

오탐 위치: 좌측 상단 .628928 / 우측 상단 .593244 / 우측 하단 .554175. 다른 정상 구역 점수: 상단 중앙 .332655 / 좌측 중간 .306572 / 우측 중간 .396216. 기준은 기존 0.5이며 변경하지 않았다.

기존 결함 두 구역의 점수는 이전 보고서와 완전히 같다. 모델·사진·개발 이력 SHA도 보존됐다. 이전에는 정상 분모가 없어 오탐률을 계산할 수 없었으므로 이번 50%를 정확도 상승/하락으로 비교하지 않는다. test 자료로 재학습하거나 임계값을 선택하지 않았다.

## API 보류 정책 대조

기존 실제 독립 API 결과와 새 평가의 카드·면·구역·box·점수를 정확히 대조했다. 새 정상 6구역은 모두 기존 .3/.7 정책에서 unknown/score_deferred다. 오탐3곳도 자동 결함 확정되지 않지만 정상6곳 모두 보류하므로 로컬 완료율 개선도 아니다. 실제 Gemini 호출 절감0·운영 채택false 유지. API는 새 호출 없이 해시와 점수가 일치하는 기존 실제 결과를 재사용했다.

## 다음 사람 입력이 필요한 경계

현재 실행 목록의 독립 엣지 평가는 완료했다. 관찰 제한 최종평가에는 새 실물의 제한 양성 정답이 없고, 앞면 train-only 경계 검증에는 기존 학습 두 실물 이외의 반사 사례가 없다. 사용자의 ‘추가 사진 없음’ 답변을 유지하며 완료 라벨을 재요청하거나 기존 val/test를 학습으로 옮기지 않는다. 새로운 실물이 확보되기 전 이 결과만으로 재학습·기준 변경·Gemini 우회는 하지 않는다.

에튜: 판단 보류는 정확도 상승과 다르다. 점수 .63은 기준 .5에서는 오탐이지만 .3~.7 보류 정책에서는 검토로 넘어간다. 잘못된 자동 판정을 줄이는 대신 자동 처리 비율도 낮아지므로 오탐률과 처리 비율을 함께 읽어야 한다.
