# 후면 점검 모델 정확도 개선 설계: 라벨 상한 → head 구조 → 입력 품질 (2026-11-21, 설계·실행 전)

## 결론
정확도(같은 자료·같은 분모의 누락·오탐·AUC)를 올리는 일을 세 갈래로 나눠 **이 순서로** 한다. W1 라벨 상한이 W2·W3를 할지 정하는 관문이다.
1. **W1 라벨 상한 측정(읽기 전용).** 사람 재판정 일치율로 모델이 넘을 수 없는 천장을 잰다.
2. **W2 head 구조 변경(실험 1회).** 지금까지 유일하게 시험하지 않은 레버다.
3. **W3 입력 품질 처리(진단 → 규칙 실험).** 저해상·슬리브 사진의 오판을 보류로 돌린다.

사용자 우선순위(2026-11-21): 정확도가 최우선. 진척률 작업(F1·D3 작동점)과 작동점·정의 변경으로 수치를 낮추는 일은 정확도 향상이 아니다.

## 확인된 출발점 (근거 파일)
- 현 구조(고정 DINOv2 ViT-S/14 패치 토큰 + 선형 토큰 head, `detail_bag_loss` mean_odds 묶음 손실 `artifacts/inner-whitening-confounder-20261021/confounder_head.py`)에서 백본·차원·L2·해상도·층·미세조정·자료 추가 모두 AUC 0.85를 못 넘었다(`docs/collaboration/reports/performance-top3-consensus-20261030.md` §17~§40, §38 종합).
- 모서리 후보 E 개발 OOF(`artifacts/experiments/20261102T140143-82781117`, 946구역·257그룹): AUC 0.8565, 같은 사진 AUC 0.796, 카드 단위 v1.14 작동점(누락 = 결함 구역 전부 <0.20, 오탐 = 정상 카드 구역 하나라도 ≥0.60) 누락 7/176·오탐 10/81. 입력 224는 크게 악화(AUC 0.745).
- 재판정 근거: 40곳 kappa 0.472(CI 0.234~0.688), 카드 위 27곳 0.357(`docs/collaboration/reports/label-boundary-criteria-20261112.md`, 원문 `label-reliability-20261111.md`). E2 화면에서 실수로 재요청한 4장 12문항 중 10개 일치. 어느 칸·어느 기준의 일치인지는 원문에서 재확인 필요.
- 누락 쏠림: 사진 가로 <1000px 결함 구역 누락 18% 대 9%, 슬리브·탑로더 사진 다수(눈 확인, 미검증). 오탐은 구판 뒷면에 몰리나 디자인 안 AUC는 같다(`docs/collaboration/reports/corner-d3-diagnosis-20261121.md`).

## 공통 평가 계약
- 주 지표: 개발 OOF 풀링 AUC와 같은 사진 AUC(사진 그룹 부트스트랩 2000회 95% 구간), 대조 = 저장된 후보 점수.
- 누락·오탐은 **오탐을 맞춘 비교**로 본다: 새 모델에서 대조와 같은 오탐 건수가 되는 임계를 OOF에서 찾아 그때의 카드 단위 누락을 비교한다. 절대 임계를 고정하면 점수 보정 이동이 분리도 개선처럼 보이기 때문이다. v1.14 작동점의 건수는 참고로 함께 적는다.
- 학습·평가 사진 그룹 분리, D1 봉인·D2 시험 자료 사용 금지, 소비된 219건 등 개발 전환 자료는 개발용으로만.
- 개선을 주장하려면 새로 라벨한 독립 자료가 필요하다. 개발 OOF 결과는 "개발 개선"으로만 보고한다.

## W1 라벨 상한 측정 (읽기 전용, 새 라벨 요청 없음)
- 입력: 같은 사람이 같은 칸·같은 구역을 두 번 이상 답한 기존 기록 전부. 후보 위치: `label-reliability-20261111.md`, `normal-rejudge-20261112.md`, `zone-rejudgment-design-20261111.md`, `artifacts/e2-scenario-20261104/walkthrough*.txt`와 `artifacts/e2-scenario-20261120/answers-*.txt`의 겹치는 id, 미리 채움 격리 u·v(`prefill-anchoring-quarantine` 메모리). 기준 문구가 다른 판정끼리는 섞지 않는다.
- 출력: 칸별(엣지·모서리·표면·관찰 제한) 일치율·Cohen kappa·분모, 그리고 "라벨이 이 비율로 뒤집힌다면 완벽한 모델의 관찰 AUC 상한"(대칭 뒤집힘 가정 시뮬레이션, 가정 명시).
- 관문(결과 전 고정):
  - 칸별 재판정 분모가 30구역 미만이면 그 칸은 "미측정"으로 두고, 소규모 블라인드 재판정(예: 모서리 60구역, 미리 채움 없음)을 사용자에게 **제안만** 한다. 완료 라벨 재요청 금지 규칙의 예외는 사용자 결정이다.
  - 추정 상한 ≤ 현 AUC + 0.03이면 W2를 보류하고, 라벨 기준·target 정의 쪽 선택지를 사용자에게 올린다.
  - 그 외에는 W2로 간다.

## W2 head 구조 변경 (실험 1회)
- 가설: 선형 토큰 head가 미세 화이트닝의 국소 패턴(여러 토큰의 조합)을 표현하지 못한다. 변경 변수 하나: 토큰 점수기를 선형 → 은닉 1층 MLP(폭 64, 드롭아웃은 대조와 같게 0) 또는 어텐션 MIL 풀링 중 **하나만**. 추천은 MLP(묶음 손실·쌍 순위 항·λ·fold·특징 불변으로 변수가 가장 작다).
- 대상: 모서리 후보 E 레시피(946구역, 같은 사진 쌍 순위 항 λ=1.0).
- 사전 기준(결과 전 고정): 풀링 AUC 차이 ≥ +0.02이고 부트스트랩 하한 >0, 같은 사진 AUC가 대조보다 낮지 않음, 오탐을 맞춘 카드 단위 누락이 대조보다 많지 않음. 실패 문장: 하나라도 어긋남.
- 위험: 용량 증가로 과적합(§37·§39에서 용량·자료 증가가 오히려 낮춤). 수렴 실패는 failed로 기록하고 반복 횟수를 바꿔 재시도하지 않는다.
- 비용: 특징 캐시 재사용 시 학습 5 fold, 메모리는 현 448과 같다.

## W3 입력 품질 처리 (진단 → 규칙 실험)
- 1단계 진단(읽기 전용): 자동으로 계산 가능한 품질 지표만 쓴다 — 원본 가로 px, 모서리 크롭 px, 라플라시안 분산(흐림), 밝은 포화 픽셀 비율(반사). 슬리브는 자동 판별이 없으므로 눈 확인 표본으로 판별기를 먼저 검증한 뒤에만 쓴다(빨간 픽셀 판별기가 14건 틀린 전례).
- 출력: 지표 구간별 구역·카드 누락·오탐과 분모, 위험-범위 곡선(낮은 품질부터 보류했을 때 남은 카드의 누락·오탐 대 보류 비율).
- 2단계 실험(사전 기준): 품질 지표 하나와 그 임계를 **개발 OOF에서 결과 전에 정한 규칙**(예: 보류 비율 ≤20%에서 누락이 가장 많이 줄어드는 단일 지표)으로 고르고, 보류되지 않은 카드의 누락·오탐이 대조보다 줄면서 보류 ≤20%인지 본다. 보류는 정확도 향상이 아니라 범위 축소이므로 보고에 둘을 나란히 적는다.
