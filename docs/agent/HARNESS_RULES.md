# 자율 개발 하네스 운영 규칙 (D-1, 2026-11-27 사용자 승인)

범위는 `docs/collaboration/plans/autonomous-harness-20261127/` 설계 묶음의 구현·운영에 한정한다. 이 문서는 아래 항목에 한해 AGENTS.md의 "자동 재시도 금지", "세션 상시 깨우기 금지", "최종 응답 이후 자동 실행 약속 금지" 문장보다 우선하며, 그 밖의 모든 제한·승인은 그대로다. 이 문서가 있다고 구현이 끝났다는 뜻이 아니다. 각 기능은 구현·검증 기록이 있는 만큼만 동작한다고 말한다.

- 인프라 중단(프로세스 종료·네트워크 장애·사용량 한도)으로 멈춘 작업은 하네스 Supervisor(launchd, LLM 미사용)가 장부 상태를 기준으로 자동 재개한다. 일시적 원인은 설계 9절 한도(최대 2회)까지만 재시도한다. 코드 오류·기준 미달·결과 불명인 실험·학습·모델 요청은 계속 자동 재시도하지 않는다.
- Supervisor는 상시 실행할 수 있다. 개발 예산 소진·`INTEGRITY_HALT`·`USER_STOPPED`·`DONE` 상태에서는 개발 작업을 시작하지 않는다.
- 하네스는 기본 checkout의 학습·실험·추론 실행 담당(단일 담당자)으로 지정한다. 현재 메인과 동시에 실행하지 않고 `./develop` 잠금과 작업권으로 직렬화한다.
- 하네스 구현·운영 범위에서 하위 에이전트를 사용할 수 있다(모델·effort 지정 가능). 보안·상태 일관성·자동 재개 핵심은 구현과 별도인 독립 검증을 거친다.
- 변하지 않는 것: 사람 라벨 재요청 금지, 완료 라벨·Gold·봉인 자료 보호, 승인 범위 밖 외부 AI 호출 금지, main 통합·push는 고지 후 승인, force push 금지, 설계에 없는 기능 추가 금지.
- 개발 예산(D-2): 주당 실험 20건, 비전 호출 300구역, 봉인 교체 주기당 승격 2건. Silver 정책(D-3): 오류율 상한 10%, 감사 10%에서 최저 2%(제안값, 0% 금지). D-4 라우팅 정책 경로는 수령 전까지 미확정이며 `DECISIONS.md`를 정본으로 한다.
