# 자율 개발 하네스 운영 규칙 (D-1, 2026-11-27 사용자 승인)

범위는 `docs/collaboration/plans/autonomous-harness-20261127/` 설계 묶음의 구현·운영에 한정한다. 이 문서는 아래 항목에 한해 AGENTS.md의 "자동 재시도 금지", "세션 상시 깨우기 금지", "최종 응답 이후 자동 실행 약속 금지" 문장보다 우선하며, 그 밖의 모든 제한·승인은 그대로다. 이 문서가 있다고 구현이 끝났다는 뜻이 아니다. 각 기능은 구현·검증 기록이 있는 만큼만 동작한다고 말한다.

- 인프라 중단(프로세스 종료·네트워크 장애·사용량 한도)으로 멈춘 작업은 하네스 Supervisor(launchd, LLM 미사용)가 장부 상태를 기준으로 자동 재개한다. 일시적 원인은 설계 9절 한도(최대 2회)까지만 재시도한다. 코드 오류·기준 미달·결과 불명인 실험·학습·모델 요청은 계속 자동 재시도하지 않는다(아래 자동 재개 예외만 제외).
- **자동 재개와 자동 재실행은 다르다**(2026-11-27 사용자 승인, 위 항목보다 우선). 재개는 미완료 단계를 이어 하는 것이고, 재실행은 처음부터 다시 하는 것이다. 완료가 확인된 단계(산출물 유효성·해시·완료 기록)는 어느 쪽으로도 다시 실행하지 않는다.
  - 자동 재개 대상은 실환경에서 권한·부작용 제한과 결과 중복 반영 방지를 확인해 **코드에 등록한 작업 유형의 미완료 단계**뿐이다. A군→B군→C군 순서로 확인된 유형만 켜며, 확인하지 않은 유형은 끈다. 이때 생기는 언어 모델 사용량 일부 중복은 승인된 개발 예산과 기존 재시도 상한 2회 안에서 수용한다.
  - 결정론적 작업도 부작용과 중복 반영 방지가 확인되어 코드에 등록한 것만 자동 재실행한다.
  - 세션 복원 불가가 **확인된** 경우에만 새 세션을 만든다. 그 밖의 재개 실패는 그 작업을 대기시킨다.
  - 결과 불명인 실험·학습·평가 실행·외부 호출·배포·승격은 자동 재실행하지 않는다. 외부 요청을 보낸 뒤 결과를 모르는 실패는 일시 원인으로 보지 않는다. 이 항목은 정상 자율 루프에서 실험·학습·평가를 실행하는 것을 금지하지 않는다(실제 실행은 별도 승인).
- 공통 장애의 근거가 없으면 실패한 작업과 그 의존 작업만 대기시키고 독립 작업은 계속한다. 미분류 실패의 횟수만으로 전체 Claude 실행기를 멈추지 않는다.
- Supervisor는 상시 실행할 수 있다. 개발 예산 소진·`INTEGRITY_HALT`·`USER_STOPPED`·`DONE` 상태에서는 개발 작업을 시작하지 않는다.
- 하네스는 기본 checkout의 학습·실험·추론 실행 담당(단일 담당자)으로 지정한다. 현재 메인과 동시에 실행하지 않고 `./develop` 잠금과 작업권으로 직렬화한다.
- 하네스 구현·운영 범위에서 하위 에이전트를 사용할 수 있다(모델·effort 지정 가능). 보안·상태 일관성·자동 재개 핵심은 구현과 별도인 독립 검증을 거친다.
- 변하지 않는 것: 사람 라벨 재요청 금지, 완료 라벨·Gold·봉인 자료 보호, 승인 범위 밖 외부 AI 호출 금지, main 통합·push는 고지 후 승인, force push 금지, 설계에 없는 기능 추가 금지.
- 개발 예산(D-2): 주당 실험 20건, 비전 호출 300구역, 봉인 교체 주기당 승격 2건. Silver 정책(D-3): 오류율 상한 10%, 감사 10%에서 최저 2%(제안값, 0% 금지). 모델·effort 라우팅은 `docs/collaboration/plans/model-routing-design.md` 1절 `routing-policy-v1`(2026-11-27 승인)을 따른다. 개발 예산·Silver 값의 정본은 `DECISIONS.md`다.
