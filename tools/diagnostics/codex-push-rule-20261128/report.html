적용 범위와 롤백

제안의 두 접두사에 일치하는 실행에는 추가 승인 요청이 생길 수 있습니다. 실제 승인창, 재시작 후 규칙 로딩, push 실행 효과는 미검증입니다. 모델 학습·추론·성능 비교도 수행하지 않았습니다.

통합 전에는 메인이 통합 여부를 결정합니다. 통합 후 코드 롤백은 통합 커밋을 되돌립니다. 규칙을 설치했다면 안내에 따라 추가 파일만 제거하고 Codex를 재시작합니다.
