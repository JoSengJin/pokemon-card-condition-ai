메인 역할
메인 = 통합·푸시·실험 단일 담당. 이 화면은 표시와 기록만 하고 권한을 강제하지 못합니다. PAIR_CODING.md/AGENTS.md는 main 통합을 Codex로 정해 두었으므로, 이양은 사용자가 그 규칙을 바꾸거나 한시적으로 허용했을 때만 의미가 있습니다. 새 메인에게는 사용자가 한 줄로 알려야 합니다.
고급 안내 — 상태 의미와 한계
사람 승인 대기: Mastra workflow가 review-gate/integrate-gate에서 suspend. 에이전트 CLI 프로세스는 이미 종료됨.
CLI 실행 중: workflow는 await-exit에서 종료를 기다림. 실제 프로세스가 실행 중이며 CLI 일시정지는 지원하지 않음(중단만 가능).
세 가지 검사: Git 계약 검사(브랜치·커밋·허용 파일) ≠ 작업 테스트(계약의 검사 명령) ≠ 통합 후 검사. 미실행은 통과가 아님.
격리 한계: 허용 파일은 실행 후 diff로만 검사. 실행 중 파일 쓰기를 막지 않음.
리뷰: 별도 CLI 프로세스로 실행되는 검토 작업. 현재 Codex 앱 대화로 메시지를 보내지 않으며, 리뷰 결과가 사람 승인을 대신하지 않음.
토큰·비용: mock과 미확인 CLI는 모두 미측정.
새 작업 만들기 — 담당·목표·고칠 파일만 고르면 나머지는 자동으로 준비됩니다
